CardioState-JEPA: Delay-Aware Cross-Modal Learning of a Shared Cardiac Representation

来源： arXiv · HF Paper · AlphaXiv

一句话主题： 跨心电、光电容积脉搏波与心音信号学习统一共享心脏生理表征

领域标签： 人工智能 / 医疗信号处理 / 跨模态心脏基础模型

快速理解

背景与任务： 心电、光电容积脉搏波和心音从电、机械与血流动力学角度描述同一心动周期，但现有心脏基础模型多为单模态训练，未能利用跨传感器共享生理信息。

核心工作： 作者提出CardioState-JEPA，通过共享Transformer编码器、掩码潜在心脏状态预测和可学习延迟对齐器，联合ECG、PPG与PCG学习统一心脏表征，并在25项下游任务上取得显著提升。

中文摘要

心电图（ECG）、光体积描记图（PPG）和心音图（PCG）提供了同一心动周期的互补视图，然而现有的心脏基础模型仅针对单一传感模态进行训练，未利用跨传感器共享的生理学信息。我们提出了CardioState-JEPA，一种心脏基础模型，基于生理学感知的联合嵌入预测架构，在ECG、PPG和PCG上联合学习单一共享表示。该模型将异构波形映射到公共token空间，使用单个共享Transformer编码器进行处理，并通过预测掩蔽的潜在心脏状态进行学习，将预训练目标置于共享生理学而非传感器特定的波形外观上。为处理电、机械和血流动力学事件之间的时间偏移，跨模态预测使用学习得到的延迟对齐器，在相应的心脏时间匹配信号。由于同步多传感器记录较为稀缺，CardioState-JEPA首先从丰富的单模态数据中学习模态内结构，然后使用配对数据在潜在心脏时间内对齐模态。作为冻结编码器在涵盖ECG、PPG和PCG的25项下游任务上进行评估，我们的编码器在平均PPG分类上比最佳自监督信号基线提高8.2个AUROC点，PCG杂音检测提高18.8个AUROC点，ECG分类提高15.5个AUROC点，并在多个ECG基准上达到或超过使用特权临床文本或监督标签训练的心脏模型。这些结果表明，异构心脏信号可以相互监督一个统一的心脏生理学基础模型。

详细分析

1. 任务输入、输出、功能和边界（约100字）

CardioState-JEPA 的输入是心电（ECG）、光电容积脉搏波（PPG）和心音（PCG）三类心脏波形，可单模态输入也可多模态同步输入；输出是一个固定维度的共享心脏状态向量，供下游线性分类或回归任务使用。其功能是作为模态无关的心脏表征提取器。边界是：不做原始波形重建、不依赖时间戳精确对齐、也不直接给出疾病诊断结论。

2. 研究动机：要解决的问题与核心 insight（约300字）

ECG、PPG、PCG 分别反映心脏的电活动、外周血流和瓣膜/心音事件，它们观测的是同一个心动周期，但现有心脏基础模型几乎都是单模态训练的，跨模态共享的生理结构没有被利用。

跨模态学习不能靠简单的“时间戳对齐”或“原始波形重建”完成。原因有二：第一，三个信号之间存在生理延迟——ECG 几乎即时反映电激活，PCG 要等电-机械耦合后才出现，PPG 更要等脉搏波传导到外周；如果按时间戳对齐 token，容易把一个模态的心动周期相位与另一个模态的不同相位匹配。第二，同一心拍在三种信号中的形态完全不同，强制重建原始波形会诱导模型学习传感器表面的形状，而不是共享的生理状态。此外，单模态数据丰富、同步配对数据稀缺，进一步增加了对齐难度。

核心 insight 是：把三种信号都看成同一个隐藏心脏状态 \(\mathbf{c}(t)\) 的“渲染”，每种模态有自己的观测函数和延迟。要学的是共享潜状态本身，并显式估计模态间生理延迟，把预测目标放在潜空间而非波形上；同时用“先单模态后跨模态”的两阶段课程来适配数据分布的不对称性。

图1：CardioState-JEPA的动机。ECG、PPG和PCG在不同的生理时间观测同一心动周期，提示共享的心脏表征。

3. 核心贡献（约300字）

论文提出并验证了以下几点：

  • 问题形式化：将统一心脏表征学习定义为从异质、带生理延迟的观测中恢复共享潜状态，而不是把多个传感器信号简单拼接。
  • CardioState-JEPA 架构：用轻量模态 tokenizer 将 ECG、PPG、PCG 统一到同一 token 空间，再用一个共享 Transformer 编码器处理所有模态，避免了为每个传感器训练独立模型。
  • 两阶段课程学习：先用大量单模态数据做模态内掩码潜在预测，再用少量配对数据做延迟感知跨模态预测，与真实数据分布相匹配。
  • 延迟感知对齐机制：显式估计模态间生理偏移，把不同模态的 token 在“心脏时间”上对齐后再比较，而不是按原始时间戳对齐。
  • 实验验证：在 25 个下游任务上冻结编码器线性探测，PPG 分类平均 AUROC 提升 8.2 点、PCG 杂音检测提升 18.8 点、ECG 分类平均提升 15.5 点（相对最佳自监督单模态基线），并且能在多个 ECG 基准上与使用临床文本监督的模型匹敌。

4. 推理阶段整体流程与基模（约400字）

部署时，系统的核心是一个固定配置的共享 Transformer 编码器和投影器。它们扮演模态无关的特征提取器：任何心脏信号先被转成统一 token 序列，再被映射到同一个心脏状态空间；下游任务只需要在状态向量上接一个轻量线性头。

  1. 输入信号：系统接收一段或多段 ECG、PPG、PCG 波形文件或数据流 → 交给对应的模态 tokenizer。
  2. 模态 tokenizer：把波形按该模态设定的步长切成 token，并为每个 token 附加位置信息和模态标记 → 输出统一维度的 token 序列。
  3. 共享 Transformer 编码器：对 token 序列做双向上下文建模，让不同时间位置的心拍信息相互参照 → 输出每个 token 的上下文编码。
  4. 投影器与池化：把上下文编码映射到公共心脏编码空间，并对整段序列做池化 → 输出固定长度的心脏状态向量。
  5. 任务线性头：根据分类或回归任务读取该向量 → 输出预测结果。

如果用户同时提供多个模态的同步记录，各模态信号分别完成第 2 步后，在同一编码器中共同处理，并在第 4 步以融合后的状态向量做预测。整个流程中编码器与投影器保持固定，不进行任何参数更新。

5. 核心方法：按论文 Method 小节总结（约600字）

3.1 Overview（概述）

CardioState-JEPA 的目标是让一个编码器同时服务 ECG、PPG、PCG 三种模态，而不是为每个传感器训练独立模型。每个模态先经过该模态特有的轻量 tokenizer 变成公共 token，之后所有处理都在共享 Transformer 编码器中完成，最终由投影器产生统一的心脏编码。两阶段训练对应两类数据：阶段 I 用大量单模态数据学习每类信号自身的结构；阶段 II 用少量配对数据让模态在潜空间中相互对齐。

3.2 Problem Formulation（问题形式化）

论文假设存在一个隐藏的心脏状态过程 \(\mathbf{c}(t)\)，每个模态的观测是它的延迟渲染：

\[ \mathbf{x}_m(t) = \mathcal{O}_m\big(\mathbf{c}(t - \tau_m(t)),\ \mathbf{u}_m(t)\big) \]

其中 \(\mathcal{O}_m\) 是模态特定渲染函数，\(\mathbf{u}_m\) 是传感器噪声与干扰，\(\tau_m\) 是相对电激活的生理延迟。由此得出两条设计需求：第一，共享心脏状态必须能从单个模态的部分观测中恢复；第二，不同模态的表示在消除模态间延迟后应当一致。这两条需求分别对应阶段 I 和阶段 II 的目标。

3.3 Modality Tokenizers and Shared Encoder（模态 Tokenizer 与共享编码器）

三种信号在采样率、通道数和形态上差异很大，直接用原始波形会让编码器浪费容量在采集差异上。Tokenizer 由跨步卷积和多尺度深度可分离卷积组成，把波形转换成包含局部上下文的 token 序列；不同模态的 token 在维度上对齐，并加入位置嵌入与模态嵌入。共享 Transformer 编码器（ViT-B：12 层、12 头、768 维）对所有模态使用同一套参数，没有模态特定层。投影器把编码映射到心脏编码空间，动量编码器用于在训练中提供稳定目标。注意力可视化表明，共享编码器会在 ECG 上关注 QRS 等电事件，在 PPG 上关注上冲与收缩峰，在 PCG 上关注心音事件，说明它在学习共同心脏表征的同时保留了模态特定的关键模式。

图7：CardioState-JEPA在代表性ECG、PPG和PCG信号上的注意力可视化。ECG图突出显示诸如QRS波群等快速电事件，PPG图强调包括上冲和收缩期峰值在内的脉搏形态，PCG图聚焦于局部声学心音事件。这些模式表明共享编码器在学习共同的心脏表征的同时关注心动周期的模态特定表现。

3.4 Stage I: Intra-Modal JEPA（阶段 I：模态内 JEPA）

阶段 I 要满足“从部分观测恢复共享状态”的要求。做法是把 token 序列中很大比例的连续块掩码掉，编码器只处理可见 token，轻量预测器 \(q_\theta\) 在潜空间预测掩码位置的目标，目标来自动量编码器对未掩码信号产生的编码并使用停止梯度。损失为

\[ \mathcal{L}_{\text{intra}} = \frac{1}{|\mathcal{T}|}\sum_{i\in\mathcal{T}} \mathcal{H}\big(\mathrm{LN}(\hat{\mathbf{z}}^i),\ \mathrm{LN}(\bar{\mathbf{z}}^i)\big) \]

其中 \(\mathcal{H}\) 是 Smooth-L1 损失。掩码块经常覆盖完整心拍，模型无法靠局部插值，必须利用相邻周期的节奏和形态推断缺失的心脏状态。

3.5 Stage II: Delay-Aware Cross-Modal JEPA（阶段 II：延迟感知跨模态 JEPA）

阶段 II 解决“消除延迟后模态一致”的问题。按相同时间戳对齐会把 ECG 的 R 波与 PCG 第一心音或 PPG 上升支比较，学到的是错位的表面关系。延迟头 \(h_\delta\) 根据源模态编码和目标模态嵌入估计有界偏移：

\[ \tau^i_{m\to n} = \tau_{\max}\tanh\big(h_\delta([\mathbf{z}^i_m;\ \mathbf{e}_n])\big) \]

目标 token 用高斯核在“源时间 + 估计延迟”处软采样：

\[ a_{ij} = \mathrm{softmax}_j\left(-\frac{1}{2}\left(\frac{t_j - t_i - \tau^i}{\sigma}\right)^2\right),\qquad \tilde{\mathbf{z}}_n^i = \sum_j a_{ij}\,\bar{\mathbf{z}}_n^j \]

对齐质量用权重 \(w_i = 1 - H(a_i)/\log N_i\) 衡量，熵高或覆盖不足的对齐会被降权或排除。交叉预测损失为

\[ \mathcal{L}_{\text{cross}} = \frac{\sum_i w_i\, \mathcal{H}\big(\mathrm{LN}(\hat{\mathbf{z}}_{mn}^i),\ \mathrm{LN}(\tilde{\mathbf{z}}_n^i)\big)}{\sum_i w_i + \epsilon} \]

这里使用的预测器与阶段 I 相同，只是额外接收延迟条件。为防止延迟头退化为随意偏移，论文用生理锚点做监督：ECG-PCG 用 R 波到第一心音的间隔，ECG-PPG 用脉搏到达时间：

\[ \mathcal{L}_{\text{delay-sup}} = \frac{1}{|\mathcal{T}|}\sum_{i\in\mathcal{T}} \mathcal{H}\big(\tau^i,\ \tau^i_{\text{anchor}}\big) \]

锚点不可靠时只跳过该监督项，延迟估计和交叉预测仍然保留。经过这一阶段，模态空间会从按传感器聚类变为按心脏状态混合的结构。

3.6 Auxiliary Objectives and Training（辅助目标与训练）

完整目标为

\[ \mathcal{L} = \lambda_{\text{intra}}\mathcal{L}_{\text{intra}} + \lambda_{\text{cross}}\mathcal{L}_{\text{cross}} + \lambda_{\text{delay}}\mathcal{L}_{\text{delay-sup}} + \lambda_{\text{state}}\mathcal{L}_{\text{state}} + \lambda_{\text{phase}}\mathcal{L}_{\text{phase}} \]

其中 \(\mathcal{L}_{\text{state}}\) 是 VICReg 风格的跨模态状态对齐，推近配对模态表示并防止坍缩；\(\mathcal{L}_{\text{phase}}\) 用锚点预测心拍内相位，把表征与心动周期结构绑定。课程设置上，阶段 I 只采样单模态数据，仅激活模态内与相位项；阶段 II 从阶段 I 热启动，配对样本激活跨模态、延迟与状态项，单模态样本继续采样以避免模态漂移。

6. 局限性和展望（约300字）

论文明确呈现的限制主要有：同步多传感器数据仍然稀缺，阶段 II 只能依赖有限的配对语料，跨模态对齐质量受此约束；延迟监督依赖峰值检测，在噪声大或心律失常严重的记录中，可靠锚点会被掩码，监督信号减弱；PCG 预训练语料规模远小于 ECG 和 PPG，三模态数据不均衡；评测集中在公开基准，尚未在真实临床工作流中验证。

可以谨慎推断的限制是：共享表征追求模态不变性（图 3 显示阶段 II 后模态边界几乎消失），这种混合可能削弱某些模态特有的细粒度信息，例如 ECG 上极细微的 ST-T 改变或 PCG 中罕见的杂音形态；冻结线性探测协议能证明表征的迁移力，但在与预训练分布差异很大的任务上，可能需要端到端适配；两阶段共 500K 步的训练成本对复现机构有一定门槛。

展望方面，将架构扩展到更多心脏传感器（如心冲击图、阻抗心动图）或在更大规模、多中心同步数据上训练，有望进一步提升共享心脏表征的完整性；引入临床文本或报告作为弱监督，可能缩小与当前最强监督模型之间的差距；对延迟进行个性化与动态建模，则能让模型在心率变化和运动伪影下更加稳健。这些方向都指向“以心脏生理状态为中心、而非以单个传感器为中心”的下一代心脏基础模型。
