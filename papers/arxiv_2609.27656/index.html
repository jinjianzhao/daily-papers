InternW0: A Foundational Physical World Model for Efficient Real-World Interactions

来源： arXiv · HF Paper · AlphaXiv

一句话主题： 构建具身智能物理世界模型，联合预测视觉动态与机器人控制

领域标签： 物理世界模型 / 机器人操控 / 具身智能

快速理解

背景与任务： 物理智能不仅需要预测世界演化，还必须在变化中保持行动有效。

核心工作： 作者提出InternW0模型，采用非对称视频-动作架构和上下文路由，并在多源数据上训练，验证于真实科学实验任务。

中文摘要

物理智能要求的不仅仅是预测世界如何演化：预测必须在世界持续变化时仍然可操作。我们推出InternW0，这是上海人工智能实验室InternW物理世界模型系列的首个实例，其构建围绕全模态接口、异步多频率处理，以及在部分观测和外部影响下的局部物理建模。InternW0通过一种带有流匹配的非对称视频–动作架构，联合学习未来视觉动态和连续机器人控制。高容量视频专家提供更长时域的预测上下文，而轻量级动作专家以更快的时标运行。InternW0不为每次动作更新重新生成未来，而是复用逐层K/V，并通过观测条件上下文路由将其适配到新观测到的状态。领域特定接口和软提示支持异构具身，而接触感知的后训练引入力和触觉信号以支持接触丰富的操作。我们在约7,200小时的异构机器人和第一人称数据上训练InternW0，其中包括EgoLab——一个275小时的真实实验室第一人称数据集。评估涵盖仿真基准和现实世界科学任务，包括一个15阶段的金属–有机框架合成流程，以及一个面向通用定量移液的5阶段接触和力感知灵巧操作。这些结果推进了可扩展、异步且科学原生的物理世界模型，以实现通用且高效的现实世界交互。

详细分析

1. 任务输入、输出、功能和边界（约100字）

InternW0 的输入包括：语言指令、多视角 RGB 图像、本体感受状态，以及接触感知任务中额外接入的力/触觉历史；输出包括连续动作块（chunk）、未来视频预测，以及力/力矩与触觉信号的预测。其功能覆盖单臂、双臂移动操作和灵巧手精细操作，并可嵌入科学实验工作流。功能边界：在部分观测与外部扰动下只对局部物理状态建模；头/腰部自由度、不可观测的外部因素不在控制与监督范围内。

2. 研究动机：要解决的问题与核心 insight（约300字）

物理智能要求预测是“可行动的”：智能体必须估计当前物理状态、预判候选动作的后果，并利用反馈修正决策；这一切还要在部分观测、外部扰动和有限算力下进行。现有世界动作模型（WAM）把未来视觉预测与动作生成耦合起来，但存在三点不足：对异构具身以及力、触觉等物理模态支持不够；同步更新昂贵的视频预测与快速动作生成会带来延迟；缺乏对外部影响下局部物理状态的持续估计机制。

核心 insight 来自资源受限视角：世界模型应被看作有限感知与计算资源下对物理状态转移的紧凑近似。由此导出三条设计需求：全模态接口（omnimodal interfaces）、异步多频率处理、局部环境与动作建模。架构层面，核心 insight 是“非对称双专家 + 上下文复用”：高容量视频专家提供长视界预测上下文，轻量动作专家以更快时间尺度做控制；不为每次动作更新重新生成未来，而是复用注意力层的键/值（K/V），并用最新观测通过观察条件化上下文路由修正计划。预测精度、决策相关性与及时性被确立为框架的三条设计准则。

3. 核心贡献（约300字）

论文提出 InternW 世界模型系列，并给出首个实例化 InternW0。

构建方面：提出非对称的视频-动作 mixture-of-transformers（MoT）架构，用 flow matching 联合学习未来视觉动态与连续控制；视频专家与轻量动作专家分工，观察条件化 chunk K/V 编辑器使预测计划可跨动作更新复用；领域软提示与专用接口支持异构具身；接触感知后训练把力/触觉历史纳入条件并与动作联合预测。

数据方面：构建约 7,200 小时、25 个训练域、81 万余条 episode 的预训练语料，包含真实/仿真机器人数据与 275 小时 EgoLab 第一人称实验室视频（图3）。

4. 推理阶段整体流程与基模（约400字）

推理时使用的基模是 InternW0 本身：视频专家负责慢时间尺度的未来视觉预测并缓存逐层 K/V；动作专家负责快时间尺度的动作块生成；两者由观察条件化 chunk K/V 编辑器耦合。视觉编码器（Wan VAE 与 DINOv3）分别提供视频潜表示与当前观测表示；在科学工作流中，外部 VLM（Intern-S2-Preview）负责把任务分解为可执行的子任务。整个推理过程如下：

  1. 输入：语言指令、初始多视角图像与本体感受 → 视频专家生成覆盖较长视界的未来视频预测，并将逐层 K/V 缓存为预测上下文；当前观测同时被编码为观测查询 → 输出：预测上下文与观测查询，交给上下文编辑接口。
  1. 输入：预测上下文 + 最新 chunk 级观测 → chunk K/V 编辑器用观测查询从预测上下文中检索任务相关信息，得到与最新观测对齐的上下文 → 输出：编辑后的 chunk 级上下文，交给动作专家。
  1. 输入：编辑后的上下文、语言嵌入、本体感受（接触感知任务中还有力/触觉历史） → 动作专家生成一个 16 步的动作块 → 输出：可执行动作序列，交给机器人或仿真器。
  1. 输入：已执行的动作及随后产生的环境反馈（新图像、力/触觉、本体感受） → 反馈被编码为最新观测并驱动两个异步循环：快循环回到第 2 步修正下一动作块的上下文；慢循环触发视频专家在后台重新预测并更新缓存 → 输出：新一轮的观测查询与缓存上下文。
  1. 重复第 2–4 步直至子任务完成；科学任务中每个阶段的执行结果交由 InkStone 平台中的 VLM 生成下一子任务 → 最终输出：完整任务执行结果与各阶段测量记录。

5. 核心方法：按论文 Method 小节总结（约600字）

2.1 Architecture（架构）

InternW0 用 mixture-of-transformers（MoT）主干实例化框架：高容量视频专家负责未来视觉预测，轻量动作专家负责机器人控制。每个联合层包含模态专属的 block，参数与 token 流彼此分离，通过“观察条件化的视频上下文接口”连接，使两个专家可以使用不同容量，同时保持视觉预测与动作生成耦合。这种交互是刻意非对称的：视频专家只从视觉观测与语言中构建共享预测表示，不消费机器人动作 token 或领域身份；动作专家则读取视频上下文、最新观测、本体感受、语言条件与具身专属接口。图1给出 InternW 世界模型系列的总体框架，图2给出 InternW0 的具体结构。

图1：InternW世界模型系列的框架。

图2：InternW0的架构。模态专属的视频专家和动作专家通过以观察为条件的chunk K/V编辑器耦合。该编辑器将缓存的视频上下文适配到chunk级观察，使其可在动作更新之间复用。冻结的Wan VAE和DINOv3编码器提供视觉表示，预计算的语言嵌入为两个专家提供条件。领域特定接口和软提示支持异构具身；力觉和触觉通道在接触感知后训练中可选引入。

2.1.1 Asynchronous Duplex Inference（异步双工推理）

目的：解决“每个控制更新都重新计算完整预测计划太昂贵，而一直执行旧计划又会过时”的张力。机制：视频专家按慢时间尺度更新预测并缓存逐层 K/V；动作专家按快时间尺度从最新计划与当前感知生成短 chunk。二者由缓存视频上下文和逐层 chunk K/V 编辑器协调。当前 chunk 对齐的 RGB 观测经 DINOv3 编码并投影为视觉上下文，学习得到的查询编码器将其浓缩为少量路由查询；编辑器先用查询从预测上下文中检索 \(R_{\ell,n}=\operatorname{Attn}(W^q_\ell q_n,K_\ell,V_\ell)\)，再把检索结果路由回原视频 token 位置 \(D_{\ell,n}=\operatorname{Attn}(K_\ell,R_{\ell,n},R_{\ell,n})\)，由轻量投影预测残差修正 \((\Delta K_{\ell,n},\Delta V_{\ell,n})\)，并按学习门控叠加：\(\widetilde{K}_{\ell,n}=K_\ell+\sigma(\gamma_\ell)\Delta K_{\ell,n}\)，\(\widetilde{V}_{\ell,n}=V_\ell+\sigma(\gamma_\ell)\Delta V_{\ell,n}\)。残差投影零初始化，因此编辑器从恒等映射开始逐步学习修正。底层视频上下文保持不变，每个动作 chunk 用各自的新观测建立自己的编辑视图，从而保留长视界预测结构，同时避免策略基于越来越过时的世界状态做决策。图7显示该设计的关键路径推理效率。

2.1.2 Soft Prompts for Cross-embodiment Pretraining（跨具身预训练的软提示）

目的：在不同机器人之间共享交互知识，同时保留动作语义与感知配置的差异。机制：每个训练域 \(d\) 有一组可学习的软提示 \(\boldsymbol{P}^{(d)}\)，拼接到每个动作 chunk 之前；域由数据来源、具身形态与子集身份定义，不一一对应机器人形态。领域专属的输入/输出投影把动作与传感器表示映射到共享 token 空间，每个维度的有效性掩码区分“缺失通道”与“有效零值”。这样，联合训练不要求各机器人控制或感知语义完全相同。

2.1.3 Mixed Supervision for Prediction and Control（预测与控制的混合监督）

目的：让无动作标注的第一人称视频提供预测监督，让带动作标签的机器人轨迹额外提供控制监督。机制：两类数据共享同一视频专家，机器人轨迹额外监督动作专家；两个专家都使用连续 flow matching。对干净目标 \(x_0\)、高斯噪声 \(\epsilon\) 与归一化 flow 时间 \(\tau\in[0,1]\)，加噪输入为 \(x_\tau=(1-\tau)x_0+\tau\epsilon\)，目标速度为 \(v^*=\epsilon-x_0\)。flow 时间按 shifted 连续调度采样，每个视频样本采样一个、每个动作 chunk 独立采样。视频注意力使用首帧因果掩码：观测首帧不 attend 未来帧，未来帧可 attend 首帧且彼此双向；首帧保持干净并作为时间锚点，不参与视频损失。预训练目标为 \(\mathcal{L}_{\mathrm{pre}}=\mathbb{E}_{\xi\sim\mathcal{D}_{\mathrm{mix}}}[\lambda_v\mathcal{L}_{\mathrm{video}}(\xi)+\lambda_a\mathbb{I}_{\mathrm{act}}(\xi)\mathcal{L}_{\mathrm{joint}}(\xi)]\)，两项都是带调度权重的掩码平方速度误差；无动作样本只贡献视频损失。

2.1.4 IDM Conditioning（IDM条件）

目的：在动作监督训练中为动作专家提供“如果未来是……，应该怎样动作”的预测性条件。机制：维护第二条独立去噪条件流，与主视频流共享全部 VideoDiT 参数，但使用独立采样的噪声与 flow 时间。每个样本以 0.5 概率保持条件流干净，否则用独立 shifted flow 时间扰动，首帧始终干净。主视频流受视频损失监督，条件流没有单独重建损失，其逐层 K/V 被编辑器和动作专家消费；条件流的 K/V 不截断梯度，动作损失的梯度可经 K/V 编辑器传播进共享视频专家，因此预测表示由“未来视频建模”和“对动作是否有用”共同塑造。推理时，条件流被生成的视频上下文替代，其逐层 K/V 被缓存并经同一接口供给动作专家。

2.1.5 Contact-Aware Post-training with Joint Action–Contact Prediction（接触感知后训练与联合动作-接触预测）

目的：在接触动力学关键的下游任务中，仅凭图像不足以判断接触状态。机制：预训练不要求力/触觉标注；后训练时在动作接口上增加实测交互信号，并与动作一起预测其未来演化。物理时间步 \(i\) 的预测目标扩展为 \(\mathbf{y}_i=[\mathbf{a}_i^\top,\mathbf{f}_i^\top,\mathbf{h}_i^\top]^\top\)，其中 \(\mathbf{a}_i\) 为动作表示、\(\mathbf{f}_i\) 为力/力矩信号、\(\mathbf{h}_i\) 为触觉表示。每个 chunk 只把生成之前可用的接触历史作为条件，未来接触通道与动作通道一起加噪、去噪；动作通道解码执行，接触通道作为预测反馈。共享的视频预测主干保持不变，只扩展动作侧接口。

2.2 Training Pipeline（训练流水线）

训练流水线组织为严格分离三层的数据平面、执行平面与优化平面：数据平面用自研数据引擎把异构机器人语料整理为训练样本流；执行平面基于 Ray 管理集群进程并协同放置数据物化与 GPU 训练；优化平面基于自研分布式训练框架，梯度训练器负责训练循环，并行策略通过可插拔后端协议注入。

2.2.1 Streaming Data Pipeline（流式数据流水线）

核心理念是全程解耦元数据与样本负载。样本先表示为紧凑连续的描述符，采样时只对元数据重排，负载按需物化，从而减少通信与数据搬运。多源合并时使用领域级混合权重，防止单一语料因体量主导训练；结果按块分区到各节点，使本地 batch 的域分布相对均匀。样本级随机选择由样本身份确定性生成，而不是执行或调度顺序，因此断点续跑能精确复现同一数据流。此外还实现节点级共享缓存，同节点 worker 可复用已解码的视频样本，减少重复 I/O。

2.2.2 Parallelism, Precision, and Compilation（并行性、精度与编译）

并行：使用可组合 FSDP2，分片单元跟随模型结构——每个联合 MoT 层与每个专家阶段独立分片，窄的逐域接口跨 rank 复制；单节点用扁平分片网格，多节点透明升级为层级 replicate-and-shard 网格，模型与检查点格式无需改动。精度：保留 FP32 主参数与优化器状态，模型计算用 BF16，分布式梯度归约用 FP32。编译：每个联合层先编译为定形状的全图单元，再套激活检查点与分片包装；选择性激活重计算只重建可配置的前缀层。检查点以事务方式持久化，支持 epoch 中途精确恢复。

6. 局限性和展望（约300字）

论文明确说明的限制主要有：

  1. 分布外泛化：RoboTwin 2.0-Clean2Random 中 clean 与 randomized 成功率相差 15.2 个百分点，说明未见过的场景变化仍有挑战。
  2. 高精度接触步骤：MOF 实验最后按钮按压阶段成功率降至 26.7%（毫米级精度要求）；定量移液的吸头弹出与归位为 46.7%，说明接触感知后训练尚未完全解决最精细的阶段。
  3. 数据范围：预训练语料排除了灵巧手机器人数据与格式转换不完整的数据拷贝；EgoLab 只以视频-only 路径参与预训练；力/触觉信号只在接触感知后训练中引入，预训练不要求这类标注。

可以谨慎推断的限制：慢时间尺度的视频预测依赖缓存复用，当实际执行长期偏离预测未来时，编辑修正只能部分补偿；真实实验中子任务由外部 VLM 生成，子任务分解错误会沿链路传播；每任务 15 次试验的统计功效有限；当前验证集中在桌面操作与单个科学工作流，对移动操作、多智能体与长时间科学实验覆盖不足。

展望：InternW 系列的目标是发展可扩展、异步且“科学原生”的物理世界模型——纳入更多模态与数据、把力/触觉感知扩展到更大范围的任务，并让执行记录与测量结果回流到模型迭代中，在更多真实科学发现工作流中形成闭环。
