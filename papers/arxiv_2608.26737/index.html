Generative Semantic Scene Completion

一句话主题： 生成式语义场景补全，用离散扩散模型统一生成与精修

领域标签： 语义场景补全 / 离散扩散模型 / LiDAR点云

快速理解

背景与任务： 户外LiDAR语义场景补全需从稀疏扫描恢复稠密语义体素网格，存在极端类别不平衡和稀疏观测挑战。

核心工作： 作者提出GSSC框架，以单一离散扩散公式实现配对稀疏-稠密数据合成、语义引导生成补全和结构化源离散扩散精修，无需重训基座即提升多种外部补全方法的mIoU。

中文摘要

室外LiDAR语义场景补全（SSC）从观测目标体积1%的扫描中恢复稠密语义体素网格，且类别不平衡超过7000倍。我们将SSC重构为生成式语义场景补全（GSSC）：一个承担三种角色的单一离散扩散公式。首先，成对稀疏-稠密场景合成（PS³）生成匹配的稀疏LiDAR观测及其稠密语义补全，从源头解决长尾问题，并构建了PS³-SemanticKITTI语料库，我们将其与SemanticKITTI一起用于训练。其次，语义引导的生成式场景补全（SGSC）通过鸟瞰语义图和稀疏3D特征流，以稀疏扫描为条件，利用多项离散扩散从噪声生成场景。第三，同一框架转而以单步流匹配细化已有补全结果：结构化源离散扩散（S²D²）。S²D²提升了SGSC自身输出及所有受测外部SSC基线的mIoU，且无需重训练基线或进行测试时自适应。在最强基线上，单步细化且无测试时增强即在SemanticKITTI隐藏测试集上达到38.8%的mIoU。据我们所知，这是该排行榜上最佳的因果式单扫描单样本结果，较同一限制下此前最佳已发表分数高出2.1个百分点。四步校正配合八视角测试时增强达到39.2%，该结果不在上述限制范围内。

详细分析

1. 任务输入、输出、功能和边界（约100字）

本方法面向户外 LiDAR 语义场景补全（SSC）。输入为单帧旋转 LiDAR 扫描；输出为一个稠密语义体素网格，覆盖 \(51.2\text{m} \times 51.2\text{m} \times 6.4\text{m}\)，分辨率 0.2 m，共 \(256 \times 256 \times 32\) 个 voxel，每个 voxel 被标记为 19 个语义类别之一或空/未标记类。功能是同时恢复未观测区域的几何占用与语义。边界是推理时只能使用当前单帧，不能使用未来帧；评测只统计序列中至少被某一帧扫描覆盖到的体素。

2. 研究动机：要解决的问题与核心 insight（约300字）

SSC 的难点来自传感器与标注共同造成的双重不平衡：一帧扫描只照亮目标体积约 1% 的 voxel，其余全部需要推断；而 SemanticKITTI 的类别直方图由采集路线决定，植被占标注点的 26.7%，摩托车手仅占 0.0037%，不平衡超过 7000 倍。图 1d 显示类别频率与 SCPNet 隐藏测试每类 IoU 的 Pearson 相关系数达 0.80，即越对规划重要的类别，训练信号越少。判别式方法无论是重加权、改网络结构、改监督，都不能增加稀有类样本；无条件生成器虽然能生成场景，却不接受稀疏观测，且仍复制原本的长尾；条件生成器则总是从噪声重建路面等确定性结构，浪费了已有预测。

核心 insight 是：将 SSC 重述为生成建模，并用同一个离散扩散公式承担三个角色。这样，(i) 可以从完整场景分布中主动合成带匹配稀疏观测的训练对，按对象库供给放大稀有类；(ii) 在没有基础模型时，从噪声做条件生成；(iii) 在已有基础模型时，把生成过程倒过来用作一步校正器，在冻结预测的基础上做确定性传输。三者不是三个模型，而是同一数学框架的不同源与不同条件设置。

3. 核心贡献（约300字）

本文的贡献可归纳为五个方面。

第一，将 SSC 重述为生成式语义场景补全（GSSC）：用一个离散扩散公式统一了 PS³、SGSC、S²D² 三种角色，分别负责合成配对数据、从噪声生成补全、以及细化已有补全。

第二，提出 PS³ 配对稀疏–稠密场景合成，通过金字塔离散扩散生成稠密场景，经 JS 散度过滤、稀有类对象库粘贴、Halo HDL-64E 射线追踪，产出 PS³-SemanticKITTI 语料库；与真实数据联合训练可提升 voxel-grid-native 基线的补全质量。

第三，提出 SGSC，用 BEV 语义图与稀疏 3D 特征流作为条件，从均匀类别噪声生成完整语义场景，无需任何基础模型。

第四，提出 S²D²，把冻结基础模型的 argmax 预测作为结构化源，通过流匹配学习到真值的确定性传输，无需重训或测试时适应即可提升 SGSC 自身输出和所有被测试外部基线的 mIoU。最强基线上单步无测试时增强达到 38.8% mIoU，较此前同约束最佳公布成绩高 2.1 个百分点；四步八视图测试时增强达到 39.2%。

第五，给出单步部署的理论支撑：精确性恒等式和非放大误差界，解释为何一步校正可行，并指出薄结构改善有限、遮挡未被隔离等后续方向。

4. 推理阶段整体流程与基模（约400字）

推理时使用两个既有模块：一个外部 SSC 基础网络（如 SCPNet）作为结构化源生成器，一个 S²D² 离散扩散校正器。基础网络的作用是从稀疏扫描给出初始语义预测；校正器的作用是在逐体素标签单纯形上把该预测向真实分布移动一小段，而无需重训基础网络。

  1. 输入单帧 LiDAR 点云 → 预处理模块将其体素化为 \(256\times256\times32\) 占用网格，并投影生成 BEV 观测线索 → 输出占用网格 \(\mathbf{L}\) 与 BEV 投影。
  2. 输入占用网格与原始点云 → 基础 SSC 网络运行一次前向，输出稠密语义体素预测；同时从该预测的顶部非空类别投影得到 BEV 语义图 \(\mathbf{B}\) → 得到结构化源 \(\mathbf{x}_{\mathrm{src}}\)（每体素 argmax 的 one-hot 表示）与条件 \(\{\mathbf{B},\mathbf{L}\}\)。
  3. 输入 \(\mathbf{x}_{\mathrm{src}}\)、\(\mathbf{B}\)、\(\mathbf{L}\) → S²D² 校正器以这些为输入，估计干净场景终点 \(\hat{\mathbf{x}}_0\) → 得到校正方向 \(\hat{\mathbf{x}}_0-\mathbf{x}_{\mathrm{src}}\)。
  4. 输入当前单纯形上的点与校正方向 → 按预设时间表执行一次 Euler 更新，把当前点沿方向移动一步 → 得到精炼后的体素类别分布。
  5. 对每个体素取 argmax → 输出最终稠密语义体素网格 \(\hat{\mathbf{Y}}\)。
  6. 若配置为多步细化，则将当前更新作为新源，重复第 3–4 步指定次数，再执行第 5 步 → 最终输出。

5. 核心方法：按论文 Method 小节总结（约600字）

3.1 Preliminaries（预备知识）

该小节定义任务与基础符号：语义网格被嵌入乘积单纯形 \(\mathcal{M}=\prod_v \Delta^{K-1}\)，标签变成单位向量。多项式扩散以均匀分布 \(\mathbf{u}\) 为噪声，通过保留概率 \((1-\beta_t)\) 逐体素向 \(\mathbf{u}\) 混合，得到闭式边缘 \(q(\mathbf{x}_t|\mathbf{x}_0)\)；反向过程由贝叶斯公式给出，推理时用去噪器估计的 \(\hat{\mathbf{x}}_0\) 替换真实 \(\mathbf{x}_0\)。Flow Matching 则用于 S²D² 的直线插值与速度场估计，是后续小节的基础。

3.2 Paired Sparse–Dense Scene Synthesis (PS³)（成对稀疏–稠密场景合成）

目的是为补全模型提供“稀疏扫描-稠密标签”配对数据，同时放大稀有类。机制是先用三级金字塔离散扩散从粗到细生成完整语义网格；再用 JS 散度过滤掉分布偏移的样本；随后从对象库中粘贴稀有类实例，使被粘贴类别的数量由对象库供给而非原始直方图决定；最后用 Halo HDL-64E 射线追踪器从合成场景反推出传感器本会看到的稀疏扫描与无效掩码。输出 PS³-SemanticKITTI 语料库，与真实帧一起作为后续模型的训练输入。

图 2：PS 3：离线数据增强流水线。三个级联的从粗到细多项式扩散，经 Jensen–Shannon 散度过滤器筛选；稀有类别对象库和硬件感知的 LiDAR 观测（Halo）HDL-64E 光线追踪器再将每个合成场景变成（稀疏、稠密）对。标定、阈值和粘贴伪代码见补充材料附录 A。

图 3：一个 PS 3 对。金字塔扩散生成一个场景（S1→S2→S3，a–c）；经 D_JS 筛选的样本接收来自对象库的稀有类别，得到 Y~（d；彩色为粘贴对象），Halo 将其光线追踪为稀疏扫描 X~（e）。

3.3 Semantic-Guided Generative Scene Completion (SGSC)（语义引导的生成式场景补全）

目的是在没有基础预测时，直接从噪声生成补全。扩散链从均匀类别噪声 \(\mathbf{u}\) 开始，条件 \(\mathbf{c}=\{\mathbf{B},\mathbf{F}\}\) 由两个流组成：一个经过学习的 BEV 头给出的鸟瞰语义图 \(\mathbf{B}\)，以及一个冻结的 LiDAR 分割骨干提供的逐体素稀疏特征 \(\mathbf{F}\)；两流以加法形式注入 U-Net 各层，时间步仅通过 AdaGN 进入。训练最小化每步 KL 散度，并辅以 Lovász-softmax 与瓶颈辅助项；推理时运行完整 100 步反向采样，最终取 argmax。

图 4：SGSC 去噪器的生成角色。一个四级稠密 3D U-Net（通道数 32→256）从均匀先验 x_T=u 生成场景，以一张 BEV 图 B 和来自一次扫描的逐体素 LSK3DNet 特征 F 为条件，并在每一级以加法方式注入（式 3）；时间步仅通过自适应组归一化（AdaGN）进入，瓶颈层堆叠两个残差块（RB）。同一架构针对结构化源重新训练后，驱动 S2D2 细化（图 5）。

图 8：生成器继承其引导的质量。真值场景（左）与来自同一开发检查点的两个 256²×32 SGSC 补全（验证序列 08，帧 6；从噪声 T=100，权重相同，仅 BEV 条件不同：oracle 与预测）。预测的 BEV 保留了路面，但使道路使用者坍缩。

3.4 Structured Source Discrete Diffusion (S²D²)（结构化源离散扩散）

目的是在不重训基础模型的前提下，用一个流匹配步骤校正其输出。把基础模型的 argmax 预测 \(\mathbf{x}_{\mathrm{src}}\) 作为结构化源，与 one-hot 真值 \(\mathbf{x}_0\) 构成线性插值 \(\mathbf{x}_t=\bar{\alpha}_t\mathbf{x}_0+(1-\bar{\alpha}_t)\mathbf{x}_{\mathrm{src}}\)。训练时沿路径做类别采样并最小化以 \(\mathbf{x}_{\mathrm{src}}\) 代替均匀先验的离散扩散 KL，同时使用 Lovász 与辅助交叉熵项；推理时从 \(\mathbf{x}_{\mathrm{src}}\) 出发，用校正器估计的 \(\hat{\mathbf{x}}_0\) 计算速度，按 \(\tilde{\mathbf{x}}_{t-1}=\tilde{\mathbf{x}}_t+(\bar{\alpha}_{t-1}-\bar{\alpha}_t)(\hat{\mathbf{x}}_0-\mathbf{x}_{\mathrm{src}})\) 执行一步 Euler 更新，再取 argmax。由于路径是直线且源与目标固定，单步即可完成主要校正；误差界 \(\|\tilde{\mathbf{x}}_{t_0}-\mathbf{x}_0\|_1\le \max_i\varepsilon_i+2\bar{\alpha}_T\) 排除了误差放大。

图 5：S2D2 细化：共享去噪器的第二个角色。速度场在逐体素单纯形上以一步欧拉法将基础预测 x_src 推进到真值 x_0（顶部）；恒等式和误差界排除了会迫使完整链路的放大效应（中部；附录 B 的命题 3、定理 1 和推论 1）；一个摩托车手场景，冻结的 base 与 base + S2D2（N=1，一次去噪器评估）的对比（底部）。

图 7：我们在验证序列 08 上的补全结果（行：帧 004025、001850）。从占用率约 1% 的扫描 (a) 和 base 导出的 BEV (b) 出发，一步校正恢复出接近真值 (d) 的稠密语义 (c)。

3.5 Why the Correction Works（校正为何有效）

校正有效来自三点：逐项匹配使损失只在基础模型出错的体素上产生大梯度；辅助 Lovász/交叉熵项与 KL 共享同一端点估计，在 \(\hat{\mathbf{x}}_0=\mathbf{x}_0\) 时同时消失，因此不改变最优解，但在 KL 平坦处继续提供信号；单步部署的误差界保证误差不随链长累积。需要强调的是，该理论只排除“必须多步”的放大效应，并不自身保证一步足够；一步足够是实验观察到的。

6. 局限性和展望（约300字）

论文明确指出的限制包括：实验没有孤立遮挡的影响；薄结构（thin structures）的 IoU 改善很小；在较弱的基础模型上（如 JS3C-Net），S²D² 会抹除真值中存在的行人，使 person IoU 降至 0.7%；SGSC 的预测 BEV 会保留路面但使道路使用者坍缩，说明生成结果受引导质量限制；理论只保证超过临界 margin 的体素被正确解码，不能预测 mIoU，单步可行主要是经验结论；从噪声生成需要 \(T=100\) 次去噪器评估，成本较高。

图 12：失败案例：S2D2 在 JS3C-Net base 上抹除了行人（验证序列 08，帧 001810）。行人和骑自行车者的体素保留其语义颜色；场景其余部分被调为灰色。真值 (c) 中出现的两个行人都被冻结的 base (a) 恢复，但在细化输出 (b) 中几乎被全部消除，后者的行人 IoU 降至 0.7%。

可谨慎推断的限制包括：S²D² 使用 argmax 而非置信度，可能丢失不确定性信息；合成数据与对象库源自 SemanticKITTI，对未见传感器或场景的泛化存在风险；多步加测试时增强相对单步只提升约 0.4 个百分点，收益有限；当前方法尚未显式建模遮挡，也没有利用时间一致性。未来方向应包括显式遮挡建模、在保持单步低成本下提高薄结构精度，以及将结构化源扩展到 logits 或连续置信度。
