WorldCast: Exploring Intelligent Visual Generation in World State Prediction

来源： arXiv · HF Paper · AlphaXiv

一句话主题： 多模态生成模型的世界状态预测能力评估与基准构建

领域标签： 多模态生成 / 世界状态预测 / 基准评估

快速理解

背景与任务： 多模态生成模型已能整合上下文并生成视觉输出，但高层次的连续世界状态预测任务仍未被充分探索。

核心工作： 构建了包含320个手工设计案例的WorldCast基准，评估12个模型，揭示前沿模型能力差距及语言模型对生成的影响。

中文摘要

人类会解读对世界的多模态观测，并预测其将如何演变。近期的多模态生成系统已展示出类似能力：它们能够整合多模态上下文，并合成描绘世界变化的视觉输出。为了刻画这一新兴轨迹，我们将模型能力组织为一个四级层次结构，并发现尽管模型在进步，更高层级的任务仍相对未被充分探索。为弥合这一差距，我们探索了模型在多步世界状态预测（multi-step world state prediction）上的表现；这一高层级任务要求模型根据多模态观测和多样化的参考，预测相继的未来世界状态。此类任务要求模型具备相互纠缠的理解与生成能力，并拥有广泛的世界知识，以将人类动作序列、物理变换和抽象视觉推理转化为连贯的视觉输出。我们提出 WorldCast——一个涵盖八个类别、共 320 个手工设计案例的基准，并评估了 12 个代表性模型。实验得出三个关键发现：(a) 前沿模型的进展正迅速拓展智能世界建模的边界，GPT-Image-2.5 System 得分 72.8，并在真实世界任务上展现出早期的视觉状态预测能力；(b) WorldCast 揭示了模型之间的巨大差距：连 Nano Banana Pro 也只达到 42.8，最佳开源模型得分 20.1，且在处理复杂上下文、纠缠引用（entangled references）和推理密集型任务方面存在不足；(c) 强大的生成模型能有效利用其底层语言模型的能力。这些发现凸显出对多模态生成模型的需求：它们既要具备动态规划和推理能力，同时还要深度统一，以忠实地模拟现实世界状态。

详细分析

1. 任务输入、输出、功能和边界（约100字）

WorldCast 的输入是自然语言指令 \(p\) 和一张或多张上下文图像 \(\mathcal{X}=(x_1,\dots,x_M)\)，这些图像可以指定初始状态、目标、物体或场景、物理属性、视觉规则或操作示范。输出是一个有序视觉状态序列 \(\hat{\mathcal{Y}}=(\hat{y}_1,\dots,\hat{y}_K)\)，表示世界如何随时间演化。它的功能是让多模态生成系统同时运用理解与生成能力预测连续未来状态。边界是：以关键帧序列而非逐帧视频为统一评估单位，不执行真实动作，任务限定在 L3–L4 级别。

2. 研究动机：要解决的问题与核心 insight（约300字）

现有图像与视频生成工作大多把任务看作静态外观生成、单步编辑或视频续写，缺少对“世界如何动态演化”的系统评估。论文提出一个四层视觉生成能力树：L1 是基本文生图，L2 是编辑、可控生成和视频生成，L3 需要多步动态转换、物理合理性和隐含规划，L4 则要求模型从目标、物理属性、逻辑规则或图示经验等异构参考中提取约束，并将其贯彻到连续状态生成中。作者认为，现实世界中的事件大多不是从单一外观锚点开始的：同一任务在不同时间步可能需要参考不同信息，比如“当前观察到什么状态”“最终要达到什么目标”“这个物体有什么材质”“历史中体现了什么规则”“以前的操作示范如何迁移到新场景”。因此，仅评估模型能否把一张参考图再现为一段视频是不够的，真正关键的问题是：模型能否把多模态理解、世界知识和视觉生成缠绕在一起，在生成过程中主动提取参考语义、判断每个参考的生效时机，并输出因果一致的多个未来世界状态。核心 insight 是：识别并测量这种高层“世界状态预测”能力，可以揭示前沿模型是否真正具备统一的生成智能；同时实验表明，模型在这一基准上的差距与其背后的语言模型能力密切相关。

Figure 1 : 我们的生成能力树与 WorldCast 基准。(a) 所提出的视觉生成能力树将智能视觉生成组织为四层层次结构（L1-L4）；(b) WorldCast 针对 L3-L4 层级能力，通过统一的多模态理解与生成，将现实世界上下文动态转换为连续的未来世界状态。

3. 核心贡献（约300字）

本文的贡献主要有三点。第一，论文提出一个面向真实世界模拟的视觉生成能力四层层次结构，并率先形式化“世界状态预测”任务。该任务要求模型从异构多模态参考出发，预测连续未来视觉状态，而不是只生成静态结果；这一定位使此前缺少系统评估的 L3–L4 高层能力变得可测量。第二，论文构建了 WorldCast 基准，包含 320 个手工设计案例、1,352 个请求生成的视觉状态，跨越 8 个任务类别：3 个 L3 任务与 5 个 L4 任务。基准覆盖物理演化、自适应任务完成、视觉线索、物理属性推断、视觉目标实现、逻辑规则归纳和上下文程序学习等能力，并要求图像生成模型和视频生成模型在同一个“有序状态序列”协议下比较。第三，论文对 12 个代表性模型进行系统诊断，使用任务完成、因果合理性和视觉一致性三维指标评估，并进一步分析交错式生成、更强语言模型增强和基于代码的智能体回路对性能的影响。实验发现，前沿统一模型已展示早期世界状态预测能力，但开放模型与专有模型之间的差距显著，且差距在 L4 任务上进一步拉大。

5. 核心方法：按论文 Method 小节总结（约600字）

论文没有单列 “Method” 标题，方法主体由第 2 节 WorldCast 与第 3 节 Evaluation Protocol 构成，下面按原文编号展开。

2 WorldCast（WorldCast 基准）

WorldCast 将任务形式化为：给定文本指令 \(p\) 和上下文图像 \(\mathcal{X}=(x_1,\dots,x_M)\)，生成系统 \(G\) 预测有序视觉状态 \(\hat{\mathcal{Y}}=G(p,\mathcal{X})=(\hat{y}_1,\dots,\hat{y}_K)\)。这里的参考图不是单纯的外观锚点，而是可能编码初始状态、目标、物理属性、规则或操作经验。基准的 L3 任务包括：观察条件化转移、物理模拟、自适应任务完成；L4 任务包括：视觉线索、物理属性、视觉目标实现、逻辑与规则、上下文程序学习。L3 与 L4 的区别在于参考理解和状态生成需要耦合的紧密程度：L4 为模型提供更丰富的上下文，但也要求更强的统一多模态推理。

Figure 3 : WorldCast 八个类别的代表性示例。该基准共包含 320 个手工设计的案例，需生成 1,352 个视觉状态。

2.1 Evaluation Metrics（评估指标）

评估指标的目标是在同一协议下比较图像模型和视频模型。整体分数由三维度加权得到：

\[ \mathrm{Final}=\frac{100}{3}\left(\alpha_1\,\mathrm{TC}+\alpha_2\,\mathrm{CP}+\alpha_3\,\mathrm{VC}\right), \]

其中 \(\alpha_1=\alpha_2=0.4\)、\(\alpha_3=0.2\)。TC 反映任务完成程度，CP 反映因果合理性，VC 反映跨帧视觉一致性。

2.1.1 Evaluation Dimensions（评估维度）

TC 由序列级 Progress Alignment（PA）和结果级 Outcome Completion（OC）组成：\(TC=(1-w_o)\,PA+w_o\,OC\)，其中案例特定的结果权重 \(w_o\in[0,0.5]\)，过程型任务可令 \(w_o=0\)。CP 检查相邻状态以及长距离依赖是否服从物理、逻辑或任务规则，惩罚未被支持的物体变化、因果倒置等现象。VC 检查对象身份、数量、几何、尺度、材质、相机和背景是否在不需要变化时保持稳定，同时豁免任务要求中的合理变化。

Figure 4 : WorldCast 上的定性示例。模型在三个评估维度上表现出不同的失败模式；所有分数均按 0–3 分制报告。

3 Evaluation Protocol（评估协议）

该协议将不同模型的原生输出转换为统一的有序状态序列。图像模型可以直接输出交错式序列或网格状态；视频模型则通过智能体适配器提取关键帧。

Agentic Video Adapter（智能体视频适配器）

视频模型输出连续视频后，由 GPT-6 Astra 通过 Codex 按 inclusion-first 原则选择任务对齐关键帧：尽可能覆盖更多关键状态，同时保持帧的时间约束。该适配器只判断视频中是否存在所需关键状态，不评估整段视频的因果合理性和画面质量。

LMM-as-a-Judge（LMM 评判）

GPT-5.5 作为自动评审器。输入包括任务指令、多模态参考、仅评审可见的人工提示和有序输出序列；它输出 PA、OC、CP、VC 分项评分。图像模型输出和视频关键帧使用同一套评审协议。

Human-Annotated Hints for Judges（人工标注的评审提示）

由于部分任务具有开放性，人工标注者会为每个案例写出评审提示，指明任务关键对象、必须出现的中间里程碑和确定性约束。这些提示只提供给评审器，不会暴露给生成模型；同一组提示用于评估所有模型的输出，以提高公平性和评分一致性。

6. 局限性和展望（约300字）

论文明确说明的限制包括：代码模拟和智能体检查回路的计算成本很高，单次运行可能超过一小时；Agentic Video Adapter 只确认视频是否包含关键状态，不评估完整视频的逐帧物理合理性与视觉质量；LMM-as-a-Judge 虽然与人类胜率高度相关，但仍然依赖人工标注提示和离散评分，不能完全替代人类专家判断。可以谨慎推断的边界还包括：WorldCast 共 320 个手工案例、8 个任务类别，覆盖范围有限；任务以关键帧序列为输出，不直接衡量逐帧物理连续性，也不评测真实环境中的闭环交互；即使最强模型在视觉目标实现等 L4 任务上仍明显偏低，说明从抽象目标反推中间步骤仍是开放问题。

展望上，论文认为把代码模拟、检查—修正循环与视觉生成结合是当前提升高层任务表现的可行方向；更根本地，需要让统一多模态生成模型具备动态规划与推理能力，把外部工具生成的中问状态变成可随时解释和使用的语义指导，而不是只当作像素级锚点。未来若能降低代码仿真的推理成本，并把这类外部推理能力内化到视觉生成模型中，将更接近真实世界状态模拟的目标。
