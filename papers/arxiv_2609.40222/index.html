LOCI: Spatial Linear Memory for Streaming World Models

来源： arXiv · HF Paper · AlphaXiv

一句话主题： 流式世界模型中的空间记忆与视角条件化回放

领域标签： 世界模型 / 流式记忆 / 线性注意力

快速理解

背景与任务： 视频世界模型需要记住并检索历史观察，以在重访视角时重现内容。

核心工作： 提出一种混合空间记忆架构，结合缓存与循环线性注意力，并利用相机几何进行条件化读写。

中文摘要

当相机重新访问先前观察过的区域时，视频世界模型应重现之前那里的内容。这既需要记住过去的观察，也需要为当前视角检索正确的观察。Key-value 缓存保留了视觉细节，但会随视频长度增长；循环记忆（recurrent memory）虽然紧凑，但会将历史压缩为固定大小的状态，因此无法再直接访问单个过去的观察。我们提出 LOCI，一种混合空间记忆架构，同时保留这两种表示。在半数 transformer 块中，主注意力保持过去观察的 key-value 缓存；在另一半中，主注意力被限制在当前块内，并由循环线性注意力记忆（recurrent linear-attention memory）补充，其读取和写入以投影相机几何为条件，因此视角同时进入记忆寻址和存储内容。循环读出流入后续由缓存支持的块中，为其查询提供累积的场景上下文。在公共 MIND memory 基准和留出的已记录轨迹上，LOCI 比代表性世界模型和同配置的全 softmax 模型更忠实地重现了重新访问的内容；在完整历史下，相同长度时其峰值内存相对全 softmax 降低约 30%。在有限保留观察库下，它能以恒定内存流式处理长视频，并在相同预算下仍比全 softmax 更忠实。

详细分析

1. 任务输入、输出、功能和边界（约100字）

任务输入是相机可控视频世界模型的一次流式生成请求：给定初始帧（或一小段历史视频）以及逐帧相机位姿/内参，模型输出与相机轨迹一致的后续视频帧。核心功能是“局部延续 + 空间持久”：当相机回到曾出现过的位置时，重建该处的场景内容。边界：本文面向已录制的第一视角轨迹，不处理真实世界交互导航；评测以位姿接近且间隔超过 8 秒的重访为事件。

2. 研究动机：要解决的问题与核心 insight（约300字）

当相机重新经过一片已观察区域，世界模型应当把“原来那里有什么”放回当前画面。这一步同时要求记忆（能访问很久以前的一帧）与检索（知道当前视角应该找哪一帧）。显式 KV 缓存能保留逐观测细节，但历史和注意力成本随视频长度增大；循环记忆固定大小、成本恒定，却把历史压成单一状态，个体观测不再可直接寻址；而直接按 FOV/pose 选择记忆，又可能丢掉以后需要的证据。

核心 insight 是让两类记忆沿特征流交互：循环记忆的读出被加到 token 特征上，后续历史 softmax 块再从这些特征生成 query。于是压缩状态负责把“现在看向哪里”的上下文带给显式历史注意力，显式 KV 负责提供被压缩掉的具体视觉内容。相机几何是关键条件：空间相关性不是按时间近邻排列，很久前朝同一表面的帧往往比刚才朝别处的帧更重要。

3. 核心贡献（约300字）

论文提出并验证了 Loci，一个同时保留固定大小循环记忆和显式历史 KV 的视频世界模型。

  • 提出混合空间记忆架构：一半模块内使用局部 softmax 注意力 + 相机条件循环读出，另一半保留可访问历史 KV 的 softmax 注意力；循环读出经门控加入特征流，后续历史注意力用这些特征构造 query，因此不需要额外 router 或辅助目标。
  • 提出视角条件循环记忆：相机投影几何既决定从状态中读什么，也决定写入状态的内容；显式遗忘按视频块推进，而不是按 token 光栅位置推进。
  • 给出完整历史密集访问与有界稀疏访问两种模式：后者用固定容量视图库控制显式存储，循环状态则保留超出库的历史压缩痕迹，从而支持恒定内存的长时间流式生成。
  • 验证上，Loci 在 MIND memory benchmark 上零样本取得比所比较模型更低的 MSE、更高的 PSNR/SSIM；在相同配方下比 full softmax 在相同有界预算高 0.89 dB；完整历史下峰值内存降低约 30%，有界模式下可 300 秒恒定内存运行。

4. 推理阶段整体流程与基模（约400字）

推理时使用的基模是 Wan2.2-TI2V-5B 视频扩散 Transformer；Loci 的实际系统把其中一部分模块改为带固定大小循环记忆的混合模块，另一部分保留显式历史注意力。基模在推理中同时承担生成、记忆读写和相机条件特征提取，没有外部工具。实际输入是初始帧（或给定历史片段）和要跟随的相机轨迹；输出是继续生成的视频。

  1. 条件编码与预填充：输入初始帧/历史片段、相机轨迹 → 条件编码模块把条件帧和相机参数变成潜变量与射线特征，并在零噪声条件下执行一次前向，初始化循环状态和显式历史缓存 → 输出可供生成块读取的初始状态、缓存和条件潜变量。
  2. 分块去噪采样：输入当前块噪声潜变量、条件特征、相机参数、已提交状态和历史缓存 → 扩散采样器在每个去噪步读取同一份已提交状态与显式历史，结合块内注意力和相机注意力逐步去噪 → 输出当前块的干净潜变量表示。
  3. 提交前向：输入当前块干净潜变量 → 提交模块对最终生成块再执行一次前向，按时间顺序更新循环状态并刷新当前块的历史缓存 → 输出下一块可读的更新状态/缓存。
  4. 记忆管理：输入已生成块和对应相机位姿 → 记忆管理器在完整历史模式下保留所有帧，在有界稀疏模式下更新近期窗口和固定容量视图库；被移出库的帧不再保留 → 输出下一块可访问的保留帧集合。
  5. 上下文反馈：输入更新后的记忆和下一段相机轨迹 → 将当前生成块追加到输出序列，并作为下一块的上下文；若有剩余轨迹则回到步骤 2，否则结束 → 输出完整生成视频。

这里的环境反馈来自已生成序列自身；若是交互式应用，用户可在块之间提供新的相机轨迹。

5. 核心方法：按论文 Method 小节总结（约600字）

论文 Method 章节原始编号为 4、4.1、4.2、4.3，以下按原顺序展开。

4 LOCI Architecture（架构）

Loci 保持 Wan 的 30 个 transformer 模块，其中 15 个为混合模块：模块内先做当前块（5 个潜帧）的局部 softmax 注意力，再从固定大小的 KDA 循环状态读取历史上下文；另外 15 个模块保持历史 softmax 注意力，直接对显式历史 KV 做 attention。所有模块都有独立的 UCPE 相机注意力分支。KDA 指 Kimi Delta Attention，即带 delta 更新规则的线性注意力。循环读出经门控加和到 token 特征后，会沿深度传到下游历史注意力模块，因此下游 query 已经携带循环记忆提供的场景上下文，不需要额外的 state-to-query adapter。

图2：Loci的核心思想。投影条件循环记忆整合历史上下文，而保留的KV保留观测级细节。循环读出更新后续历史注意力使用的特征，通过特征流连接两种表示。

图3：Loci的概念示意图。相机条件的循环状态从过去的观测中累积上下文；在重访时，其读出塑造后续历史注意力块用于关注共可见保留观测的查询。层布局见附录A.1。

4.1 Projective Camera Encoding for Recurrent Memory（循环记忆的投影相机编码）

目的是让循环记忆的内容与寻址都由相机几何决定。PRoPE 被用于循环分支：给定世界到射线的变换 \(P_i\)，查询映射 \(A_i\) 使用 \(P_i^\top\)，键和值映射 \(B_i,C_i\) 使用 \(P_i^{-1}\)，并叠加上 patch 级旋转；循环分支关闭时间 RoPE。于是状态中存储的是相机变换后的键-值关联，读取时 query 也与当前视角的投影变换比较；输出再经 \(C_i^{-1}\) 映射回原特征空间：

\[ \widehat q_i=\mathcal N(A_i q_i),\quad \widehat k_i=\mathcal N(B_i k_i),\quad \widetilde v_i=C_i v_i. \]

4.2 Chunk-Synchronous Memory Dynamics（块同步记忆动态）

目的是规定循环状态在块边界如何读写。给定上一块结束状态 \(S_{c-1}\)，当前块每个 token 先读同一状态：

\[ r_i=C_i^{-1}(d^{-1/2}S_{c-1}^\top \widehat q_i), \]

再与块内局部注意力输出做门控相加。随后 token 按 delta rule 逐 token 写入状态：

\[ \bar S^{(i)}=D_i S^{(i-1)},\quad S^{(i)}=\bar S^{(i)}+\beta_i\widehat k_i(\widetilde v_i-\bar S^{(i)\top}\widehat k_i)^\top. \]

与语言 KDA 不同，retention \(D_i\) 只在每块第一个 token 处生效，由块平均特征生成，其余位置为单位阵；所以显式遗忘按视频块推进，而 delta 修正保持 token 级。训练用 chunk-wise diffusion forcing；推理时去噪迭代只读不写，块采样完成后单独 commit forward 更新状态。

4.3 Dense and Bounded Sparse Historical Access（密集与有界稀疏历史访问）

目的是控制显式历史存储的增长。Dense 模式让历史 softmax 块关注已评测前缀中的全部帧。Bounded sparse 模式维护一个固定框架集合：

\[ \mathcal F_c=\{0\}\cup \mathcal B_c\cup \mathcal R_c\cup \mathcal U_c,\quad |\mathcal B_c|\le20,\ |\mathcal R_c|\le8,\ |\mathcal U_c|=5. \]

其中 0 是始终保留的条件帧 sink，\(\mathcal B_c\) 是全景 bank，\(\mathcal R_c\) 是最近完成帧，\(\mathcal U_c\) 是当前块。bank 按 FOV 覆盖标准从离开近期窗口的帧中选取能增加互补覆盖的帧；被丢弃的帧不存档。循环状态始终保留，因此即使 bank 移除了某些观测，其压缩痕迹仍留在状态中；显式主注意力和相机注意力共享这一保留帧集合。

6. 局限性和展望（约300字）

论文明确说明的限制包括：留出评测轨迹是 Unreal Engine 渲染的，真实世界采集未评估；所有模型绝对保真度仍低，基准平均 PSNR 低于 15 dB，因此改进应理解为相对改进；只在 Wan2.2-TI2V-5B 和 5,000 步更新短预算上验证；所有 30 个模块都保留一个显式历史的相机注意力分支，因此循环路径只减半主注意力 KV，而不是全部显式存储；训练时循环状态由带噪块特征构造，推理时由生成块提交，存在不一致；有界稀疏模式的速率优势依赖优化实现。

可以谨慎推断的限制是：视图库选择只基于 FOV 覆盖，不估计遮挡或深度，因此复杂场景中可能保留并非真正共视的帧；固定大小循环状态容量有限，极长历史中的个别物体细节仍可能被压缩；没有真实多视角视频验证，向更大模型和更多数据扩展时结论不一定保持。

展望方面，可以把深度或遮挡感知纳入视图库选择，减少训练/推理状态不一致，并在真实世界长轨迹、更大模型和更长生成时长上做进一步验证；更细粒度的通道级遗忘也是一个自然扩展方向。
