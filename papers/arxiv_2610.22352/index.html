SUPRA-TEX: 3D Generation with Super-Aligned Texture

来源： arXiv · HF Paper · AlphaXiv

一句话主题： 单图三维资产生成中的超对齐纹理生成方法

领域标签： 三维生成 / 纹理生成 / 单图重建 / PBR材质 / 扩散模型

快速理解

背景与任务： 单图3D生成需在保持参考图视觉细节的同时，为网格生成可重光照材质，但现有方法存在多视图融合伪影或细节丢失问题。

核心工作： 作者提出SUPRA-Tex，将可见材质估计、表面对齐和观察引导的3D补全解耦，利用MLLM编辑模型预测PBR图，并借助交错流Transformer在观测潜变量锚定下生成完整材质，实现可见区域高保真和不可见区域一致补全。

中文摘要

单图像3D生成旨在为给定的3D网格赋予可重新照明的材质，同时忠实保留参考图像的视觉细节。现有方法要么在融合不一致的多视角预测时引入伪影，要么通过隐式图像特征条件化难以保留精细细节。为解决这些挑战，我们提出了SUPRA-Tex，其构建原则是解耦可见材质估计、表面对齐和观测引导的3D补全。这种分工使得在有限3D数据上训练的3D生成器能够将其能力集中于保留可见证据和补全未观测表面。具体而言，我们首先训练一个基于MLLM的图像编辑模型，在参考视角下预测与光照分离的PBR贴图。然后我们将这些贴图投影到可见表面上，并用预训练的材质VAE编码器将其编码为原生观测隐变量，这些隐变量与生成目标的隐空间共享。一个交错流Transformer将这些隐变量作为固定的只读锚点，同时交替进行未观测区域和全表面的更新，以生成完整的材质隐变量。该设计实现了与参考的超对齐，在可见区域提供“所见即所得”的保真度，并在未观测表面上实现连贯补全。仅使用公开数据集训练，SUPRA-Tex在几何条件纹理化和端到端资产生成方面均达到SOTA性能，在真实世界图像上匹配甚至超越领先的商业系统。项目页面：https://supra-3d.github.io/supratex/

详细分析

1. 任务输入、输出、功能和边界（约100字）

任务输入：一张参考图像（通常包含文字、Logo、图案），以及可选网格与相机；若未提供，则由几何模型预测。输出：覆盖整个网格表面的可重光照 PBR（基于物理渲染）材质，包括反照率、金属度、粗糙度、不透明度，并可端到端生成完整 3D 资产。功能边界：要求可见区域忠实复现参考外观，未观测区域生成一致材质；但该流程不修正输入几何，也不解决单图像材质分解本身的不确定性。

2. 研究动机：要解决的问题与核心 insight（约300字）

现有单图 3D 生成主要有两条路线。多视图合成先在各视角用 2D 生成模型合成外观，再投影融合到网格上；但跨视角不一致会产生接缝、重影，混合冲突预测还会模糊文字等锐利细节。原生 3D 生成直接在三维表征上生成材质，绕过了视角融合伪影，但难以保持参考图像中的精细细节。例如 TRELLIS.2 使用 3D 材质 VAE，其图像交叉注意力没有提供像素与表面位置的显式对应；近期工作虽通过相机投影把图像特征提升到 3D，但这些条件仍是视觉特征而非材质观测。因此，3D 生成器被迫同时完成三件困难任务：从视觉特征推断 PBR 属性、把参考细节放到正确的表面位置、为未观测区域合成材质。由于 3D 训练数据本就稀缺，让单一 3D 生成器联合学习这些异质任务负担过重。核心 insight 是：把“可见材质估计”交给 2D 生成先验，用相机投影建立显式表面对齐，再把参考图像中的可见证据转换成与生成目标同潜空间的“原生材质观测”。这样，3D 生成器不需要从抽象视觉特征猜测材质，而是直接锚定在已有材质证据上，把更多容量用于未观测表面的补全，从而实现可见区域“所见即所得”和全表面一致补全。

3. 核心贡献（约300字）

论文提出并验证了 SUPRA-Tex，其贡献可归纳为三点。第一，提出“解耦可见材质估计、表面对齐、观测引导的 3D 补全”这一框架性见解：先用 2D 先验估计光照分离的 PBR 材质，再通过相机投影建立与网格的对齐，最后让 3D 生成器围绕原生观测证据完成全表面材质生成。基于该框架，仅使用公共数据集训练的 SUPRA-Tex 在给定几何的纹理生成和端到端单图 3D 生成上均达到 SOTA，并与商业系统在真实图像上可比或更好。第二，提出原生观测编码（native observation encoding）：将参考视角 PBR 估计投影到可见表面，用冻结的材质 VAE 编码器编码部分材质到生成目标潜空间，得到原生观测潜变量；同时附加覆盖率和边界距离元数据，避免零填充未观测区域带来的虚假材质值。第三，提出交错流 Transformer（interleaved flow transformer）：观测流作为固定只读的键/值锚点，生成流交替更新未观测单元和全表面，既让未观测区域获得更多更新，又保持全表面一致性；同一接口支持额外视角和 2D 编辑，无需重训生成器。

4. 推理阶段整体流程与基模（约400字）

推理时使用三个固定模型构成的流水线：Pixal3D* 几何与相机预测器（仅在未给定网格/相机时启用）、二维材质转换器（多模态大模型图像编辑模型）、由固定材质 VAE 与交错流 Transformer 组成的材质生成器。整体流程如图1所示。

图1：SUPRA-Tex 概览。左：图像到材质转换。二维材质转换器从单张参考图像估计光照分离的反照率、金属度和粗糙度贴图。中：原生观测编码。利用网格 M 和相机投影 π，将有效预测投影到可见表面体素上，并从部分 PBR 输入中省略未观测体素。冻结的材质编码器 E_mat 将这些部分 PBR 属性映射到生成目标的潜空间。这些潜变量与覆盖和边界元数据一起构成观测表示 C_o。右：观测引导的补全。以几何潜变量 G 为条件，交错流 Transformer 从噪声 Z1 生成完整材质潜变量 Z0。插图中，固定只读流 O 提供键和值，而生成流 X 交替更新无观测单元（U）和整个表面（S）上的状态。冻结解码器 D_mat 将 Z0 转换为表面 PBR 材质，并从左、右照明。

  1. 输入：参考图像 \(I\)，以及可选网格 \(\mathcal{M}\) 与相机 \(\pi\)。处理：若未提供几何，Pixal3D* 从 \(I\) 预测与参考视角对齐的网格和相机；若已提供则直接使用。输出：网格 \(\mathcal{M}\) 与相机 \(\pi\)。
  2. 输入：参考图像 \(I\)。处理：二维材质转换器一次前向输出光照分离的 \(1024\times1024\) 贴图，包括反照率、金属度、粗糙度，其中金属度/粗糙度被合并为三通道图以匹配输入格式。输出：参考视角材质估计 \(\widehat{T}_{\mathrm{2D}}\)。
  3. 输入：\(\widehat{T}_{\mathrm{2D}}\)、\(\mathcal{M}\)、\(\pi\)。处理：将前景像素投影到第一个可见表面点，通过前景掩码侵蚀和深度不连续过滤移除不可靠边界对应，再把保留材质体素化为部分表面表示 \(\mathcal{P}_o\)。输出：只含可见支撑的部分 PBR 体素。
  4. 输入：\(\mathcal{P}_o\) 与网格 \(\mathcal{M}\)。处理：固定材质 VAE 编码器把 \(\mathcal{P}_o\) 编码为原生观测潜变量 \(z^o\)；同时计算每个观测单元的覆盖率 \(\rho\) 和边界距离 \(d\)；几何 VAE 把 \(\mathcal{M}\) 编码为几何潜变量 \(G\)。输出：固定观测锚点 \(O\) 与几何条件 \(G\)。
  5. 输入：噪声潜变量 \(Z_1\)、\(O\)、\(G\)。处理：交错流 Transformer 用 25 步欧拉采样逐步去噪，每步让未观测单元和全表面交替参与更新，并始终从只读观测流读取键/值。输出：完整材质潜变量 \(Z_0\)。
  6. 输入：\(Z_0\)。处理：固定材质 VAE 解码器把完整材质潜变量映射回表面的 PBR 属性（反照率、金属度、粗糙度、不透明度）。输出：可导出/重光照的全表面 PBR 材质，或与预测几何合并后输出完整 3D 资产。

可选的反馈循环：用户提供额外的背面视图或 2D 编辑图时，可重新进入步骤 3–4，将新观测追加到同一三维坐标索引的锚点中，再继续步骤 5–6；生成模型本身不需要改变。

5. 核心方法：按论文 Method 小节总结（约600字）

3.1 Preliminaries（预备知识）

表面 PBR 与材质潜变量：在网格 \(\mathcal{M}\) 的每个表面点 \(\mathbf{p}\) 上定义反照率 \(\mathbf{a}\in\mathbb{R}^3\)、金属度 \(m\in[0,1]\)、粗糙度 \(r\in[0,1]\) 和不透明度 \(\alpha\in[0,1]\)，构成 O-Voxel 材质元组 \(T(\mathbf{p})=(\mathbf{a},m,r,\alpha)\)。独立的稀疏 VAE 将几何和材质分别压缩为几何潜变量 \(G=\{g_s\}\) 与材质潜变量 \(Z=\{z_s\}\)，坐标索引为活跃表面单元 \(s\in\mathcal{S}\)。材质编码器 \(E_{\mathrm{mat}}\) 可将部分表面属性 \(\mathcal{P}\) 编码为 \(Z\)，解码器 \(D_{\mathrm{mat}}\) 将其恢复为表面 PBR。框架还采用基于 TRELLIS.2 的 Pixal3D* 作为几何基础模型，提供参考对齐网格或相机预测。该表示体系是后续原生观测编码和生成共用的空间。

3.2 Image-to-Material Translation（图像到材质转换）

目的：把可见材质估计从 3D 生成中剥离。具体机制：训练一个基于多模态大模型（MLLM）的图像编辑模型 \(F_{\mathrm{2D}}\)，从单张照片直接预测参考视角的反照率 \(\hat{\mathbf{a}}\)、金属度 \(\hat{m}\) 和粗糙度 \(\hat{r}\)，即 \(\widehat{T}_{\mathrm{2D}}=F_{\mathrm{2D}}(I)\)。由于预训练图像 VAE 是三通道，金属度和粗糙度与一个常数通道打包成三通道图；这样既符合图像 VAE 的输入格式，也符合材质编码器的输入域。模型采用多模态 DiT 骨干和分解的模态轴联合注意力，在同一前向中联合预测反照率、金属-粗糙度和辅助法线图，以实现通道间空间对齐。训练使用 Objaverse 渲染的 RGB 与真值材质/法线对，采用固定最大噪声端点的潜流匹配目标；推理时一次前向、无需迭代去噪即可解码出 \(1024\times1024\) 材质图。该方法利用 2D 先验解耦光照与固有色，并把物理 PBR 观测而非抽象图像特征交给下游。

3.3 Native Observation Encoding（原生观测编码）

目的：把参考视角 PBR 估计转换为 3D 生成器可直接锚定的原生观测。流程分三部分。过滤表面投影：通过相机投影 \(\pi\) 将每个前景像素 \(\mathbf{u}\) 关联到网格第一个可见表面点 \(\mathbf{p}\)；推理时用前景掩码侵蚀和局部深度不连续过滤去除不可靠边界对应，保留的有效对应集合 \(\mathcal{H}_{\mathrm{valid}}\)，再体素化为部分表面表示 \(\mathcal{P}_o\)。稀疏坐标编码：\(\mathcal{P}_o\) 直接匹配固定材质 VAE 输入，\(E_{\mathrm{mat}}(\mathcal{P}_o)=\{(s,z_s^o)\mid s\in\mathcal{S}_o\}\)，得到原生观测潜变量；用稀疏坐标架构省略未观测体素，避免零填充给未见表面赋予错误材质值。空间观测元数据：覆盖率 \(\rho_s\) 表示单元内被观测表面体素的比例，边界距离 \(d_s\) 表示该单元到最近未观测区域在图上的步数；二者描述观测范围而非 2D 估计精度。最终观测表示 \(\mathcal{C}_o=\{(s,z_s^o,\rho_s,d_s)\}\)。由于锚点按 3D 坐标索引，额外视角和 2D 编辑可追加到同一接口。

3.4 Observation-Guided Completion（观测引导补全）

目的：在锚定观测证据的同时完成全表面材质潜变量。机制是交错流 Transformer。双流设计：生成流 \(X\) 覆盖全部活跃单元 \(\mathcal{S}\)，观测流 \(O\) 覆盖已观测单元 \(\mathcal{S}_o\)。输入投影为 \(X_s^{(0)}=W_{\mathrm{in}}([Z_{t,s};g_s])\)，\(O_s=W_{\mathrm{in}}([\bar{z}_s^o;g_s])+W_{\mathrm{meta}}([\rho_s;d_s])+b_o\)，其中 \(\bar{z}_s^o\) 是归一化后的观测潜变量，\(b_o\) 为可学习角色偏置。只读 KV：观测流不产生查询、不被更新，在每层作为键/值来源，相当于固定记忆。交替更新：偶数块只查询并更新未观测单元 \(\mathcal{U}=\mathcal{S}\setminus\mathcal{S}_o\)，奇数块查询并更新全表面 \(\mathcal{S}\)，从而为未观测区域分配更多状态更新，同时保持全表面交互。注意力中 \(Q_\ell\) 只来自被查询坐标，\(K/V\) 拼接观测流和生成流，使用 3D RoPE 编码相对位置。最终输出投影对全部 \(\mathcal{S}\) 预测速度。实现采用 60 个 Transformer 块、排列成 30 个交替对。

图6：交错流 Transformer。一次前向传播经过 60 个不同块，排列成 30 个交替对。固定观测流 O（橙色）提供键和值，不进行查询或状态更新。生成流 X 覆盖完整活跃潜变量单元集合 S，在已观测单元 S_o（紫色）和无任何观测的单元 U = S ∖ S_o（青色）上带有状态；下标 o 表示已观测。已观测单元仍可能包含未见表面体素。偶数索引块查询并更新 X_U；奇数索引块查询并更新整个 X。两类块都从所有 O 和 X 读取键和值，输出投影预测所有 N = |S| 个单元上的速度。源标签表示归一化、时间调制和注意力投影之前的 token。推理时，25 步欧拉采样每一步都调用一次完整的 Transformer 前向传播。

3.5 Training and Inference（训练与推理）

训练目标：生成流以完整材质潜变量 \(Z_{\mathrm{gt}}\) 为回归目标。给定噪声 \(\epsilon\) 和时间 \(t\)，定义 \(Z_t=(1-t)Z_{\mathrm{gt}}+[\sigma_{\min}+(1-\sigma_{\min})t]\epsilon\)，目标速度 \(v^=(1-\sigma_{\min})\epsilon-Z_{\mathrm{gt}}\)。损失为 \(v_\theta(Z_t,t;O,G)\) 与 \(v^\) 的 MSE，覆盖包括观测坐标在内的全部有效 token。观测表示保持固定、不随噪声路径加噪，作为条件输入；生成流在全表面上被监督恢复可见外观并补全未观测区域。推理时，先从噪声 \(Z_1\sim\mathcal{N}(0,\mathbf{I})\) 出发，用 25 步欧拉积分学习到的速度场，再反归一化并用 \(D_{\mathrm{mat}}\) 解码为全表面 PBR；可选 KV 缓存复用观测流的键/值以降低采样开销。

6. 局限性和展望（约300字）

论文明确指出的限制有四类。第一，端到端生成依赖上游预测几何，参考图与网格之间大的形状或位姿差异会把观测投影到错误表面位置，过滤只能去除部分不可靠对应，不能修正固定几何。第二，上游几何生成器可能在不可见表面产生不合理凸起结构，SUPRA-Tex 无法移除这些结构，它们仍会影响纹理补全。第三，当文字或图案跨越可见/不可见边界时，模型可能保留可见片段但无法在隐藏侧延续笔画或布局。第四，二维材质估计本身有歧义，例如把有光泽漆木判成高金属度，该误差会作为条件进入生成器并保留在最终资产中。图5给出对应案例。

图5：不完美输入和不完整观测下的局限性。(a) 正面输出在龙首周围出现局部纹样畸变；斜视角显示底层几何中存在虚假凸起。(b) 两个前斜视角显示上游几何中的虚假凸起在纹理细化后仍然可见。(c) 有光泽的漆木外观被赋予了高金属度值。由于没有材质真值，此示例说明单图像材质推断中的歧义，而非已证实的估计误差。灰度图的值从 0（黑）到 1（白）。(d) 已观测和未观测的基础色视图显示隐藏侧纹样精度下降；方框标示放大的细节。(a) 中的正面输出和 (d) 中的两个输出使用未光照基础色；(a) 中的斜视角输出和 (b) 中的两个输出使用相同中性光照下的 PBR 渲染。

可谨慎推断的展望：论文的 Oracle 实验表明，若二维材质估计更接近真值，三维纹理质量会继续提升，因此改进单图像材质分解是明确可行的方向。此外，更准确的几何与相机对齐、利用多视角观测或交互式编辑来约束可见性边界，也是论文接口支持但未作完整评估的潜在改进路径。论文没有提供校正几何后的对照，也没有对未见表面区域进行真值度量的实验，所以这些推断不应被视为已验证结论。
