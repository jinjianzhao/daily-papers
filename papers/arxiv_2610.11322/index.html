USDCraft: Geometrically Grounded Programmatic Modeling of Articulated 3D Assets for Simulation

来源： arXiv · HF Paper · AlphaXiv

一句话主题： 基于几何证据和程序化建模的铰接3D资产生成

领域标签： 铰接3D资产 / 程序化建模 / 机器人仿真

快速理解

背景与任务： 真实到仿真机器人操作需要几何保真且功能正常的铰接3D资产，但现有方法难以处理分布外或不完整网格。

核心工作： 作者提出USDCraft，利用预训练LLM编写和修订可执行程序，通过源几何分析和迭代几何检查重建仿真就绪的铰接USD资产。

中文摘要

几何保真且功能性的关节式3D资产对于真实到仿真（real-to-sim）机器人操作至关重要，因为在此场景中，仿真中训练的策略必须迁移到物理对象上。最近的基于网格的方法学习从带标注的3D资产推断关节结构，但当现实世界对象超出训练分布或其网格不完整或损坏时，部署仍然具有挑战性。为解决这些限制，我们将关节式资产重建表述为基于部分几何证据的程序化建模，并引入USDCraft——一个框架，其中预训练大语言模型（LLM）编写并修订面向仿真就绪关节式资产的可执行程序，无需任务特定训练。我们提出源几何分析，将源网格转换为区分已观测表面与未知空间的度量文本描述，以及迭代几何复核，以相同表示重新编码每个候选，使得差异指向程序编辑，而未观测区域则保持开放以待补全。视觉反馈和物理创作指导完善了建模过程，最终生成具有显式物理属性、无需手动调整即可加载到Isaac Sim中的关节式USD资产。实验在两个基准上展示了领先的关节恢复性能，并验证了USDCraft在真实-仿真-真实（real-to-sim-to-real）机器人操作中的有效性。

详细分析

1. 任务输入、输出、功能和边界（约100字）

任务是从一个源网格、一张参考图像和可选文本请求出发，重建或生成仿真就绪的铰接 3D 资产。输出是一个可执行资产程序，编译后得到含刚体部件、关节（类型/轴/原点/限位）和物理参数（质量/接触/关节摩擦）的 USD 资产，可直接载入 Isaac Sim。功能包括补全缺失几何、分离融合部件、恢复关节；边界是面向刚性铰接物体，不支持精细格栅与可变形物体动力学。

2. 研究动机：要解决的问题与核心 insight（约300字）

真实到仿真（real-to-sim）的机器人学习需要几何准确且运动正确的铰接资产。网格类方法从静态网格分割部件并预测关节，但真实扫描常有表面缺失、部件融合或网格损坏；分割只能标记现有表面，无法恢复缺失几何和功能开口，而且这类方法依赖任务专用训练，面对分布外类别时难推广。

另一类 agentic 方法用语言模型从文本/图像直接编写程序，能够补全未扫描部分并覆盖多样类别；但如果不测量真实物体，生成的尺寸和部件位置可能偏离目标实例，导致仿真策略难以迁移到真实物体。

核心 insight 是：不能只做表面分割，也不能完全依赖常识想象。USDCraft 把问题表述为“基于部分几何证据的程序化建模”：源网格提供度量约束，图像提供对象身份、可见部件和运动方式，程序提供可编辑、可补全的资产表示。把网格转成 LLM 可读的度量文本描述，再把候选资产编码到同一表示中进行差异比较，误差就能定位到程序中的具体参数。这样既保留了程序建模的灵活性，又让重建结果被真实测量约束。

3. 核心贡献（约300字）

论文的贡献可以归纳为三点。

第一，问题重构：将铰接资产重建表述为“程序化建模”，由现成 LLM 编写、编译并反复修订可执行资产程序。重建和生成共用同一程序表示，不需要为每个类别训练专用网络或任务专用微调。

第二，两个几何 grounding 机制：提出源几何分析，把源网格转成带度量的文本表示，并区分已观测表面与未知空间；提出迭代几何复核，把每个候选重新编码到同一表示，通过覆盖率、缺失/多余表面和首表面深度差异，将误差映射为具体程序编辑。视觉反馈和物理创作指导进一步补全几何诊断无法发现的外观、装配和运动问题。

第三，系统与验证：实现完整工具链，输出带 PhysX 参数的 USD 资产，可直接载入 Isaac Sim；在 USDCraft-bench 和 Lightwheel 上取得领先的重建结果；在真实抽屉、烤面包机等任务上实现较小的 sim-to-real 性能下降；同时发布 USDCraft-10k 资产生成库。

4. 推理阶段整体流程与基模（约400字）

实际使用时，系统输入是源网格、参考图像和可选文本请求；若没有源网格，则退化为从文本或图像生成资产。推理以现成 LLM（例如 GPT-5.6 Sol 或 GPT-6 Astra）为建模智能体，它不针对当前任务调整参数，而是在工具反馈下负责写出和修改资产程序。下图给出整体流程：蓝色模块只在重建时测量源几何，紫色模块在重建和生成中共享，橙色表示输出进入仿真。

Figure 2: USDCraft 总览。建模智能体细化资产程序，并选择使用哪些工具以及使用顺序。蓝色模块测量源几何体（仅在重建时），紫色模块为共享工具，橙色标记下游用途。

重建时，系统先把扫描网格和参考图像转化为两种证据：几何证据和语义部件计划。下图展示了扫描与重建的对应关系：每行内，扫描和重建结果共享同一相机和尺度。

典型一次重建的推理循环如下：

  1. 输入：源网格与参考图像。源几何分析模块把网格采样到统一度量网格，生成轴向切片和局部测量（边界、开口、凸起、内部结构）组成的文本；同时，LLM 观察参考图像，记下可见部件、连接方式和运动方式。输出：度量文本几何描述 + 部件计划。
  2. 输入：上述文本、部件计划和可选文本请求。建模 LLM 选择 CadQuery 参数化实体或 SDF 原语，编写候选资产程序，包含部件、关节、材料与 PhysX 物理参数。输出：候选程序。
  3. 输入：候选程序。编译工具执行程序，生成几何、碰撞体、质量/接触参数、关节限位并导出 USD。输出：可直接加载的候选 USD 资产和渲染图。
  4. 输入：候选 USD 与源网格。迭代几何复核把候选重新编码到与源相同的网格表示，比较覆盖率、缺失/多余表面以及六个方向的首表面深度。输出：差异清单。
  5. 输入：候选渲染图与参考图像。视觉反馈渲染候选在默认或指定关节姿态下的材料和部件颜色视图，由 LLM 判断是否缺少部件、装配不合理、外观错误或运动干涉。输出：外观与运动问题清单。
  6. 输入：差异清单与问题清单。LLM 把这些反馈定位到程序中的具体参数，进行局部编辑，回到第 3 步重新编译；直到几何复核和视觉复核都通过，输出最终 USD 资产。

5. 核心方法：按论文 Method 小节总结（约600字）

论文 Method 章节将系统设计为五个部分，下面按原文顺序说明。

3.1 Problem Setup（问题设定）

重建任务的输入是源网格、参考图像和可选文本请求；输出是可执行资产程序。程序编译后得到带有刚体部件、关节类型/轴/原点/限位以及质量和接触摩擦等物理参数的铰接资产。理想结果应满足：网格可靠观测到的地方，几何与源一致；缺失或未观测区域按图像和物体功能补全；运动方式与图中对象一致。因此，网格决定度量和放置，图像决定对象身份、可见部件与可能运动。模型通过图像观察记录这些部件、连接方式和运动方式，形成“部件计划”。生成是不含源网格的特例，跳过网格测量，直接用文本或图像条件化程序。

3.2 Source Geometry Analysis（源几何分析）

目的：解决 LLM 无法直接读网格的问题。方法由全局轴向编码和按需网格检查组成。全局编码在共享度量网格上采样源表面，得到 \(S_M\)；沿垂直轴以切片图序列加上局部度量摘要（边界、凸起、开口、内部装配）串行化。关键是 \(S_M\) 之外的单元被标记为未知而不是空或实心：扫描中的洞不代表自由空间，闭合外壳内部也不代表实体，这样模型既能补全缺失区域，又不会把未知空间误当误差。自动检测出的特征作为测量锚点，功能意义由 LLM 根据图像和对象知识判断。按需检查则让 LLM 在关注区域查询局部边界、点分布和表面朝向，用于补充低分辨率全局文本的细节。该模块为初始程序编写提供度量依据，也为后续复核提供参考网格。

3.3 Programmatic Asset Representation（程序化资产表示）

选择程序是为了让每个几何和物理参数显式出现，从而可被局部编辑，而不需要整体重新生成；程序还可以加入源网格从未观测到的部件与连接，这是纯分割无法做到的。工具方面，CadQuery 负责尺寸精确的机械零件，SDF 解析原语负责有机形状与平滑过渡；外观在同一程序中用 PBR 材质、纹理和贴花编写。物理属性直接用 PhysX 参数（质量、接触摩擦、关节限位、关节摩擦、驱动）书写，省去从通用预测形式到引擎参数的转换。编译过程派生碰撞几何，导出 USD/URDF，并打包网格与纹理。创作指导来自对 Isaac Sim 测试结果的归纳，例如保持手动机机构被动、检查正常运动序列中的关节间隙；无法从输入证据测量的属性被明确当作建模假设。

3.4 Iterative Geometric Rechecking（迭代几何复核）

目的：初始程序可能引入误差，需要在同一几何表示中比较候选与源。设 \(S_M\) 为源表面占用的网格单元，\(S_t\) 为候选在参考构型下重新编码后的占位。首先计算覆盖率与两组差异：

\[ r_t = \frac{|S_M\cap S_t|}{|S_M|}, \qquad \mathcal D_t^- = S_M\setminus S_t, \qquad \mathcal D_t^+ = S_t\setminus S_M. \]

\(r_t\) 是候选覆盖源表面比例；\(\mathcal D_t^-\) 是源表面被候选漏掉的区域，属于需要修正的直接证据；\(\mathcal D_t^+\) 是候选多出但源未知的区域，可能是错误，也可能是补全（内壁、图像支持的部件、缺失连接），因此被作为待解释问题而非统一惩罚。仅覆盖率无法区分部件放错位置和形状画错，所以再使用六个轴对齐方向的首表面深度图。对共享投影网格 \(\Omega\)，源深度 \(d_M(u)\)、候选深度 \(d_t(u)\)，残差为

\[ \delta(u) = d_t(u) - d_M(u). \]

进一步得到：

\[ b = \operatorname{median}_{u\in\Omega}\delta(u), \qquad e_{\mathrm{profile}} = Q_{0.9}\left(\{|\delta(u)-b|:u\in\Omega\}\right). \]

中位偏移 \(b\) 表示沿观察方向的前后平移；\(e_{\mathrm{profile}}\) 表示去除平移后的形状差异。论文给出的例子是把手：\(b\) 仅 \(0.64\,\text{mm}\)，\(e_{\mathrm{profile}}\) 为 \(3.41\,\text{mm}\)，说明应改轮廓而不是移动位置；若 \(b\) 大而 \(e_{\mathrm{profile}}\) 小，则说明部件整体装错位置。每次修订后重新编译并只复核受影响几何，把复核结果闭环到程序编辑。

3.5 Visual Feedback（视觉反馈）

几何复核仅比较表面，不能判断资产是否“看起来像”目标对象、运动是否合理。视觉反馈渲染候选资产，带材料和分部件颜色，视点由智能体选择，关节处于默认或指定构型；将渲染图与参考图像或文本请求比较，可以发现缺失部件、不合理装配、外观错误以及部件运动时出现的间隙或干涉问题。在无源网格的生成模式下，视觉反馈是主要的候选检查手段；在重建模式下，它与几何复核互补：几何负责度量对齐，视觉负责语义和外观。

6. 局限性和展望（约300字）

论文明确说明的限制主要有两点。第一，精细栅格或线框结构（如网球拍网线、推车铁丝框）难以保真重建，现有几何复核和程序化建模不容易表达细小支柱与镂空。第二，可变形物体仅支持已标注状态和静止几何，柔性体动力学未在 Isaac Sim 中验证，因此系统当前主要面向刚性或分段刚体铰接对象。下图展示了带有柔性部件的生成资产，其运动学展示仍需依赖带标注的连接点。

Figure 12: 带有柔性部件的生成资产，以原生材质和部件颜色显示。雨伞的运动学展示使用带标注的连接点。

可以谨慎推断的边界包括：输出中的质量、摩擦、关节摩擦等物理参数在没有直接测量时属于建模假设，若任务对接触参数非常敏感，可能仍需人工调整；源网格的尺度如果来自图像估计而非标定，绝对尺寸会带有一定误差；文本化切片编码的分辨率有限，微小零件和复杂内部机构可能丢失细节；LLM 的 token 使用和运行时间会随资产复杂度增加。

展望上，若将几何证据从规则切片扩展为分层、稀疏或局部隐式表示，并引入主动触觉或交互测量，可以改善精细结构与物理参数估计；在 Isaac Sim 中验证柔性体动力学后，系统也有望向线缆、织物和软体部件扩展。
