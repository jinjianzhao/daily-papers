MegaParts: Scaling Part-Aware 3D Object Generation to 300 Parts via Token-Efficient Autoregressive Modeling

来源： arXiv · HF Paper · AlphaXiv

一句话主题： 可控多部件3D物体生成与建模

领域标签： 三维生成 / 部件感知建模 / 自回归模型

快速理解

背景与任务： 部件感知3D生成可支持可控建模、编辑和关节化，但复杂物体的部件增多会导致令牌长度和内存成本过高。

核心工作： 作者提出MegaParts，通过高效向量量化形状分词器和结构化自回归序列建模，将部件感知3D生成扩展到最多300个部件并提升网格质量。

中文摘要

面向部件（part-aware）的 3D 物体生成对于可控建模、编辑和关节化（articulation）等图形学应用至关重要，在这些应用中，物体被表示为由语义部件组成的连贯集合。然而，现有的部件感知生成方法在处理高度复杂的物体时，扩展性并不好。随着部件数量增加，生成细致几何所需的 token 长度和内存开销会变得过于高昂。为此，我们提出 MegaParts，一种可扩展的自回归（autoregressive）3D 生成框架，通过将结构化序列建模与一种 token 高效的向量量化（vector-quantized）形状 tokenizer 结合来应对这一挑战。我们的 tokenizer 通过在高保真重建约束下最小化 token 使用量，学习用于部件级几何的离散潜变量表示，并能够根据几何复杂度进行自适应长度的 tokenization。在这一紧凑表示之上，我们训练一个大语言模型（large language model）在统一的结构化序列中生成物体边界框、部件边界框以及部件形状 token。结合高效的长上下文训练策略，我们的 token 高效表述可扩展到最多 300 个部件和最长 256k token 的序列。这显著拓展了部件感知 3D 生成的规模，同时保留了组合结构并支持细粒度的部件级控制。我们的方法在网格质量上优于基线的自回归和扩散模型，表明压缩的离散部件 token 不仅提升了可扩展性，也提高了可生成几何的保真度。这些结果表明，LLM 原生的 token 高效自回归建模是大规模部件感知 3D 生成中一种很有前景的扩散模型替代方案。项目页面见 https://expmaster.github.io/megaparts_webpage。

详细分析

MegaParts：如何让部件感知 3D 生成扩展到 300 个部件

一、任务定义：输入、输出、功能与边界

1. 输入

MegaParts 面向的是部件感知的 3D 对象生成。一个对象不再被看成单个整体，而是由多个具有独立几何形状和空间位置的部件组成，例如：

  • 钢琴：琴键、琴腿、踏板、琴盖；
  • 洗碗机：门、按钮、搁架、内部结构；
  • 控制面板：旋钮、按键、开关、外壳。

模型可以接受以下输入：

  1. 文本提示，例如“一个带有多个按钮和旋钮的控制台”；
  2. 对象级 bounding box，即整个对象在三维空间中的位置和尺度；
  3. 部件级 bounding boxes，即每个部件的位置和尺度；
  4. 这些控制信号可以单独使用，也可以组合使用。

其中，bounding box 是包围一个物体的三维轴对齐盒子。论文用它表示一个部件的中心位置和尺寸：

\[ \mathbf b^{(c)}=[\mathbf m^{(c)},\mathbf e^{(c)}], \]

其中 \(\mathbf m^{(c)}\) 是中心，\(\mathbf e^{(c)}\) 是尺度。

2. 输出

模型输出的是一个由多个部件网格组成的 3D 对象，包括：

  • 每个部件的 bounding box；
  • 每个部件的局部几何；
  • 由这些部件组装成的完整网格；
  • 显式的部件划分，因此可以单独编辑或赋予运动。

它输出的核心是几何，不包括：

  • 纹理和材质；
  • 物理属性；
  • 部件之间的运动约束；
  • 完整的语义标签体系；
  • 一定正确的功能关系，例如“这个旋钮确实控制那个部件”。

因此，MegaParts 生成的是结构化几何资产，而不是完整的游戏引擎资产或物理仿真资产。

论文展示了这种表示可以用于复杂对象生成、局部编辑和关节对象创建：

Figure 4. 细粒度的部件感知生成支持多种下游应用。左：带有详细部件分解的 articulated object 创建。右：由局部部件先验引导的二次创作。

二、论文要解决什么问题

1. 现有方法在复杂多部件对象上难以扩展

很多 3D 生成模型把一个对象编码成一个整体，或者使用扩散模型分别处理布局和局部几何。这些方法在部件数量较少时可以工作，但当对象包含几十到几百个部件时，会遇到三个具体问题：

问题一：token 数量随部件数快速增长

假设每个部件都需要 \(L\) 个离散 token，一个对象有 \(K\) 个部件，那么仅几何部分就需要大约：

\[ K L \]

个 token。

例如：

  • 50 个部件，每个部件 1024 个 token：约 51,200 个 token；
  • 300 个部件，每个部件 1024 个 token：约 307,200 个 token。

这还没有计算文本、对象布局和部件 bounding box。因此，直接给每个部件分配固定长度的高精度表示，会让上下文长度和显存迅速变大。

问题二：固定 token 预算浪费严重

不同部件的几何复杂度差异很大：

  • 一个简单圆柱形桌腿不需要很多 token；
  • 一个带孔洞、曲面和细小结构的机械部件需要更多 token。

如果所有部件都使用相同长度：

  • 预算按复杂部件设置：简单部件浪费 token；
  • 预算按简单部件设置：复杂部件丢失细节。

所以核心矛盾是：

如何在保持几何细节的同时，让每个部件只使用它实际需要的 token 数量？

问题三：长序列不仅占内存，而且关系难以处理

部件之间存在结构关系，例如：

  • 四条桌腿应当共同支撑桌面；
  • 一排琴键应当保持相似排列；
  • 旋钮、按钮和面板之间存在空间组织关系。

当所有部件的几何 token 被放入一个超长序列中，模型需要同时学习：

  1. 全局布局；
  2. 部件之间的关系；
  3. 每个部件内部的细节。

因此，长度增加不仅使计算昂贵，也使学习目标混杂。

三、核心 insight：先把几何压缩好，再让语言模型生成结构化长序列

MegaParts 的关键思想可以概括为两步：

  1. 部件级压缩：用一个支持可变长度的离散几何表示编码每个部件；
  2. 结构化自回归生成：让大型语言模型按“对象布局 → 部件布局 → 部件几何”的顺序生成。

这里的“自回归”指的是：模型每次预测下一个 token，并且可以使用之前已经生成的 token。例如：

\[ p(\mathbf s|\mathbf q) = \prod_{t=1}^{T} p(s_t|\mathbf q,s_{<t}), \]

其中 \(\mathbf q\) 是文本或 bounding box 条件，\(\mathbf s\) 是完整的结构化 3D 序列。

论文的主要贡献有三点：

  1. 提出一种token 高效的部件级 VQ-VAE，让几何表示长度可以根据部件复杂度变化；
  2. 将对象 bounding box、部件 bounding box 和部件几何 token 放入同一个结构化序列中生成；
  3. 使用长上下文训练策略，使模型可以处理最多约 300 个部件、最长约 256k token 的对象。

从整体上看，论文把“生成一个复杂 3D 对象”类比为“工厂装配”：先决定各部件在哪里，再制造每个部件，最后把它们组装起来。

四、使用的基模与整体流程

1. 几何 tokenizer：基于 Cube 架构改造的 VQ-VAE

论文没有直接把原始网格顶点和面输入语言模型，而是先训练一个几何 tokenizer。

它的基础架构来自 Cube 的 VQ-VAE，但进行了两个重要改造：

  • encoder 和 decoder 在 latent token 维度上使用因果注意力；
  • 训练时随机截断 latent 序列，使前缀 token 尽可能包含重要几何信息。

VQ-VAE 可以理解为一个“离散压缩器”：

  • encoder：把连续几何压缩成离散 token；
  • codebook：把连续向量映射到有限的离散向量集合；
  • decoder：从离散 token 恢复几何。

论文不是直接恢复三角网格，而是恢复一个有符号距离场，简称 SDF。

对于空间中的一点 \(\mathbf x\)，SDF 输出该点到表面的有符号距离：

  • 在物体内部，距离为负；
  • 在物体外部，距离为正；
  • 在表面上，距离接近 0。

之后通过 marching cubes 从 SDF 提取网格。

整体处理流程如下：

Figure 2. MegaParts 概览。我们的框架由两个阶段组成。上：我们学习一种用于部件几何的 token 高效 vector-quantized 表示。下：我们训练一个部件感知的 autoregressive 生成器，将一个 3D 对象表示为一个受文本提示及可选对象级和部件级 bounding boxes 条件约束的结构化序列。若没有 bounding boxes，模型先预测 object box 和 part boxes，随后为每个部件自回归生成局部形状 tokens。解码后的部件几何随后被组装成最终的部件感知 3D 资产。

五、关键机制一：为什么使用因果几何 tokenizer

1. 普通双向 tokenizer 的问题

在普通的双向 encoder-decoder 中，所有 latent token 可以互相访问。几何信息可能平均分散在整个序列中：

\[ [z_1,z_2,\ldots,z_M]. \]

这样，如果只保留前 \(L\) 个 token：

\[ [z_1,\ldots,z_L], \]

后面的信息被截断，可能导致整体几何突然严重损坏。

这不适合自适应长度表示，因为自适应长度要求：

前面的 token 表示粗略且重要的结构，后面的 token 再逐步补充细节。

2. 论文的做法

论文让 latent 序列上的 encoder 和 decoder 使用因果注意力。第 \(i\) 个 latent 只能访问当前位置之前的 latent，而不能访问未来 token。

同时，训练时随机选择不同的前缀长度：

\[ L\in\{2^4,2^5,\ldots,2^{12}\} = \{16,32,\ldots,4096\}. \]

模型需要在不同长度的前缀下都完成重建。这会推动模型形成一种粗到细的编码方式：

  • 早期 token：整体轮廓、主要结构；
  • 中间 token：局部形状；
  • 后期 token：细小结构和高频细节。

3. 得到什么

得到一个可以被截短的几何表示：

  • 只用少量 token，可以恢复部件的大致形状；
  • 使用更多 token，可以恢复更细的几何；
  • 不同部件可以使用不同长度。

这正是后续自适应 token 分配的基础。

六、关键机制二：如何稳定训练离散 VQ-VAE

VQ-VAE 的训练有一个特殊困难：encoder 输出需要映射到离散 codebook，而 codebook 中的离散向量也在更新。两边同时变化时，可能出现：

  • codebook 分配不稳定；
  • 某些 code 几乎从不使用；
  • decoder 不断追逐变化的离散表示；
  • 重建质量难以收敛。

论文使用了几种稳定措施。

1. 分阶段优化

先进行一段 encoder 和 decoder 的联合训练，然后交替进行：

  • encoder-only 阶段：固定 decoder，更新 encoder；
  • decoder-only 阶段：固定 encoder，更新 decoder。

这样可以减少两个模块同时改变造成的震荡。

2. 最优传输量化

论文采用 optimal-transport quantization，目的是让 batch 中的 encoder 输出更合理地分配到 codebook，避免大量样本集中使用少量 code。

3. Stochastic Gradient Shortcut

论文还使用 Cube 中的 Stochastic Gradient Shortcut，帮助梯度穿过离散量化操作。

4. 几何损失

训练目标包括四部分：

截断 SDF 重建损失

让预测的 SDF 接近真实 SDF：

\[ \mathcal L_{\text{tsdf}} = \frac{1}{N} \sum_i \left(f_\theta(\mathbf x_i;\mathbf z)-\tilde s_i\right)^2. \]

Eikonal 损失

理想的 SDF 在表面附近应满足：

\[ \|\nabla_{\mathbf x}f(\mathbf x)\|_2\approx 1. \]

因此加入：

\[ \mathcal L_{\text{eik}} = \frac{1}{|\mathcal B|} \sum_{i\in\mathcal B} (\|\mathbf g_i\|_2-1)^2. \]

它主要用于约束距离场的几何性质，而不是直接提高 token 数量。

法向一致性损失

SDF 的梯度方向应该与表面法向一致，因此约束预测法向和真实法向的夹角。

VQ 损失

让 encoder 输出靠近对应 codebook 向量，同时更新 codebook 向量靠近 encoder 输出。

最终目标为：

\[ \mathcal L = \lambda_{\text{tsdf}}\mathcal L_{\text{tsdf}} + \lambda_{\text{eik}}\mathcal L_{\text{eik}} + \lambda_{\text{normal}}\mathcal L_{\text{normal}} + \lambda_{\text{vq}}\mathcal L_{\text{vq}}. \]

七、关键机制三：如何为每个部件分配不同 token 数

1. 局部坐标和全局 bounding box 分离

对于每个部件，论文先把它归一化到局部坐标系：

\[ [-1,1]^3. \]

VQ-VAE 只负责编码这个部件的局部几何，而不负责它在整个对象中的位置和尺度。

位置和尺度单独由 bounding box 表示。这样做有两个好处：

  1. 同一个几何 tokenizer 可以处理不同位置、不同大小的部件；
  2. 几何 token 不需要浪费容量编码全局平移和缩放。

2. Rate-distortion 选择长度

对于部件 \(c\)，论文使用不同长度的前缀重建它：

\[ \hat{\mathcal M}^{(c)}_L. \]

然后计算一个目标：

\[ J^{(c)}(L) = D^{(c)}(L)+\gamma R^{(c)}(L). \]

其中：

  • \(D^{(c)}(L)\)：使用 \(L\) 个 token 后的几何误差；
  • \(R^{(c)}(L)=L/L_{\max}\)：token 使用率；
  • \(\gamma\)：压缩惩罚强度。

几何误差包括：

\[ D^{(c)}(L) = w_{\text{cd}}D_{\text{cd}}^{(c)}(L) + w_{\text{n}}D_{\text{normal}}^{(c)}(L) + w_{\text{u}}D_{\text{bbox}}^{(c)}(L). \]

具体来说：

  • Chamfer distance 衡量两个表面点集的距离；
  • normal error 衡量表面方向差异；
  • bbox 项用于避免只重建出小碎片或漂浮物。

最后选取：

\[ L_c^\star = \arg\min_{L\in\{16,32,\ldots,4096\}} J^{(c)}(L). \]

因此：

  • 简单部件可能只保留 16 或 32 个 token；
  • 复杂部件可能保留 1024、2048 或更多 token。

这不是让生成模型在每一步动态“思考需要多少 token”，而是先通过 VQ-VAE 推理阶段的 rate-distortion 评估，为训练数据确定每个部件的合适长度。生成时，模型也学习预测相应的结构和 token 序列。

Figure 3. 对于由多个部件组成的复杂对象，我们会自适应地为每个部件分配合适的 token 预算。在 VQ-VAE 的推理过程中，我们在不同 token 预算下重建部件网格，并基于精心设计的 rate distortion metric 确定最优 token 数。我们的方法能够为不同复杂度的部件提供灵活的表示容量，同时将视觉退化降到最低。

八、关键机制四：结构化自回归序列

论文将一个对象序列化为：

  1. 文本条件；
  2. 对象级 bounding box；
  3. 每个部件的 bounding box；
  4. 每个部件的 token 长度；
  5. 每个部件的形状 token。

抽象地写，可以表示为：

\[ \mathcal Y=[\mathcal P,\mathcal C], \]

其中：

\[ \mathcal P = [ \mathbf a^{(1)},\ldots,\mathbf a^{(K)} ], \qquad \mathbf a^{(c)} = [\mathbf b^{(c)},L_c^\star], \]

表示所有部件的布局和 token 长度；\(\mathcal C\) 表示所有部件的离散几何 token。

1. 为什么先生成布局

如果直接生成所有几何 token，模型需要从混合的局部细节中推断部件之间的空间关系。

MegaParts 先生成布局，相当于先回答：

  • 有多少个部件？
  • 每个部件在哪里？
  • 每个部件有多大？
  • 每个部件需要多少几何 token？

然后才生成形状。这样全局结构和局部几何在序列中有明确分工。

2. 为什么规定部件顺序

部件集合本身没有天然顺序。若同一对象在训练中每次以不同顺序出现，模型会面临额外的不确定性。

论文按照部件 bounding box 中心的空间位置排序部件，从而建立确定性的序列顺序。部件内部则按前缀顺序表示，从较粗几何逐渐过渡到细节。

3. 使用什么生成基模

论文使用 Qwen3 作为生成器，并对其进行微调。Qwen3 原本是语言模型，这里被用于预测离散化后的 3D 结构序列。

需要注意：论文并不是直接让 Qwen3 输出网格顶点和三角形，而是让它输出：

  • 数值化或离散化的 bounding box 信息；
  • 离散几何 code；
  • 序列结构控制符号。

随后由 VQ-VAE decoder 将部件 code 解码成 SDF，再用 marching cubes 提取网格。

4. 最终组装

对于第 \(c\) 个部件：

  1. 解码它的局部几何；
  2. 在局部 \([-1,1]^3\) 坐标系中提取网格；
  3. 根据生成的 bounding box 做缩放和平移；
  4. 将所有部件网格组合成完整对象。

论文使用的变换形式为：

\[ \mathbf v' = 0.5\max(\hat{\mathbf e}^{(c)}) \mathbf v + \hat{\mathbf m}^{(c)}. \]

也就是说，局部网格通过部件尺度和中心位置映射回全局空间。

  2. 生成结果具有显式部件分解；
  3. 部件 bounding box 可以控制部件布局；
  4. 细粒度部件结构有利于局部编辑和关节对象创建。

十二、方法的边界与潜在问题

1. 长上下文成本仍然很高

论文声称支持最长 256k token，但“支持”不等于成本低。

自回归模型在推理时仍然需要逐 token 生成。即使使用并行训练，推理时间、KV cache 显存和通信开销仍可能很大。论文的贡献是扩大可处理范围，而不是消除长序列的计算成本。

2. 300 个部件是规模上限，不是所有对象都能稳定生成 300 个部件

论文展示了最多 300 个部件的能力，但需要区分：

  • 最大部件数量；
  • 所有部件都高质量、语义正确；
  • 复杂部件之间关系始终一致。

正文给出了“最多 300 个部件”和“最多 256k token”的系统规模声明，但没有在给出的正文中提供完整的按部件数量分组的成功率、推理速度或显存曲线。因此，不能仅根据摘要断言模型在 300 部件上始终稳定。

3. 部件语义主要依赖数据和序列监督

模型生成了结构化部件，但论文没有描述一个完整的、独立的语义推理模块。它是否把某个几何区域识别为“按钮”“琴键”或“支架”，很大程度上取决于训练数据中的部件分解和文本标注质量。

如果数据中的部件标注：

  • 粗糙；
  • 不一致；
  • 同一部件类别划分标准不同；

那么模型可能生成几何上合理、但语义拆分不一致的结果。

4. 部件之间的关系仍然比较弱

当前表示重点是：

  • 部件自身几何；
  • 部件位置和尺度。

它没有显式表示：

  • 部件连接关系；
  • 父子层级；
  • 旋转轴；
  • 运动范围；
  • 碰撞关系；
  • 物理约束。

因此，生成一个“看起来可以活动”的多部件对象，不代表它已经是可直接用于动画或仿真的 articulation asset。

5. 只建模几何，不建模外观

论文明确指出当前方法没有统一建模：

  • 纹理；
  • 材质；
  • 语义注释；
  • 物理和功能关系。

这意味着生成的网格可能具有好的形状和部件结构，但还需要后处理才能用于高质量渲染或交互应用。

6. 实验数据和评价仍有限

主要定量实验使用 PartObjaverse-Tiny，训练数据则包含公开和私有数据。对于公开研究来说，这会带来几个限制：

  • 私有数据不一定能够复现；
  • 小型测试集未必代表真实工业级资产；
  • normal-map FID 和 CLIP 不能覆盖拓扑、材质、物理有效性等方面；
  • 部件级指标会受到部件标注策略影响。

十三、最终判断

MegaParts 最重要的贡献不是简单地“把 Transformer 变大”，而是改变了 3D 对象进入 Transformer 的方式：

不再为每个部件使用固定长度的高精度表示，而是让简单部件使用更短前缀，让复杂部件使用更长前缀；同时先生成布局，再生成局部几何。

这一设计解决了多部件 3D 生成中的主要长度浪费问题。论文的实验也形成了比较完整的证据链：

  1. VQ-VAE 重建实验说明离散几何表示质量较高；
  2. 多种 token 预算下性能逐步改善，支持前缀式粗到细表示；
  3. 消融实验说明因果注意力和分阶段优化确实重要；
  4. 文本生成和 bounding box 条件生成结果优于所比较的基线；
  5. 可视化结果展示了更细粒度的部件分解和布局控制。

但它的结论应限定为：

MegaParts 证明了“自适应长度的部件级离散表示 + 长上下文自回归模型”是扩展部件感知 3D 生成的一条有效路线。

它还没有证明：

  • 自回归模型在所有 3D 生成任务中都优于扩散模型；
  • 300 个部件下始终保持同样的质量；
  • 生成结果天然具备正确的语义、运动和物理关系；
  • 长上下文成本已经变得便宜；
  • 模型可以直接产出带材质、可动画、可仿真的完整资产。

因此，对低年级博士生而言，可以把这篇论文的核心价值概括为：

它把“多部件 3D 生成的可扩展性”主要转化成了一个表示学习和序列组织问题，并通过自适应 token 预算解决了固定长度编码带来的浪费。

这是一种有说服力的系统设计，尤其适合结构化、部件数量多的对象；但它的长期价值仍取决于能否进一步降低长序列成本，并显式建模部件之间的语义层级、连接关系和物理功能。
