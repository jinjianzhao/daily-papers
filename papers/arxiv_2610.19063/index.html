WorldMemBench: A Comprehensive Benchmark for Memory of Video World Models

来源： arXiv · HF Paper · AlphaXiv

一句话主题： 视频世界模型的世界记忆能力评测基准

领域标签： 人工智能 / 视频世界模型 / 世界记忆基准

快速理解

背景与任务： 视频世界模型需要保持历史一致，世界记忆是关键能力。

核心工作： 提出了WorldMemBench基准，包含260个测试用例，系统评估静态与动态记忆并评测9个模型。

中文摘要

随着视频模型实现更长、更逼真的交互式体验，保持世界与其历史的一致性变得至关重要。这既需要保留先前观察到的内容，也需要确保世界随时间的连贯演化。世界记忆是一项关键能力，需要与视觉保真度和视频时长一同评估。我们提出了WorldMemBench，一个用于系统评估视频世界模型中世界记忆的基准。在260个测试用例中，它通过人物身份与外观的保持、物体外观与几何的保持以及环境内容与几何的保持来评估静态记忆，并通过事件进展与状态持续性来评估动态记忆。利用受控的相机离场和多次重访轨迹，该基准将静态内容与固定的初始参照进行比较，将动态事件与预期的状态转换进行比较。它将外观与几何指标及事件特定评估相结合，并报告视频质量和相机跟随准确度作为补充性诊断指标。对九个代表性模型的评估表明，强大的静态保持能力并不意味着可靠的动态状态演化，而重复重访揭示了首次返回之后的记忆退化。人类研究支持我们的自动评估与人类判断之间的一致性。WorldMemBench为诊断记忆失败和指导持久、时间连贯的视频世界的发展提供了一个系统化的测试平台。

详细分析

1. 任务输入、输出、功能和边界（约100字）

WorldMemBench 的输入是被测视频世界模型、一个受控相机轨迹（平移或旋转）、初始观察提示/参考帧、静态目标掩码以及动态事件定义。输出是一份多维记忆诊断报告：静态记忆（人/物/环境）、动态记忆（事件推进、状态持续、最终状态、因果物理）、通用视频质量和相机跟随误差。功能是定位模型在离屏后保持内容与推进事件的能力。边界是仅覆盖 260 个设计案例、23 个语义类别、七类状态转移和固定轨迹类型，不评测自由开放探索或全新场景学习。

2. 研究动机：要解决的问题与核心 insight（约300字）

视频世界模型正在从短片段生成走向长时间、可交互的持续探索。用户反复让相机离开某个区域再回来时，世界不能“失忆”：人物的身份和衣服不能变，物体的外观和几何不能变，场景布局不能变；同时，在视野外发生的事件回到视野时应呈现合理的状态推进。传统的视觉质量指标和单次重访一致性指标无法回答“模型是否拥有世界记忆”这一问题。现有基准要么只覆盖静态重访，要么只覆盖动态状态演化，缺少同时包含精细静态记忆、离屏事件演化、多次重访和物理一致性的统一评测。

核心 insight 是：静态记忆与动态记忆不能用同一把尺子衡量。静态内容应当与固定的初始参考保持一致，衡量的是“不漂移”；动态事件则应当与预期的状态转移一致，衡量的是“会演化”。因此评测需要受控“离开—重访”轨迹来制造观测中断，用固定参考和事件检查表分别打分。更进一步，一次成功返回只能证明某个瞬间恢复成功，不能证明记忆稳定；只有连续多重重访、甚至跨轴返回，才能暴露逐渐累积的记忆衰减。静态分数高不代表动态演化好，两个维度必须分开报告。

3. 核心贡献（约300字）

论文提出并验证了 WorldMemBench 这一面向视频世界模型记忆能力的评测基准。

  • 构建了 260 个测试案例、23 个语义类别，其中 200 个静态记忆案例覆盖人类、物体、环境，60 个动态记忆案例覆盖七类视野外状态转移。
  • 设计了固定参考多重重访协议：通过平移方形回路、同轴多次旋转和跨轴旋转，把每次返回都与初始观察阶段同一参考进行比较；动态事件则采用事件门控检查表，把“事件是否开始”和“开始后是否演变得正确”解耦。
  • 评估了九个代表性视频世界模型，发现没有任何模型在四个评测维度上全面领先。HY-WorldPlay 静态记忆指标全为第一，但动态记忆总体仅 0.294、事件启动率只有 31.7%；LingBot-World 等模型动态记忆更好，说明强静态保持并不蕴含可靠动态演化。
  • 人类研究显示，六项静态指标与人类盲审的成对一致率为 78.5%–92.5%，动态总体与人类评分的 Spearman 相关系数为 0.732；多重重访实验进一步显示记忆分数随返回次数单调下降，如图 5 所示。

4. 推理阶段整体流程与基模（约400字）

实际使用 WorldMemBench 评测时，核心基模有两类：被测的视频世界模型是主生成器，例如 LingBot World v2，负责把文本、动作和相机条件转换成长视频；DA3、ViPE、MUSIQ、LAION aesthetic 和 Qwen3.8-27B 等辅助模型分别承担位姿估计、深度/质量评估和动态事件判定。整体流程是一个“输入测试案例 → 生成视频 → 提取观测 → 逐维度评分 → 输出报告”的推理闭环，不涉及任何训练过程。

Figure 1: WorldMemBench 概览。上：人类、物体、环境和动态事件上的案例覆盖。左下：受控离开-重访评估将每次返回与固定初始参考进行比较。右下：九个视频世界模型的能力概况。

实际推理步骤如下：

  1. 输入 → 被测视频世界模型 → 输出连续视频。 用户选择某个静态或动态测试案例，输入包括初始条件、目标限制和相机轨迹。世界模型按自身接口生成一段包含“初始观察—离开—返回”的连续像素帧序列。
  2. 输入 → 观测提取工具链 → 输出逐帧观测。 将视频和预设轨迹送入位姿/深度/分割工具，DA3 与 ViPE 估计相机位姿，目标检测与视频分割生成人/物掩码，深度估计器输出逐帧深度图。
  3. 输入 → 静态记忆评分模块 → 输出静态分数。 把初始参考帧、返回帧、掩码和深度送入固定参考比较流程，计算身份、外观、几何、环境可见性、深度顺序和球面重建分数。
  4. 输入 → 动态记忆评分模块 → 输出动态分数。 将视频采样帧和相机阶段范围交给 Qwen3.8-27B，先判断事件是否在初始阶段可见开始，再回答八个带参考答案的事件检查问题，得到事件推进、状态持续、最终状态与因果物理子分。
  5. 输入 → 质量与控制评分模块 → 输出诊断分数。 视频质量评分器在采样帧上计算成像与美学质量；相机跟随模块比较估计位姿与目标轨迹，输出平移和旋转相对位姿误差。
  6. 输入 → 汇总模块 → 输出最终报告。 所有分数按多重重访协议聚合，形成模型能力画像；报告反馈给用户并用于选择下一测试案例。

5. 核心方法：按论文 Method 小节总结（约600字）

论文方法由第 3 节“WorldMemBench Construction”和第 4 节“Evaluation Protocol and Metrics”组成。

3.1 Evaluation Dimensions（评估维度）

该小节确定评测的四个互补维度：静态记忆、动态记忆、通用视频质量和相机跟随。静态记忆用于考察人类、物体和环境的保持能力；动态记忆用于考察事件在视野外是否推进、状态是否持续、最终状态是否正确、因果物理是否合理；视频质量和相机跟随作为辅助诊断，帮助解释记忆分数差异是否来自渲染质量或视角偏差。

3.2 Data Composition（数据组成）

WorldMemBench 共 260 个核心案例：Human 60、Object 70、Environment 70、Dynamic Memory 60。前 200 个构成静态记忆子集，动态子集独立。静态记忆案例同时用于视频质量评估，其中 85 个适合轨迹比较的案例用于相机跟随评估。图 2 展示了内环四个类别与外环 23 个子类别的覆盖关系。

Figure 2: WorldMemBench 的组成与多样性。(a) 案例分类法，内环为人类、物体、环境和动态类别，外环为子类别。(b) 静态记忆、动态记忆、通用视频质量和相机跟随评估的案例数量。(c) 代表性案例，显示目标框和掩码、场景深度以及重访前后的事件状态。

3.3 Camera Trajectories（相机轨迹）

该小节定义受控“离开—重访”轨迹。平移轨迹保持初始观察方向，按前—右—后—左形成方形回路并回到初始位置；旋转轨迹保持相机位置不变，通过左右偏航或上下俯仰离开并返回。符号上，\(V\) 表示初始观察，\(D_i\) 为第 \(i\) 次离开，\(R_i\) 为第 \(i\) 次返回；LRLR 表示同一旋转轴重复两次周期，LRUD 表示先偏航再俯仰，从而产生跨轴返回。

Figure 3: WorldMemBench 中的评估相机轨迹。平移保持初始观看方向并完成方形回路（绿色），而旋转保持相机位置固定并进行左右偏航（橙色）或上下俯仰（蓝色）。

4.1 Multi-Revisit Protocol（多重重访协议）

该协议是静态记忆评分的基础：每次返回看到的同一目标都跟初始观察阶段的固定参考比较，而不是与上一次返回比较。目标 \(u\) 在第 \(k\) 次返回的分数为 \(s_{u,k}\)，先对全部返回平均得到目标分 \(S_u\)，再对所有目标平均得到 rollout 总分。即使某次返回没有有效观测，该次返回也计入分母，避免模型通过“不返回”取巧。

4.2 General Video Quality（通用视频质量）

该小节用 MUSIQ-SPAQ 计算成像质量、用基于 CLIP 的 LAION aesthetic 预测器计算美学质量。每个 rollout 每四帧采样一次，分数先对帧平均，再对案例平均，并归一化到 \([0,1]\)。它是记忆指标之外的独立诊断，用于区分“内容保持得好”与“画面本身更清晰”。

4.3 Camera Following（相机跟随）

相机跟随用相对位姿误差 RPE 衡量生成相机运动是否符合预设轨迹。平移 RPE 把 DA3 和 ViPE 估计的轨迹分别与目标轨迹做 Sim(3) 对齐，再比较相邻帧平移量；旋转 RPE 比较相邻旋转增量的 SO(3) 测地线角度，并按目标角度路径归一化。两个指标都是无量纲、越低越好。该模块帮助识别因视角漂移导致的假性记忆下降。

4.4 Static Memory（静态记忆）

静态记忆分为三层。Human Memory 用 ArcFace 面部嵌入比较身份，用 DINOv2 在人物掩码内的特征比较外观；Object Memory 用 DINOv2 比较物体外观，用归一化到统一画布后的掩码 IoU 比较几何轮廓；Environment Memory 用全局 DINOv2 特征比较可见内容，用深度 Spearman 相关比较相对深度顺序，并把参考与返回深度投影到球面网格、去除全局尺度偏差后计算 Spherical Reconstruction Score，同时惩罚缺失表面、多余表面和距离偏差。所有指标都采用固定参考和式 (1) 的多重重访聚合。

4.5 Dynamic Memory（动态记忆）

动态记忆的每个案例定义初始状态、动作和期望下一状态。Qwen3.8-27B 先生成候选二值问题，并固定八个带参考答案的问题，覆盖返回时进展、持续/复位、最终状态和因果物理四方面。评估时，该模型先判断事件是否在初始阶段可见开始；若未开始，则该案例所有问题记零；若已开始，再逐题判定是否与固定答案一致。由此得到门控总分，并可分解为事件启动率与条件分数，从而区分“模型根本没执行事件”和“事件开始后执行错误”。

6. 局限性和展望（约300字）

论文明确可识别的限制包括：案例规模仅 260 个、动态案例只有 60 个，无法覆盖全部开放世界；相机轨迹限定为方形平移、左右/上下旋转及其组合，不能代表自由六自由度交互；动态评估依赖 Qwen3.8-27B 的自动判断，即使有事件门控，仍可能受到语言模型偏见影响；九个模型的评测各自使用官方默认配置，比较结果会受采样参数和输出分辨率影响。人类研究中 Environment Depth 的模型级 Spearman 只有 0.301，说明该指标与人类感知的对应关系仍然有限。

可以谨慎推断的展望是：静态固定参考可能把合理的光照变化或非刚性形变误判为记忆失败；检测、分割和位姿估计的误差会向静态与相机指标传导；上下文访问实验只在一个模型上完成，结论未必跨模型成立；跨轴返回的额外退化可能与具体的相机条件编码方式有关，但论文没有给出机制解释。未来工作可扩展更长的多重重访、更自由的动作空间、更丰富的动态事件类型，并进一步研究如何用该基准指导上下文检索和长期记忆机制的设计。
