LATO.2: Factorized 3D Mesh Generation with Vertex and Topology Flow

一句话主题： 基于因子化流匹配的3D网格生成

领域标签： 三维生成 / 网格生成 / 流匹配

快速理解

背景与任务： 现有拓扑感知网格生成方法常将顶点几何与连接结构耦合建模，导致学习困难和表面破损。

核心工作： 作者提出LATO.2，将生成过程分解为顶点流和条件连接流，并借助共享体素支架实现高保真网格生成、分块生成和拓扑自适应编辑。

中文摘要

在精心设计的潜在表示上进行流匹配（Flow matching），近来已成为拓扑感知网格生成（topology-aware mesh generation）的一种强大范式。然而，现有方法在联合潜在空间中共同建模顶点和连通性，将连续的顶点几何与离散的组合结构纠缠在一起；这使流学习复杂化，并表现为顶点漂移和表面破损。我们提出 LATO.2，这是一种因子化流匹配框架，将网格生成分解为先进行顶点流，再进行以已实现顶点为条件的连通性流，且两个阶段都锚定于共享的粗体素支架。专用的变分自编码器（VAEs）支撑这两个阶段，能够以亚体素精度恢复顶点，并将离散连通性嵌入到连续潜在空间中。我们展示了这种因子化所独有的两个优势：（i）部件式生成（part-wise generation），其中支架被划分，每个部件都以完整的潜在容量进行合成，从而生成比单体潜在表示所允许的分辨率高得多的网格；（ii）拓扑自适应编辑（topology-adaptive editing），其中对第一阶段顶点的操纵会诱导出相应的连通性，而无需重新优化。实验表明，LATO.2 在几何保真度和连通性质量方面超越了最先进的拓扑感知网格生成器。

详细分析

下面按“低年级博士生、懂 Transformer/flow/VAE 基础，但不熟悉 mesh 生成”的背景来讲这篇 LATO.2: Factorized 3D Mesh Generation with Vertex and Topology Flow。

1. 任务输入、输出、功能和边界

这篇论文做的是 显式 3D mesh 生成。

一个三角网格 mesh 可以简单写成：

\[ \mathcal{M}=(\mathbf{V},\mathbf{E}) \]

其中：

  • \(\mathbf{V}=\{\mathbf{v}_i\}_{i=1}^{N}\subset \mathbb{R}^3\)：顶点集合，每个顶点是一个 3D 坐标；
  • \(\mathbf{E}\)：边集合，表示哪些顶点之间相连；
  • 由边进一步恢复面，即 triangles 或 polygonal faces。

这和 NeRF、SDF、occupancy field、3D Gaussian 等表示不同。那些方法通常先生成连续场或点/体素结构，再通过 Marching Cubes 等后处理提取 mesh。这样得到的 mesh 往往面数很高、三角形分布不规则、拓扑不干净，不像艺术家建模时会手工设计的低冗余、有结构的 mesh。

输入

LATO.2 支持多种条件输入，论文中主要包括：

  1. 图像条件

给定一张或多张渲染图，希望生成对应的 mesh。

  1. 点云或 voxel 条件

给定点云或稀疏体素结构，希望生成拓扑明确的 mesh。

  1. 用户指定的顶点数量条件

用户可以指定希望生成多少 vertices，从而控制 mesh 分辨率。

  1. 已有 vertex set，用于编辑或 stitching

比如用户已经移动了一部分顶点，或者把两个 mesh 的顶点集合并，希望系统重新预测 connectivity。

输出

输出是一个显式 mesh：

  • 顶点坐标；
  • 顶点之间的边连接；
  • 由边环检测恢复出的 faces。

也就是说，它不是输出隐式场，也不是输出 triangle soup，而是直接生成具有 connectivity 的 mesh。

功能

LATO.2 主要提供四类能力：

  1. 条件 mesh 生成

从图像、点云、voxel 等条件生成 mesh。

  1. 顶点数量可控生成

用户可以调节目标顶点数量，例如生成更粗或更密的 mesh。

  1. part-wise 高分辨率生成

将物体分成多个 part，每个 part 单独占满 latent volume 生成，再拼起来，从而突破单个整体 latent 容量限制。

  1. topology-adaptive editing

用户修改顶点位置后，不需要手写拓扑规则，也不需要重新优化整个 mesh；只需重新运行 topology flow，就能根据新的 vertex set 重新生成 connectivity。

边界

这篇论文不解决所有 3D asset 生成问题。它主要关注：

  • 几何顶点；
  • mesh connectivity；
  • faces reconstruction。

它没有完整处理：

  • UV 展开；
  • 纹理；
  • 材质；
  • rigging；
  • animation-ready semantic structure；
  • topology 对 vertex 位置的反向修正。

此外，topology decoding 默认需要检查 vertex pair，复杂度接近 \(O(N^2)\)，虽然当前规模可接受，但如果顶点数大幅增加，就需要更高效的候选边筛选策略。

2. 论文要解决的问题以及问题发生的具体原因

这篇论文的核心问题是：

如何生成既有高质量几何形状，又有干净 mesh connectivity 的显式 3D mesh？

现有方法大致有三类。

2.1 隐式或体素/场方法的问题

很多 3D 生成方法先生成 SDF、occupancy field、NeRF、3D Gaussian 或其他非 mesh 表示，再用 Marching Cubes 提取 mesh。

这种方法的问题不是“不能生成形状”，而是：

  1. connectivity 不是模型显式学习的目标

Marching Cubes 根据规则把等值面切出来，它并不知道艺术家建模中哪些边应该沿着结构线走。

  1. 三角面密集且不规则

体素分辨率决定面片分布，常常导致大量细碎 triangles。

  1. 后处理 mesh 不利于生产流程

rigging、deformation、UV、editing 都希望 mesh 有比较清晰的 edge flow 和拓扑结构。

所以这类方法几何可能好，但 topology 不一定干净。

2.2 自回归 mesh 生成的问题

另一类方法把 mesh 序列化为 token，例如：

  • 顶点坐标 token；
  • face index token；
  • traversal token；
  • edge-breaking token。

然后用 autoregressive Transformer 一个 token 一个 token 地生成。

这种方法的好处是显式建模 connectivity，但具体问题是：

  1. 序列非常长

一个 face 可能需要多个顶点索引或坐标 token。mesh 面数一大，序列长度迅速膨胀。

  1. 推理慢

自回归生成必须一步一步采样，不能像 diffusion/flow 那样高度并行。

  1. 长程拓扑一致性难

一个早期 token 错了，后面很多 faces 都可能受影响。

  1. 坐标常需要量化

顶点坐标被离散成 bins，会带来几何误差。

所以 autoregressive mesh generation 很直接，但在高分辨率 mesh 上成本高、速度慢、容易受到长序列限制。

2.3 之前 flow-based mesh 方法的问题

最近一些方法开始用 diffusion 或 flow matching 在连续 latent space 中生成 mesh。

典型代表包括：

  • PolyDiff；
  • MeshCraft；
  • MeshFlow；
  • LATO。

这些方法比 autoregressive 方法更并行，速度更快，也更适合条件控制。

但 LATO.2 指出一个关键问题：

许多已有 flow-based 方法把 vertex geometry 和 connectivity 放在同一个 latent space 里联合建模，导致连续几何信号和离散组合结构互相纠缠。

具体来说，mesh 的两个组成部分性质很不一样：

部分数学性质学习难点
顶点坐标 \(\mathbf{V}\)连续变量需要高精度空间定位
connectivity \(\mathbf{E}\)离散组合结构需要判断哪些点连边、形成哪些 faces

如果把它们塞进一个 latent 中，flow model 必须同时学习：

  • 某个 latent 维度如何控制顶点精确位置；
  • 某个 latent 维度如何控制离散边关系；
  • 两者如何共同决定最终面片。

这会带来两个具体后果：

  1. vertices 漂移

latent 中 topology 信息和 geometry 信息互相干扰，解码时顶点位置可能偏离合理 surface。

  1. broken surfaces

connectivity 错误会导致面缺失、面断裂、局部破洞或不连贯。

论文认为，这不是 flow matching 本身不适合 mesh，而是 representation 设计不合理：把性质不同的两个问题强行合成一个问题，增加了学习难度。

3. 核心 insight 与贡献

LATO.2 的核心 insight 是：

不要同时生成“顶点位置 + 拓扑连接”。先生成顶点，再在给定顶点的条件下生成拓扑。

也就是把 mesh generation 分解成：

\[ p(\mathbf{V}, \mathbf{E} \mid c) = p(\mathbf{V} \mid c) \cdot p(\mathbf{E} \mid \mathbf{V}, c) \]

其中 \(c\) 是图像、点云、voxel 等条件。

这个分解非常自然：

  1. 顶点本来就是连续坐标

适合用 VAE + flow 在连续 latent space 中生成。

  1. connectivity 在顶点已知后变成点集上的关系预测问题

如果顶点位置已经确定，那么 topology 可以看成： “在这些点之间，哪些 pair 应该连边？”

这就可以用 per-vertex latent、attention 和 pairwise edge classifier 来建模。

  1. 编辑时只改 vertex，topology 可以重新适配

如果用户移动了某些顶点，只需要重新预测 \(\mathbf{E}\mid \mathbf{V}\)，而不是重新生成整个 mesh。

论文贡献

主要贡献可以概括为四点。

贡献 1：factorized flow matching framework

LATO.2 将显式 mesh 生成分解为两个 flow：

  • V-Flow：生成 vertex latent，再解码出顶点；
  • T-Flow：在生成顶点条件下生成 topology latent，再解码出 connectivity。

二者共享一个 coarse voxel scaffold，即粗粒度稀疏体素支架，用来提供全局空间结构。

贡献 2：专门的 Vertex VAE

V-VAE 只负责 vertex geometry：

  • 输入 Vertex Displacement Field；
  • 压缩到 sparse structured latent；
  • coarse-to-fine 解码；
  • 在最细 voxel 处预测 sub-voxel offset，减少量化误差。

贡献 3：专门的 Topology VAE

T-VAE 只负责 connectivity：

  • 以每个 vertex 为 token；
  • 用 ground-truth adjacency mask 让 encoder 只能沿真实边 attention；
  • decoder 预测 pairwise edge probabilities；
  • 最后通过 loop detection 恢复 faces。

贡献 4：factorization 带来的新能力

因为 topology 是 conditioned on realized vertices 的，所以 LATO.2 支持：

  1. part-wise generation

每个 part 单独用完整 latent capacity 生成，最后再预测整体 topology。

  1. topology-adaptive editing

用户改顶点后，T-Flow 自动生成新的 connectivity。

4. 使用的基模，以及从输入到输出的整体流程

LATO.2 的基模包括：

  1. VAE

用来学习两个 latent spaces：

  • vertex latent；
  • topology latent。
  1. Flow Matching / Rectified Flow

用来在 latent space 中做生成。

  1. Sparse 3D Conv + Sparse Transformer

用来处理稀疏 voxel scaffold。

  1. PointNet

用来从 surface sampled points 提取局部几何特征。

  1. Transformer attention

用于 vertex tokens 之间的信息传播。

  1. Pairwise MLP classifier

用于判断两个 vertices 是否连边。

整体流程如下：

  1. 从输入图像、点云或 voxel 条件生成 coarse sparse structure；
  2. V-Flow 在 coarse structure 的 active cells 上采样 vertex latent；
  3. V-VAE decoder 用 coarse-to-fine sparse refinement 解码顶点；
  4. 得到 realized vertices；
  5. T-Flow 以这些 vertices 为条件，采样 topology latent；
  6. T-VAE decoder 预测 vertex pairs 的 edge probabilities；
  7. 根据预测 edge set 做 loop detection，恢复 faces；
  8. 输出完整 mesh。

Figure 2: LATO.2 pipeline 概览。LATO.2 将显式 mesh 生成分解为 vertex 和 topology 合成。V-VAE 学习稀疏 vertex latents，并以 sub-voxel offsets 重建高分辨率 vertex positions；T-VAE 通过 vertex-aware attention 学习 topology latents。推理时，V-Flow 在图像条件下生成 vertices，并可控制 vertex counts；T-Flow 在生成的 vertices 条件下预测 connectivity。

5. 每个关键机制为什么需要、具体怎么做、得到什么

下面逐个拆开。

5.1 Vertex VAE：为什么不直接回归顶点坐标？

为什么需要

mesh 顶点集合有两个麻烦：

  1. 无序性

顶点没有天然顺序。直接预测 \((x_1,y_1,z_1),...,(x_N,y_N,z_N)\) 会遇到 permutation ambiguity。

  1. 数量可变

不同 mesh 顶点数不同，无法简单固定输出维度。

因此 LATO.2 不直接回归顶点列表，而是将顶点表示成稀疏 voxel field 上的结构。

具体怎么做

论文采用 LATO 中的 Vertex Displacement Field, VDF。

大致步骤是：

  1. 在 mesh surface 上采样大量点 \(\mathcal{P}=\{\mathbf{p}_k\}\)；
  2. 每个采样点带有：
    • 点位置 \(\mathbf{p}_k\)；
    • 法向 \(\mathbf{n}_k\)；
    • displacement vector \(\mathbf{d}_k\)，指向该点所在 face 的某个 vertex；
  3. 用 PointNet 处理这些点特征；
  4. 将点特征 rasterize 到高分辨率 sparse voxel grid；
  5. 用 sparse 3D convolution 和 attention 下采样到较粗 latent grid，例如 \(64^3\)。

这样得到 vertex latent：

\[ \mathbf{z}_v = \mathcal{E}_v(\mathcal{P}) \]

decoder 再从 \(\mathbf{z}_v\) coarse-to-fine 重建 vertices。

得到什么

得到一个适合 flow model 学习的 sparse structured latent。它避免了直接处理无序可变长顶点集合的问题。

5.2 Coarse-to-fine sparse refinement：为什么需要逐级细化？

为什么需要

如果直接在 \(1024^3\) dense grid 上预测 vertex occupancy，计算量不可接受。 但如果只用低分辨率 grid，又会损失顶点位置精度。

所以需要：

  • 用粗 latent 保持计算可控；
  • 逐级 subdivision 到高分辨率；
  • 每一步只保留可能包含顶点的 voxels。

具体怎么做

V-VAE decoder 从 sparse latent 开始：

  1. 对当前 surviving voxels 做 subdivision；
  2. 预测哪些 child voxels 含有 vertex；
  3. prune 掉空 voxels；
  4. 用 sparse cross-attention 从 latent 中重新注入全局上下文；
  5. 重复直到最高分辨率。

训练时，每个 refinement level 都有 pruning loss。由于空 voxel 远多于含 vertex 的 voxel，所以用 asymmetric focal loss 缓解类别不平衡。

得到什么

模型能以稀疏方式恢复高分辨率 vertex occupancy，而不需要 dense 3D grid 的巨大成本。

5.3 Sub-voxel offset head：为什么需要预测 drift vector？

为什么需要

即使最后 voxel 分辨率达到 \(1024^3\)，如果 vertex 只能放在 voxel center，仍然有量化误差。

这类似图像检测中 bounding box 只落在 grid cell center 会不准，因此需要 offset refinement。

具体怎么做

在最细 voxel 上，decoder 不仅预测该 voxel 是否包含 vertex，还预测一个局部偏移：

\[ \{\hat{\mathbf{v}}_i,\boldsymbol{\delta}_i\} = \mathcal{D}_v(\mathbf{z}_v) \]

最终 vertex position 是：

\[ \hat{\mathbf{v}}_i+\boldsymbol{\delta}_i \]

其中 \(\hat{\mathbf{v}}_i\) 是 voxel center，\(\boldsymbol{\delta}_i\) 是连续 offset。

offset 用 MSE loss 监督。

得到什么

它显著降低 vertex reconstruction error。论文表 1 中，LATO.2 的 V-VAE 达到：

  • CD(L1)：0.0003；
  • HD：0.0069；

优于 LATO 的 CD(L1) 0.0038 和 HD 0.0083。

消融中，去掉 offset head：

  • voxel occupancy 指标几乎不变；
  • 但几何距离明显变差。

这说明 offset head 主要改善的是连续坐标精度，而不是 voxel 分类准确率。

Figure 7: V-VAE 和 T-VAE reconstruction performances 可视化。a) V-VAE vertex reconstruction 可视化。灰色 vertices 表示正确重建的 vertices，黄色 vertices 表示缺失的 ground-truth vertices，红色 vertices 表示 false positive predictions。b) offset head 对 VAE reconstruction quality 的影响；使用 offset head 时误差显著更小。c) T-VAE 的 topology reconstruction。给定原始 mesh，T-VAE 可从学习到的 topology latent 完美重建 connectivity。

5.4 T-VAE：为什么 topology 要用 per-vertex latent？

为什么需要

connectivity 是离散的：

\[ \mathbf{A}\in \{0,1\}^{N\times N} \]

其中：

\[ e_{ij}=1 \]

表示 vertex \(i\) 和 vertex \(j\) 有边相连。

直接生成 adjacency matrix 很困难，因为：

  1. \(N\) 可变；
  2. adjacency 是离散矩阵；
  3. 所有 pair 是 \(O(N^2)\)；
  4. topology 和空间几何相关，但又不是简单最近邻图。

LATO.2 的做法是： 给定 vertices 后，把 topology 信息编码到每个 vertex token 的 latent feature 中。然后通过 pairwise classifier 判断边。

具体怎么做

T-VAE encoder 输入是 realized vertex set：

\[ \hat{\mathbf{V}}=\{\hat{\mathbf{v}}_i\}_{i=1}^{N} \]

每个 vertex 做 positional encoding，然后送入 Transformer：

\[ \mathbf{z}_t = \mathcal{E}_t(\hat{\mathbf{V}}) = \mathrm{SelfAttn}^{8}(\mathrm{PosEmb}(\hat{\mathbf{V}})) \]

关键设计是：encoder 中使用 ground-truth adjacency mask。

也就是说，在训练 T-VAE encoder 时，vertex \(i\) 只能 attend：

  • 自己；
  • ground-truth 中和它相连的 vertices。

mask 写成：

\[ M_{ij}= \begin{cases} 0, & e_{ij}=1 \text{ or } i=j\\ -\infty, & \text{otherwise} \end{cases} \]

这样 ground-truth edges 并不是作为显式 edge label 输入 MLP，而是通过 attention mask 控制信息传播路径。

为什么这个设计重要

因为 encoder 唯一看到 connectivity 的方式就是 attention mask。 如果它想重建 topology，就必须把“哪些 vertex 和哪些 vertex 有连接关系”压进 per-vertex latent。

也就是说，T-VAE 被迫学习一种连续 topology latent。

decoder 怎么做

decoder 用 unmasked self-attention 得到每个 vertex 的 hidden state：

\[ \mathbf{h}=\mathcal{D}_t(\mathbf{z}_t) \]

然后对每个 vertex pair \((i,j)\) 预测 edge probability：

\[ \hat{e}_{ij} = \sigma[ \mathrm{MLP}(\mathbf{h}_i\oplus \mathbf{h}_j) + \mathrm{MLP}(\mathbf{h}_j\oplus \mathbf{h}_i) ] \]

这里同时计算 \((i,j)\) 和 \((j,i)\)，是为了保证无向边的对称性。

训练时不枚举所有 \(N^2\) pairs，而是采样候选集合 \(\mathcal{C}\)，包括：

  • true connected pairs：正样本；
  • top-\(K\) nearest neighbors：困难负样本集中在附近；
  • random pairs：容易负样本。

loss 是 asymmetric focal loss + KL。

得到什么

T-VAE 学到一个连续 topology latent space，可以从 per-vertex features 恢复 adjacency。图 7(c) 显示，在给定原始 mesh 时，T-VAE 可以很好重建 connectivity。

5.5 V-Flow：如何生成 vertices？

为什么需要

V-VAE 只是 autoencoder，只能编码和重建已有 mesh。 要从图像或点云生成新 mesh，需要学习 vertex latent 的分布。

具体怎么做

LATO.2 用 rectified flow matching 在 vertex latent space 中训练 V-Flow。

训练时，给定真实 vertex latent \(\mathbf{z}_v\)，采样高斯噪声 \(\epsilon\)，构造插值：

\[ \mathbf{z}_v^\tau = (1-\tau)\mathbf{z}_v+\tau\epsilon \]

模型学习速度场：

\[ v_\theta(\mathbf{z}_v^\tau,\tau,c) \approx \epsilon-\mathbf{z}_v \]

loss：

\[ \mathcal{L}_{\text{V-Flow}} = \mathbb{E} \left[ \left\| v_\theta(\mathbf{z}_v^\tau,\tau,\mathbf{c}_{img},\mathbf{c}_{vn}) - (\epsilon-\mathbf{z}_v) \right\|_2^2 \right] \]

条件包括：

  1. 图像特征 \(\mathbf{c}_{img}\)

用 DINO 特征，通过 cross-attention 注入。

  1. vertex count condition \(\mathbf{c}_{vn}\)

定义为：

\[ \mathbf{c}_{vn}=\log_2 N \]

经过 MLP 后和 timestep embedding 一起通过 adaLN 注入。

得到什么

推理时用户可以指定目标 vertex number。 同一个输入结构下，vertex budget 越高，生成 mesh 越密，细节越多。

Figure 9: Vertex number controlled generation。V-Flow 的显式 vertex number condition 通过指定目标 vertices 数量实现可控 mesh resolution。给定相同的 structure voxels，将 vertex budget 从 0.2 0.2 K 增加到 4 4 K，会生成逐渐更密集且具有更精细几何细节的 meshes，同时 topology flow 会自动使 connectivity 适配生成的 vertex set，并保持底层形状结构。

5.6 T-Flow：如何生成 connectivity？

为什么需要

T-VAE 可以把已有 mesh 的 connectivity 编码进 topology latent，但生成时没有 ground-truth connectivity。 所以需要一个 generative model 从 vertex set 条件下采样 topology latent。

具体怎么做

T-Flow 也是 rectified flow matching，不过作用在 topology latent \(\mathbf{z}_t\) 上。

输入条件是：

  1. realized vertices \(\hat{\mathbf{V}}\)

每个 topology token 对应一个 vertex，并带有 3D positional encoding。

  1. coarse geometric context \(\mathbf{c}_g\)

从 coarse sparse structure \(\hat{\mathcal{S}}\) 经过 3D CNN 得到。

训练目标：

\[ \mathcal{L}_{\text{T-Flow}} = \mathbb{E} \left[ \left\| v_\phi(\mathbf{z}_t^\tau,\tau,\mathbf{c}_g) - (\epsilon-\mathbf{z}_t) \right\|_2^2 \right] \]

为了支持编辑场景中没有 coarse geometric context，训练时会随机 drop \(\mathbf{c}_g\)。

此外，论文在 attention blocks 中对 query/key 使用 RMS normalization，以稳定不同 vertex 数量下的 attention。

得到什么

给定生成出来或用户编辑后的 vertices，T-Flow 可以采样 topology latent，T-VAE decoder 再预测 pairwise edges。

这就是 LATO.2 能做 topology-adaptive editing 的原因。

5.7 Loop detection：为什么还需要从 edges 恢复 faces？

T-VAE decoder 预测的是 edge probabilities，而 mesh 最终需要 faces。

论文做法是：

  1. 根据 pairwise probabilities 得到 edge set；
  2. 在 edge graph 中检测闭合环；
  3. 将合适的 loops 转换为 faces。

这一步把“边预测”转成最终 mesh faces。

论文正文没有特别展开 loop detection 的工程细节，所以这里不能过度推断。可以确定的是：LATO.2 的 topology decoder 输出的是边概率，faces 是由后续 loop detection 恢复的。

6. Factorization 带来的两个特殊能力

6.1 Topology-adaptive mesh editing

为什么 factorization 能支持 editing？

如果 geometry 和 topology 联合在一个 latent 中，那么用户一旦改了 vertex positions，原始 latent 很可能不再有效。要得到合理 topology，可能需要重新优化 latent 或设计复杂规则。

LATO.2 中 topology 是：

\[ p(\mathbf{E}\mid \mathbf{V}) \]

所以只要给一个新的 vertex set，T-Flow 就能重新生成 connectivity。

具体应用 1：mesh stitching

给定来自不同 mesh 的 vertex subsets：

  1. 将它们对齐到同一个坐标系；
  2. 合并 vertex sets；
  3. 运行 T-Flow；
  4. 在连接处自动生成新 faces。

具体应用 2：part transformation

用户旋转或平移某个 part 后：

  • 如果保留原 connectivity，过渡区域可能出现拉伸、自交；
  • 如果重新运行 T-Flow，可以重新预测连接关系，修复过渡区域。

Figure 4: Topology adaptive mesh editing。a) Mesh stitching：给定从不同 meshes 裁剪得到的 vertex sets 的并集，我们的 T-Flow 在连接处生成无缝 connectivity；新合成的 faces 以红色突出显示。b) Part transformation：在保持原始 connectivity 固定的情况下直接旋转某个 part 会导致 face stretching 和 self-intersections（伪影以红色突出显示，左），而用我们的 T-Flow 重新生成 connectivity 可得到无交叉、topologically coherent 的 mesh（红色，右）。

6.2 Part-wise generation：为什么能突破整体 latent 容量？

问题

如果整个物体只用一个固定大小 latent volume，比如 \(64^3\) sparse latent，那么它的最大顶点容量有限。

对于复杂物体，整体 latent 同时负责所有区域，局部细节可能不够。

核心做法

LATO.2 把 coarse structure 分成多个 parts。

每个 part：

  1. 单独裁剪出来；
  2. 归一化到完整 latent volume；
  3. 用完整 V-Flow/V-VAE capacity 生成；
  4. 再变换回原坐标系。

最后将所有 part 的 vertices 合并，用 T-Flow 预测 connectivity，可以：

  • 对所有 part vertices 联合预测；
  • 或逐 part 预测后 stitching。

这种做法的关键是： 每个 part 都享受完整 latent capacity，所以整体 mesh 的有效分辨率可以随 part 数增加。

Figure 3: Part-wise generation pipeline。一个可控结构规划器（Yang et al., 2025）用 part-level bounding boxes 增强由图像或点云条件生成的稀疏结构。得到的 box-aware structure 被编码为 part features，并通过 image tokens 与 part voxels 之间的 cross-attention 与 image features 融合。随后 structure decoder 预测 part-aware sparse structure，LATO.2 据此为每个 part 生成 vertices。最后，T-Flow 在所有 part vertices 的并集上联合预测 connectivity，或逐 part 预测并通过 stitching 组合结果。

得到什么

part 数越多，mesh face count 和细节越多。图 5 显示，随着 parts 增加，模型可以生成更密集、更精细的 mesh。

Figure 5: Part-wise generation and refinement。粗略结构被划分为多个 parts，每个 part 被重新缩放以占据完整 latent volume，并以完整 latent capacity 生成，从而得到明显更密集、细节更多的 meshes。随着 parts 数量增加，face count 相应增长，并呈现更精细的几何细节。

8. 局限性

论文自己也承认几个限制。

8.1 Vertex stage 的错误无法被 topology stage 修正

因为流程是：

\[ \mathbf{V} \rightarrow \mathbf{E} \]

T-Flow 只根据给定 vertices 生成 connectivity。 如果 V-Flow 已经把某些顶点放错位置，T-Flow 不会主动移动顶点。

因此 geometry error 会传递到 topology generation。

未来可能需要 joint refinement 或 iterative feedback，让 topology 反过来影响 vertex placement。

8.2 Pairwise topology decoding 是二次复杂度

默认推理会评估所有 vertex pairs：

\[ O(N^2) \]

当前顶点规模下可以接受，因为每个 pair 只经过轻量 MLP；但当顶点数非常大时，这会成为瓶颈。

未来需要：

  • sparse candidate selection；
  • local-neighborhood pruning；
  • learned edge proposal；
  • hierarchical graph decoding。

8.3 没有生成完整生产资产属性

LATO.2 关注 geometry 和 connectivity，不生成：

  • UV；
  • texture；
  • materials；
  • rigging-friendly semantic loops；
  • subdivision surface 控制结构。

所以它离完整 production-ready asset generation 还有距离。

8.4 Faces 由 loop detection 恢复，细节没有充分展开

论文明确说 edge probabilities 之后通过 loop detection 恢复 faces，但没有在正文中非常详细说明：

  • 如何筛选 loops；
  • 如何避免非流形结构；
  • 如何处理复杂 polygon；
  • 如何保证 face orientation 一致。

因此 topology quality 的一部分依赖这个后处理步骤，其泛化边界需要进一步明确。

9. 最终判断

LATO.2 的主要价值不只是“又做了一个 mesh generator”，而是提出了一个很清晰的建模分解：

\[ \text{mesh generation} = \text{vertex generation} + \text{vertex-conditioned topology generation} \]

这个分解解决了先前 unified latent 方法中的一个具体问题： 连续 vertex coordinates 和离散 connectivity 被迫共享 latent，导致 flow 同时学习两种性质差异很大的信号，从而容易出现 vertex drift 和 broken surfaces。

LATO.2 的设计让：

  • V-Flow 专注于生成高精度顶点；
  • T-Flow 专注于在已知顶点上生成连接关系；
  • V-VAE 用 sub-voxel offset 降低量化误差；
  • T-VAE 用 adjacency-masked attention 学习连续 topology latent；
  • factorization 自然支持 vertex count control、part-wise generation 和 topology-adaptive editing。

从实验看，它在论文设置下优于多个 autoregressive 和 flow-based baseline，且消融实验支持主要设计组件的必要性。

但它也不是最终解法。它仍然依赖两阶段 pipeline，vertex error 会向后传播；topology decoding 有 \(O(N^2)\) 扩展问题；完整资产属性尚未处理。

总体来说，这篇论文的核心启发是：

对于 hybrid representation，不一定要设计一个更大的 unified latent；有时更合理的是按变量性质拆分生成过程，让每个 generative model 只处理一种结构更单一的分布。
