World in World: Explore the World with World Models

来源： arXiv · HF Paper · AlphaXiv

一句话主题： 基于世界模型的视频重渲染与可控探索

领域标签： 视频世界模型 / 无需训练推理 / 相机控制重渲染

快速理解

背景与任务： 现有视频世界模型虽支持长时程交互探索，但灵活控制困难，需任务特定模块或额外训练。

核心工作： 提出World in World，一个无需训练的推理时接口，将异构控制证据转化为带相机和时间标签的状态，通过冻结模型的注意力实现可控重渲染。

中文摘要

自回归视频世界模型支持交互式、长时程探索，但灵活控制仍具挑战性。从新视角探索源视频需要生成的 rollout 与记录事件保持同步，将已观察内容置于请求的视角中，合理补全新暴露区域，并在重访时恢复先前生成的外观。现有方法通常通过任务特定模块或额外训练来满足这些需求。我们提出 World in World，一个无需训练的推理时接口，将异构控制证据转换为带相机与时间标签的干净视觉状态，并通过冻结的因果视频模型的原生自注意力读取这些状态。证据包括源视频观察、目标视角场景投影、引导新暴露主体区域补全的几何渲染，以及滚动缓存之外检索到的生成状态。每个证据源携带 token 级支持及其自身的可用性调度。对应路由器将持久点身份与几何结合以建立 token 对应关系，引导受支持的查询朝向匹配的源视频 token。逐证据注意力 CFG（EWA）随后利用同一去噪前向传递的注意力响应，独立调节每个辅助通道的额外贡献。该共享接口支持相机控制的重新渲染、长时程重访以及使用相同冻结主干网络的人体动作迁移。我们在多种视角变化下的相机控制视频重渲染任务上评估 World in World，考察感知质量、时间一致性和相机跟随精度。

详细分析

1. 任务输入、输出、功能和边界

输入为一段源视频（记录一个动态事件）与一条目标相机轨迹（含相机内参、位姿及逐帧事件时间对应），可选输入包括事件时间偏移、外观/运动编辑信号或人体运动序列。输出是与源事件保持同步、从目标视角观察的重渲染视频：内容落在请求视角、新暴露区域被合理补全、回访区域恢复先前外观。功能是为参数固定的因果视频世界模型提供训练自由的推理期视觉证据接口。边界：不修改基模参数；证据构建依赖深度估计、人体重建等外部工具；定量评估聚焦于相机控制重渲染。

2. 研究动机：要解决的问题与核心 insight

自回归视频世界模型支持交互式长时探索，但灵活控制仍是开放问题。要从新视角“探索”一段源视频中的动态世界，生成必须同时满足四点：(1) 与记录事件保持同步；(2) 把已观察内容放到请求视角的正确位置；(3) 在视角大幅变化时补全新暴露的表面；(4) 相机回访早期区域时恢复之前生成的外观与布局。现有方法通常为每个控制需求设计专用模块或额外训练，新增证据类型就要重新设计或重新训练，难以让同一个冻结基模接受异构控制信息。

核心观察是：带干净状态缓存的因果视频世界模型已经有一个共享入口——它的原生自注意力。生成时，模型把初始观测和最近已定稿的输出当作“干净视觉状态”来读，并附带相机与时间编码。因此外部控制信息也可以转换成同样的表示：带相机位姿、事件时间和有效空间区域的干净视觉状态，通过现成的注意力层被读取。这样一来，扩展世界模型控制就不再是模型适配问题，而是“视觉证据的构建与编排”问题，可拆成三个互补的子问题：构建有用的视觉证据、定位相关证据、调节证据对生成的影响强度。

3. 核心贡献

论文提出 World in World（WiW），一个训练自由的推理期视觉证据接口，用于扩展冻结因果视频世界模型的可控性。其贡献可概括为：

  • 统一接口：将源视频观测、目标视角投影、渲染几何、检索到的生成历史等异构证据统一表示为带相机、事件时间与空间有效性标签的干净视觉状态，通过基模原生自注意力读取，不需要训练或控制专用适配器。
  • 互补证据构造：源观测提供外观与动态参考；基于深度的目标视角投影提供空间布局参考；可渲染主体几何补全新暴露表面；全程历史库在滚动缓存逐出早期状态后仍可检索，支持长时回访。
  • 两种注意力机制：对应引导的注意力路由（CGAR）用持久点身份与相机几何把查询定位到匹配的源视频令牌；逐证据注意力 CFG（EWA）独立调节每个辅助证据通道的引导强度，且复用同一次去噪前向的响应，不增加网络函数评估次数。
  • 验证与下游应用：同一冻结骨干支持相机重渲染、长时回访、子弹时间、视频稳定、视频编辑、案例间 K/V 共享与人体运动迁移。在 DAVIS 与 OpenVid-1M 上，WiW 取得七个 VBench 维度平均分最高（85.192）与最低相机轨迹误差（TransError 0.0686、RotError 2.83°），图像质量指标也全面领先。

4. 推理阶段整体流程与基模

推理时使用的基模是参数固定的因果视频世界模型 LingBot-World 2.0（公开 causal-fast 版本）。其角色是“世界生成器”：把初始观测、最近已生成帧以及外部视觉证据都当作可读的干净视觉状态，通过原生自注意力按块去噪预测新视角视频，并保持与源事件的时间同步。

图2：World in World 流程概览。目标视角投影、渲染几何和检索到的历史状态提供临时视觉证据。对应引导的注意力路由将查询连接到匹配的源视频令牌，逐证据注意力 CFG 调节每个通道的额外贡献。临时证据块在每个块之后被移除；最终输出进入滚动缓存，其视觉特征在逐出后被存档。

  1. 输入：源视频与目标相机轨迹 → 证据构建模块估计源视频逐帧深度，并重建视频主体（人物）的可驱动几何状态 → 输出：源视频观测、深度图、主体几何状态，交给下一步。
  2. 输入：上述结果与目标相机 → 投影与渲染模块把源像素按深度重投影到目标视角，并把主体几何渲染到目标相机 → 输出：目标视角投影画面、可见性掩码、目标深度、几何渲染画面与支撑掩码，交给下一步。
  3. 输入：上述视觉证据、相机位姿、事件时间标签、历史库检索结果 → 证据编码模块把每种证据整理成带相机、时间和空间有效性标注的干净视觉状态，并生成可从原生自注意力读取的缓存特征 → 输出：各证据通道的缓存特征及其可用时段，交给下一步。
  4. 输入：滚动缓存中的初始观测与近期已生成帧、各证据缓存特征 → 基模去噪生成模块在当前块的自注意力中读取证据，定位匹配的源视频令牌并独立调节各证据通道的引导强度，生成当前块 → 输出：当前块的干净视频帧，交给下一步。
  5. 输入：已确定的当前块帧 → 缓存与历史库更新模块把新帧写入滚动缓存；被逐出的早期帧连同相机位姿与事件时间索引存入全程历史库 → 输出：更新后的滚动缓存与历史库，供后续块使用。
  6. 判断：若目标轨迹仍有未生成帧，回到步骤 3 继续下一块（历史库参与检索）；否则终止，输出与源事件同步、符合目标相机的重渲染视频。

5. 核心方法

3.1 Control through Visual Evidence（通过视觉证据进行控制）

目的：定义统一的证据表示，使异构控制信息都能进入冻结基模的原生自注意力。对证据通道 \(b\)，转换器 \(\Psi_b\) 把原始证据 \(E_b\) 与目标相机轨迹 \(C\) 映射为：

\[ \Psi_b(E_b; C, s) = (X_b, P_b, \omega_b, \gamma_b^{(s)}). \]

其中 \(X_b\) 为证据视觉内容；\(P_b\) 记录每帧相机内参、位姿与事件时间索引；\(\omega_{bj}\in[0,1]\) 为证据令牌 \(j\) 的空间支撑权重；\(\gamma_b^{(s)}\in\{0,1\}\) 指示该通道在去噪步 \(s\) 是否激活。将干净视觉状态连同相机与时间信息送入冻结骨干（扩散时间步设为 \(t=0\)），一次前向提取各注意力层的键/值（K/V）并缓存为干净 K/V。注意力分两类：原生块保留骨干的 18 个潜在帧状态槽（6 个源锚点、8 个近期历史状态、4 个当前块状态），源视频证据占用源锚点槽；其余证据作为临时辅助注意力块附加，当前块定稿后移除。所有块复用冻结骨干的 Q/K/V 投影，并保留原生文本与相机条件通路（含源相机 Plücker 信息）。时间关系通过旋转位置编码（RoPE）的时间坐标指定；支撑权重缩放未归一化注意力分数；激活计划控制证据参与去噪的阶段。

3.2 Target-View Scene Evidence（目标视角场景证据）

源视频观测只提供外观参考，不告诉模型内容应出现在目标图像的哪个位置；视角变化会改变投影位置与遮挡关系。为此，对目标帧 \(m\) 和时间对齐的源视角 \(r\)，用源 RGB 与 DepthCrafter 估计的深度把源像素反投影到 3D，再重投影到目标相机：

\[ (X_{r,m}^{\mathrm{proj}}, M_{r,m}^{\mathrm{proj}}, Z_{r,m}^{\mathrm{proj}}) = \operatorname{Proj}(I_{r,m}^{\mathrm{src}}, D_{r,m}^{\mathrm{src}}; C_{r,m}^{\mathrm{src}}\rightarrow C_m). \]

输出为目标视角 RGB、可见性掩码与目标相机深度。由于遮挡与局部几何误差会影响投影，论文按可见性与几何可靠性把掩码转换为令牌级支撑权重，使模型在可靠区域采纳布局参考、在不确定区域降低其影响。消融实验显示该通道对相机控制贡献最大，源相机 Plücker 条件也有助于维持跨视角结构。

图5：空间证据和相机条件化的定性消融。(a) 目标视角扭曲有助于在视角变化时保持主体结构和场景布局。(b) 源相机 Plücker 条件化通过保留源视角相机信息来帮助维持跨视角结构。

3.3 Rendered Geometry Evidence（渲染几何证据）

投影只能重排源视频中已出现的内容；大视角运动会暴露源视频未观察到的表面。为此，论文用可渲染的主体表示从目标相机产生形状与外观提议：

\[ (X_m^{\mathrm{geo}}, M_m^{\mathrm{geo}}, Z_m^{\mathrm{geo}}) = \operatorname{Render}(G_m, C_m). \]

人体实例中，\(G_m=(\mathcal{A},\Theta_m)\) 包含 LHM++ 从清晰全身裁剪重建的 Avatar \(\mathcal{A}\) 与每帧 SMPL-X 参数 \(\Theta_m\)。Avatar 与身体模型通过源视角深度对应对齐到投影场景的坐标框架与深度尺度；SMPL-X 深度用于解决主体间遮挡，并与投影场景深度比较，从而剔除主体边界附近不可靠的背景投影。渲染 RGB、支撑掩码与深度经统一接口编码，帮助模型补全新暴露的主体表面。

3.4 Retrieved Generated Evidence（检索生成证据）

投影与几何提供的是“当前目标视角”的证据；持续生成还需要此前生成内容的记忆。滚动缓存只保留最近状态，相机回访早期区域时这些状态可能已被逐出。论文维护一个全程历史库：每个被逐出的已定稿状态把逐层干净 K/V 连同相机位姿与事件时间索引归档。检索时按目标视角表面覆盖率与视角方向兼容性对历史状态排序，选择多样化的 top-\(K\) 子集，通过临时辅助注意力块读取，从而恢复滚动缓存之外的外观与布局，维持长时场景一致性。

3.5 Attention Routing and Guidance（注意力路由与引导）

证据可访问不等于查询能定位到正确位置：视角变化、动态运动与重复纹理都会使外观注意力产生歧义。

对应引导的注意力路由（CGAR）：用持久点身份与深度/相机几何建立当前查询与源视频令牌的对应。对几何匹配的查询 \(i\) 与源视频键 \(j\)，在路由注意力分数中加入对应权重的对数：

\[ \ell_{ij}^{\mathrm{corr}} = \frac{\mathbf{q}_i^{\top}\mathbf{k}_j}{\sqrt{d_h}} + \log \beta_{ij}. \]

路由响应与其他注意力块的响应联合归一化，使受支持的查询读到几何对应的源视频证据。

逐证据注意力 CFG（EWA）：不同证据通道的可靠性与作用各不相同，需要独立调节强度。令 \(\mathbf{o}_0\) 为仅原生块的响应，\(\mathbf{o}_e\) 为原生块加证据 \(e\) 的联合归一化响应。直接放大 \(\mathbf{o}_e\) 会连带放大原生生成方向的分量，因此只加强证据引入的互补方向：先去除 \(\mathbf{o}_e\) 沿 \(\mathbf{o}_0\) 的投影，用两者余弦相似度的非负部分调制残差，再用独立强度 \(g_e\) 控制修正幅度：

\[ \widetilde{\mathbf{o}}_e = \mathbf{o}_e + g_e\,\max\!\left(0,\cos(\mathbf{o}_e,\mathbf{o}_0)\right) \left[\mathbf{o}_e - \operatorname{Proj}_{\mathbf{o}_0}(\mathbf{o}_e)\right]. \]

之后把逐证据修正加到所有激活注意力块的联合响应上，并以原生响应 \(\mathbf{o}_0\) 的范数为参考约束输出幅度，防止过度引导破坏生成质量。EWA 复用同一次去噪前向中已有注意力块的输出，因此不增加网络函数评估次数。下图定性说明 CGAR 与 EWA 保持主体外观与背景结构、几何证据补全新暴露区域、历史检索恢复回访区域的作用。

图6：证据使用与可用性的定性消融。(a) 对应引导的注意力路由（CGAR）和逐证据注意力（EWA）有助于保持主体外观和背景结构。(b) 渲染的人体几何引导新暴露主体区域的补全。(c) 在早期状态已从滚动缓存中移除后，相机重新访问先前生成的区域。历史检索有助于保持早期访问期间建立的外观和布局。

6. 局限性和展望

论文正文没有设置专门的局限性章节，以下限制多数是根据方法设计谨慎推断的边界。

明确可见的限制来自证据构建对外部工具的依赖：DepthCrafter 的深度、LHM++ 的人体重建与 SMPL-X 的姿态参数误差会直接进入证据；几何证据通道目前面向人物主体，推广到任意物体需要新的可渲染表示。历史库需归档全程 K/V 与位姿，检索 top-\(K\) 限制了注意力计算量，但归档存储随时间线性增长。CGAR 的 \(\beta\) 与 EWA 的 \(g_e\) 属于推理期超参数，不同场景可能需要调节。评估主战场是 DAVIS 与 OpenVid-1M 上的相机控制重渲染；长时回访、人体运动迁移、视频编辑等应用以定性展示为主，定量覆盖有限。此外，方法的有效性受制于冻结基模自身先验的强弱，证据只能“引导”而无法完全替代基模缺失的能力。

展望方面：引入更鲁棒的通用几何估计器以降低工具误差；把几何证据推广到任意物体的可驱动表示；设计自适应的引导强度与对应权重；将该接口迁移到更多因果视频世界模型，并探索更丰富的控制证据组合，如光照、物体交互与多主体场景。
