LeWAM: End-to-End World and Action Modeling with JEPAs

来源： arXiv · HF Paper · AlphaXiv

一句话主题： 基于联合嵌入预测架构的端到端机器人视觉运动控制

领域标签： 机器人控制 / 世界模型 / 联合嵌入预测架构 / 视觉规划 / 行为克隆

快速理解

背景与任务： 现有联合嵌入预测架构（JEPA）通常先训练表示与动力学，再添加控制策略，缺乏端到端联合优化。

核心工作： 作者提出LeWAM，通过联合训练潜状态预测与动作流匹配，并施加各向同性高斯约束，实现单模型直接策略执行与高效规划，显著提升视觉规划性能与速度。

中文摘要

联合嵌入预测架构（JEPAs）无需像素重建即可学习紧凑的潜在世界模型。现有JEPA流程通常先训练视觉表征和动作条件动力学，之后再添加控制策略或求解器。我们提出LeWAM，一种用于控制的端到端JEPA，具有：（1）联合训练目标，涵盖下一潜在状态预测与动作流匹配；（2）对潜在状态施加各向同性高斯约束，使单一模型既能支持直接策略执行，也能通过其习得的潜在动力学评估采样动作来实现高效规划。与先前的视觉规划JEPA相比，LeWAM在接触丰富任务上将成功率从28.6%提升至89.7%，在长 horizon 任务上从10.9%提升至46.2%，且规划速度快32.3倍。在仿真和物理机器人的行为克隆任务中，LeWAM也与已有方法具有竞争力。可解释性分析表明，LeWAM学习了与控制相关的表征和动作分布，能有效指导测试时的规划与控制。

详细分析

1. 任务输入、输出、功能和边界（约100字）

LeWAM 的输入是无奖励的离线轨迹（像素观测 \(\bm{o}_{1:T}\) 与动作 \(\bm{a}_{1:T}\)），在视觉规划时额外提供目标图像；输出是可直接执行的动作块，或经潜在动力学评估、细化后的动作序列。其功能是联合建模潜在世界动力学与随机策略，同时支持视觉规划与行为克隆。边界：单任务、单具身、潜在空间预测而不重建像素，不依赖奖励监督。

2. 研究动机：要解决的问题与核心 insight（约300字）

现有 JEPA（联合嵌入预测架构，在潜在空间预测未来而不做像素重建）类世界模型，如 DINO-WM 与 LeWorldModel，通常分两阶段：先训练视觉表示与动作条件动力学，再外接 CEM（交叉熵法）规划器或单独训练动作预测器。这带来三个问题：(1) 表示与动力学可能保留与任务无关的观测信息，或偏向时间上持久的干扰特征，缺乏控制相关信息；(2) CEM 用宽高斯先验采样动作序列，动作维数或规划视野增长时需要的采样量急剧上升，接触切换又使局部优化困难；(3) 在冻结表示上后训练动作预测器，动作监督与表示学习脱节，也无法为规划提供有效先验。

核心洞察是：把表示、动力学与随机策略放在同一个端到端目标中联合训练——用干净动作监督状态预测，用带噪动作通过流匹配（从噪声到真实动作块回归速度场）学习动作分布，使两类监督共同塑造共享编码器；再用学到的动作分布初始化规划搜索，配合潜在动力学的迭代细化，从而同时改善控制相关信息保留、规划搜索效率与接触场景下的规划质量。

3. 核心贡献（约300字）

论文提出、构建并验证了三点贡献：

(1) 提出了第一个联合学习视觉表示、动作条件潜在动力学与随机策略的端到端 JEPA（即 LeWAM）。它用一个联合预测目标（下一潜状态预测 + 动作流匹配）和一个潜在空间各向同性高斯约束（SIGReg，一种统计分布正则化）在单一训练阶段内完成学习，参数量约 17M，无需像素重建、奖励监督或单独的后训练策略头。

(2) 提出配套的规划流程：先从学到的动作分布采样候选动作序列，再利用学到的潜在动力学对目标状态成本做迭代细化。该流程同时支持直接策略执行与高效视觉规划，把“动作先验”与“后果预测”耦合在同一个模型中。

(3) 实验验证：在十个异构仿真环境中，视觉规划平均成功率从 LeWM 的 50.9% 提升到 93.5%；接触丰富任务从 28.6% 提升到 89.7%；100 步目标偏移下从 10.9% 提升到 46.2%；规划速度比 LeWM(CEM) 快 32.3 倍。行为克隆在仿真与实体机器人上与 Diffusion Policy、\(\pi_{0.5}\) 等既有方法竞争。线性探针与消融显示其表示保留了解码性好的物理状态与动作信息，动作分布能有效引导测试时规划。

4. 推理阶段整体流程与基模（约400字）

推理基模是一个已训练好的 LeWAM 模型，由共享视觉编码器与 MoT（Mixture-of-Transformers）预测器组成。编码器负责把像素观测映射为潜在状态；预测器内部有状态分支（潜在动力学，想象动作的后果）与动作分支（随机动作生成，直接给出候选动作）。系统按“编码 → 生成候选动作 → 想象后果 → 细化 → 执行”的循环工作。

  1. 输入：当前观测历史与目标图像 → 共享视觉编码器把它们映射为历史潜变量与目标潜变量 → 输出潜变量，交给预测器。
  2. 输入：历史潜变量、目标潜变量与随机噪声 → 动作分支生成 \(N\) 个候选动作块 → 输出候选动作块，交给状态分支。
  3. 输入：每个候选块的前 \(K\) 个动作（\(K\) 为每次执行的环境步数）与当前历史潜状态 → 状态分支预测下一潜状态并更新历史 → 输出新的潜状态。
  4. 重复步骤 2–3 直到覆盖规划长度 \(L\) → 得到 \(N\) 条完整候选计划 → 交给细化环节。
  5. 输入：\(N\) 条候选计划与目标潜变量 → 系统通过潜在动力学迭代调整动作，使预测终点与目标潜变量的距离最小化，并保留每条候选的历史最优迭代 → 输出细化后的计划。
  6. 输入：细化后的候选计划 → 系统选择目标距离最小的计划，执行其前 \(K\) 个动作；环境返回新观测 → 回到步骤 1，形成滚动时域闭环。

直接控制模式是上述流程的简化路径：编码观测后，动作分支直接生成一个动作块并执行前 \(K\) 个动作，不需要目标图像、候选集与细化环节。

5. 核心方法：按论文 Method 小节总结（约600字）

3.1 End-to-End Training with LeWAM（LeWAM 的端到端训练）

该小节的目标是让编码器、动力学与策略在同一个前向中同时被监督。给定无奖励离线轨迹，\(\bm{z}_t=\operatorname{Enc}(\bm{o}_t)\) 为观测的潜表示。动力学按帧跳跃 \(K\) 预测未来潜状态 \(\bm{z}_{t+K}\)，策略建模长度为 \(C\ge K\) 的连续动作块 \(\bm{A}_{t,C}\)；可选目标上下文 \(\bm{c}_t\) 包含目标图像潜变量 \(\bm{z}_g\) 与归一化剩余视野。编码器由 ResNet-18 主干、空间 softmax 池化与 MLP 组成，同一编码器处理历史帧、未来目标帧与目标图像，参数量约 16.9M。

预测器采用 Mixture-of-Transformers（MoT）：状态分支 \(f_z\) 与动作分支 \(f_a\) 各有独立的 query/key/value 与前馈参数，但共享同一个掩码自注意力。状态查询 token 读取历史潜变量与干净动作，输出预测未来潜状态；动作分支从带噪动作块回归速度：

\[ \hat{\bm{z}}_{t+K}=f_z(\bm{q}^z_{t+K};\bm{z}_{\le t},\bm{A}_{t,K}),\qquad \hat{\bm{v}}_{t,C}=f_a(\bm{A}^{(s)}_{t,C};s,\bm{z}_{\le t},\bm{c}_t). \]

注意力掩码的设计如图 3：历史潜变量只互相注意，状态查询可读干净动作，带噪动作 token 只能读历史与自身因果前缀，防止干净动作信息泄漏给动作分支；目标 token 仅对带噪动作可见。训练目标分两部分：动力学损失 \(\mathcal{L}_{\mathrm{dyn}}\) 用 MSE 度量预测潜状态与真实潜状态的误差；动作流匹配损失 \(\mathcal{L}_{\mathrm{act}}\) 通过对动作块 \(\bm{A}_{t,C}\) 采样 \(s\sim U[0,1]\)、\(\epsilon\sim\mathcal{N}(\bm{0},\bm{I})\)，构造插值 \(\bm{A}^{(s)}_{t,C}=(1-s)\epsilon+s\bm{A}_{t,C}\)，回归目标速度 \(\bm{v}_{t,C}=\bm{A}_{t,C}-\epsilon\)。总目标为

\[ \mathcal{L}_{\mathrm{LeWAM}}=\mathcal{L}_{\mathrm{dyn}}+\mathcal{L}_{\mathrm{act}}+\lambda_{\mathrm{sig}}\mathcal{L}_{\mathrm{sig}}, \]

其中 SIGReg 用随机单位方向投影上的 Epps–Pulley 正态性统计量把潜在分布约束为各向同性高斯，防止表示坍缩并保持信息多样性。两个目标在同一前向中作用于同一共享编码器，因此表示同时受“后果预测”与“动作生成”监督。

3.2 Efficient Control with LeWAM（LeWAM 的高效控制）

该小节说明训练好的模型如何在测试时用于控制。直接控制：固定历史与目标上下文后，从高斯噪声 \(\bm{A}^{(0)}_{t,C}\sim\mathcal{N}(\bm{0},\bm{I})\) 出发，沿动作分支给出的路径积分到 \(s=1\)，生成一个长度为 \(C\) 的动作块：

\[ \frac{\mathrm{d}\bm{A}^{(s)}_{t,C}}{\mathrm{d}s}=f_a(\bm{A}^{(s)}_{t,C};s,\bm{z}_{\le t},\bm{c}_t),\qquad \hat{\bm{A}}_{t,C}=\bm{A}^{(1)}_{t,C}. \]

执行前 \(K\) 个动作后从新观测重新采样，实现闭环。

规划：先在潜在空间中交替执行“动作分支采样动作块”与“状态分支前推潜状态”，生成 \(N\) 条长度为 \(L\) 的候选计划；再以目标成本

\[ \mathcal{C}(\bm{A})=\operatorname{MSE}\!\left(\hat{\bm{z}}_{t+L}(\bm{A}),\bm{z}_g\right) \]

为准则，通过潜在动力学对候选动作做迭代更新，并用邻近惩罚限制动作偏离采样先验过大；最后在各候选的历史最优迭代中选择成本最低者执行前 \(K\) 个动作，进入滚动时域，如图 4 所示。学习到的动作分布提供了有意义的搜索起点，迭代细化在候选附近做局部改进，从而避免宽高斯先验下 CEM 的大量随机采样。

Figure 4: 使用 LeWAM 进行规划。每个 MoT 预测器阶段从高斯噪声中采样 N 个动作块，并使用每个块中的前 K 个动作（记为 A_{t,K}）将潜在动力学从步骤 t 推进到 t+K。五点曲线表示动作块（我们使用 K=5），堆叠曲线表示 N 个长度为 L 的采样计划。步骤1通过冻结的 LeWAM 动力学，使用目标状态成本对所有计划进行梯度下降细化。步骤2选择成本最低的细化迭代作为最终计划，记为 A⋆。附录 A.1 以伪算法形式给出了完整过程。

6. 局限性和展望（约300字）

论文明确说明的限制：(1) 数据覆盖有限——任务套件规模不大，混合专家演示与非专家交互，缺少对困难接触转变更广的覆盖，需更广泛的 play data 与探索；(2) 泛化未充分验证——动作条件动力学理论上可支持比纯策略更广的泛化，但尚未在新物体、新视角、新接触状态上测试；(3) 单任务、单具身——每个任务与具身单独训练，未做多任务、跨机器人或语言条件扩展；(4) 缺少分层规划——LeWAM 只提供底层规划与控制，长任务需要高层规划器分解子目标；(5) 规模有限——视觉规划模型约 17M 参数，更大模型、数据集、更大候选种群与更多细化步是明确的扩展方向。

可谨慎推断的限制：100 步目标偏移下的平均成功率（46.2%）明显低于 25 步偏移（93.5%），说明潜状态动力学的误差随视野延长而累积；实体机器人平均成功率约 33.3%，与 Diffusion Policy 相当但绝对水平不高，表明遥操作数据下的实体闭环控制仍有较大改进空间。此外，规划质量依赖潜在空间中距离度量的可区分性，SIGReg 的约束权重与目标成本的形式需针对任务调整。
