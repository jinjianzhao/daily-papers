Ring Forcing: Towards Precise Long-Term Memory for Autoregressive Video Diffusion

一句话主题： 面向长时视频生成的自回归扩散模型长期记忆增强方法

领域标签： 视频生成 / 长期记忆 / 自回归扩散模型

快速理解

背景与任务： 现有视频生成模型缺乏长期记忆，难以在长时间生成中保持物体同一性和利用远距离历史信息。

核心工作： 提出Ring Forcing框架，采用环状训练策略强制历史检索，并结合压缩和稀疏RoPE扩展记忆容量与灵活适应。

中文摘要

将视频生成扩展到长时间时长时，会暴露出一个关键瓶颈：现有模型缺乏稳健的长期记忆。这一缺陷可从两个关键方面研究：物体恒存性（object permanence），即物体重新出现时精确再现其外观的能力；以及记忆容量（memory capacity），即处理超长上下文并利用远距离历史信息的能力。稳健的长期记忆需要两者兼具：仅有物体恒存性而缺乏足够的上下文处理能力，会限制时间范围；而只有长上下文却缺乏恒存性，则无法维持物体身份的一致性。为了解决这一问题，我们提出了 Ring Forcing，一个自回归视频扩散框架，旨在稳健地构建并精确地利用长期记忆。我们的环形结构训练策略强制模型从遥远历史中进行检索，有效调和了严格遵循历史与生成多样性之间的权衡。为了扩展记忆容量，我们引入了一种压缩与时间步组合策略。在固定序列长度约束下，该方法将有效历史跨度扩展到分钟级时长，并对整个历史实现全面的感受野。此外，我们提出了一种稀疏 RoPE 机制，在充分利用预训练先验的同时，实现灵活、可扩展的记忆适配。大量实验表明，Ring Forcing 在分钟级连贯性和物体恒存性上表现优异，显著优于现有最先进方法。

详细分析

1. 任务输入、输出、功能和边界（约100字）

任务输入是文本提示（可包含期望时长），输出是一段分钟级连续视频。功能上，系统在自回归逐段生成时维护历史上下文，使物体离开画面再出现时仍能保持同一身份。当前验证边界是单镜头、480×832分辨率、15 FPS的连续长视频；有效历史范围可达约140秒，生成目标为分钟级，不覆盖多镜头场景切换。

2. 研究动机：要解决的问题与核心 insight（约300字）

长视频生成的主要瓶颈不是局部平滑，而是长期记忆。论文将长期记忆拆成两个维度：物体恒存性（object permanence）和记忆容量（memory capacity）。

物体恒存性的问题是：当物体离开视野再出现时，现有自回归视频模型经常给它换一个身份。论文指出，这不是单纯因为上下文不够长，而是训练信号有问题。标准视频数据呈现“线性叙事”偏差：物体很少在短窗口内消失再出现，模型因此学到的是从当前帧预测下一帧的短视转移概率。即使推理时提供了长历史，模型也没有动力去检索远处信息，注意力几乎不会分配给远处帧。

记忆容量的问题是：直接在帧级或token级上扩展历史会带来巨大的注意力计算开销；而压缩序列又会缩小感受野。于是出现了“要长上下文就得多花算力，要省算力就得牺牲上下文”的两难。

核心 insight 是“把未来变成历史”。训练时构造一个环形序列，把目标片段的反向副本嵌入到遥远历史中，使模型只有进行显式长程检索才能最小化生成误差。同时，利用扩散模型在不同噪声水平关注不同信息的特性，在不同时间步给模型提供不同压缩率的历史视图，从而在固定上下文预算内覆盖分钟级历史。最后，用稀疏 RoPE 把压缩后的 token 映射回物理时空坐标，保留基础模型原有的相对位置先验。

图2：预测帧对历史帧的注意力分配。(a) 标准线性训练存在短视注意力偏差，无法从遥远历史中有效检索信息。(b) 环形结构训练（我们的方法）使模型能够从过去提取更多信息，实现对历史帧的精确检索。

3. 核心贡献（约300字）

论文提出 Ring Forcing，一个面向自回归视频扩散的长期记忆框架。贡献主要有四点：

  • 环形结构训练策略：将原始视频与反向视频拼接成环，把真值目标作为“隐藏真值”嵌入历史，迫使模型显式学习长程检索。同时用随机头部裁剪防止边界信息泄漏，用随机上下文丢弃来平衡“严格遵循历史”和“开放生成多样性”。
  • 压缩与时间步组合策略：在固定 token 预算下，用时空压缩把长历史压缩成定长条件序列；并根据扩散时间步切换“全局流”和“细节流”，分别保留时间密度和空间细节，使有效历史长度扩展到分钟级。
  • 稀疏 RoPE 策略：把压缩后的历史 token 映射回原始物理时空坐标，而不是使用压缩后的离散索引，从而更充分地利用基础模型的相对时空位置先验。
  • 实验验证：在“出现-消失-重现”基准和一分钟通用生成基准上，Ring Forcing 的物体恒存性、美学质量、自然度和人类偏好都优于 LongLive、LongCat、FramePack 等基线，并且推理开销与基础模型基本一致。

4. 推理阶段整体流程与基模（约400字）

推理时使用的生成模型是 Wan2.2-T2V-A14B，角色是每一步输出一小段视频。它不直接保存所有历史，而是由 Ring Forcing 的上下文模块为它提供一段定长的压缩历史条件。

  1. 输入：用户文本提示与目标时长。系统将文本转为条件向量，并初始化空历史缓冲区。→ 输出：条件向量和初始状态。
  2. 输入：条件向量。基础模型生成第一段约1秒的视频片段。→ 输出：新片段。
  3. 输入：新片段与已有历史。上下文管理模块将片段追加到历史，并把长历史压缩成固定 token 预算的上下文，保证信息覆盖全程。→ 输出：压缩历史上下文。
  4. 输入：压缩历史上下文与条件向量。基础模型生成下一段约1秒的视频片段。→ 输出：新片段。
  5. 输入：新片段。系统将其解码并加入最终视频，再更新历史缓冲；若未达到目标时长，则回到步骤3继续循环。→ 输出：更新的历史与当前完整视频。
  6. 输入：达到目标时长后的完整视频。系统输出最终视频文件。→ 输出：用户得到分钟级视频。

5. 核心方法：按论文 Method 小节总结（约600字）

3.1 Ring-Structured Training Strategy（环形结构训练策略）

该小节解决“模型不会主动检索远处历史”的问题。设原始视频为 \(\mathcal{V}=\{v_1,v_2,\dots,v_N\}\)，论文构造闭环视频 \(\mathcal{V}_{ring}=[\mathcal{V},\mathcal{V}_{rev}]\)，其中 \(\mathcal{V}_{rev}=\{v_N,v_{N-1},\dots,v_1\}\)。目标片段严格从正向部分采样，即 \(\mathbf{x}_{tgt}=\{v_t,\dots,v_{t+L_{tgt}-1}\}\)。将环展开后，条件上下文为 \(\mathbf{C}_{full}=[\mathbf{h}_{syn},\mathbf{h}_{org}]\)，其中 \(\mathbf{h}_{syn}\) 是合成历史，内部包含反序目标片段；\(\mathbf{h}_{org}\) 是原始历史。这样模型若想精确重建目标，就必须从远处检索被反向嵌入的答案。

该设计存在一个信息泄漏捷径：合成历史的第一帧是目标片段后一帧，模型可以直接推断目标结尾，从而忽略远处答案。因此论文加入随机头部裁剪，随机去掉合成历史的前缀，同时保留反序目标。随后，又以概率 \(p_{drop}\) 随机丢弃合成历史，仅保留原始历史；否则使用环上下文。这个“Ring Context Drop”使模型既能在有答案时检索历史，也能在没有答案时自然延续，避免过度依赖合成历史。

图3：环形结构训练策略概览。我们通过将线性原始视频与其反向副本拼接来构建序列环。通过将环展开为条件序列，目标帧作为隐藏真值（Hidden GT）自然嵌入遥远历史中，这实质上迫使自回归生成器学习显式长程检索。为防止琐碎的捷径，应用随机头部裁剪（Random Head Crop）截断边界信息泄漏，同时使用随机上下文丢弃（Random Context Drop）来平衡历史遵循与生成多样性。

3.2 Compression and Timestep Composition（压缩与时间步组合）

该小节解决记忆容量问题。论文定义时空压缩算子 \(\Psi(\mathbf{Z};r_h,r_w,r_t)\)，对历史 latent 做空间和时间下采样，以满足固定 token 预算 \(\mathcal{B}_{max}\)。

简单均匀下采样会丢失高频细节。论文利用扩散模型的特性：高噪声区间主要决定全局结构与运动，低噪声区间主要决定边缘与纹理。复合条件算子 \(\Phi(\mathbf{Z}_{hist},t,\delta)\) 根据时间步 \(t\) 选择不同压缩视图：

\[ \Phi(\mathbf{Z}_{hist},t,\delta)= \begin{cases} \Psi(\mathbf{Z}_{hist};r_h^{g},r_w^{g},r_t^{g}), & t>\tau\\ \mathcal{S}\left(\Psi(\mathbf{Z}_{hist};r_h^{d},r_w^{d},r_t^{d}),\delta\right), & t\leq\tau \end{cases} \]

第一分支是“全局流”：空间压缩较大、时间采样较密，用于保留结构信息；第二分支是“细节流”：空间尽量保留、时间采样稀疏，用于保留高频细节。\(\mathcal{S}(\cdot,\delta)\) 是循环移位，通过改变 \(\delta\) 使不同采样步覆盖历史的不同时间位置。两个分支的总 token 数基本相同，因此不增加计算开销，却能让模型在生成过程中看到互补的历史视图。

3.3 Sparse RoPE Strategy（稀疏RoPE策略）

压缩会改变 token 在序列中的离散索引。如果直接用压缩后的索引做位置编码，基础模型原本学到的“相对时空尺度”感知会被破坏。论文提出稀疏 RoPE：把压缩 token 映射回原始连续时空坐标。

以目标片段为坐标原点 \((0,0,0)\)，对压缩历史中的 token \((t,h,w)\)，空间坐标映射为：

\[ \tilde{h}=h\cdot s_s+0.5\cdot(s_s-1),\quad \tilde{w}=w\cdot s_s+0.5\cdot(s_s-1) \]

时间坐标映射为：

\[ \tilde{t}=-\left((L_{hist}-1-t)\cdot s_t+0.5\cdot(s_t-1)+0.5\right) \]

其中 \(s_s\)、\(s_t\) 分别是空间和时间下采样倍数。这样历史 token 被放在物理坐标的负时间区域，且每个 token 位于其对应 patch 的中心。最后用 \((\tilde{t},\tilde{h},\tilde{w})\) 计算 3D RoPE。它使模型在不同压缩率下仍保持一致的相对时空定位，从而更有效地利用基础模型已有的位置先验。

3.4 Training Objective（训练目标）

论文使用 rectified flow 框架训练生成模型。历史 latents \(\mathbf{Z}_{hist}^{(b)}\) 由伯努利变量 \(b\sim \text{Bernoulli}(1-p_{drop})\) 控制：\(b=1\) 时使用环上下文，\(b=0\) 时使用标准上下文。条件输入为 \(\tilde{\mathbf{C}}=\Phi(\mathbf{Z}_{hist}^{(b)},t,\delta)\)。训练目标为：

\[ \mathcal{L}_{\text{Ring}}= \mathbb{E}_{t,\mathbf{Z}_{tgt},\epsilon,b,\delta} \left[ \left\|(\epsilon-\mathbf{Z}_{tgt})-G_\theta(\mathbf{Z}_t,t,\tilde{\mathbf{C}})\right\|_2^2 \right] \]

其中 \(\mathbf{Z}_t=(1-t)\mathbf{Z}_{tgt}+t\epsilon\)。这个目标把环形数据构造、上下文丢弃、时间步组合压缩统一到了同一个损失中，让模型同时学会“需要检索时检索”和“不需要检索时自由生成”。

6. 局限性和展望（约300字）

论文明确说明的限制包括：自回归生成是因果式的，微小误差仍会随极长 rollout 累积，虽然 Ring Forcing 明显抑制了身份漂移，但极长时间下仍可能出现局部失真；环式数据构造是高效的代理任务，但面对多个相似物体密集遮挡或交叉遮挡时，需要更细粒度的记忆提取；固定速率的压缩和时间步组合会丢弃部分高频信息，可能影响极小物体或快速瞬变运动。

论文展望的方向是内容自适应的记忆压缩：根据空间复杂度动态分配 token 预算，例如保留关键主体的高分辨率、压缩静态背景；同时将评估协议扩展到分钟级多镜头场景。

可以谨慎推断的限制是：当前实验主要验证单镜头连续视频，对多镜头剪辑、场景切换和复杂情节的记忆保持还没有直接证据；时间步组合中的切换阈值 \(\tau\) 依赖基础模型的噪声调度，迁移到其他扩散模型时可能需要重新选择；稀疏 RoPE 的收益建立在基础模型本身具备较强 3D 相对位置先验之上，如果基础模型缺少这种先验，增益可能会变小。
