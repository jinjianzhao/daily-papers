Motion Mamba 2.0: Autoregressive Diffusion Mamba for Long-Horizon Humanoid Control

来源： arXiv · HF Paper · AlphaXiv

一句话主题： 面向长时程人形控制，研究基于Mamba自回归扩散的可控运动生成与高效推理。

领域标签： 人工智能 / 运动生成 / 人形机器人控制

快速理解

背景与任务： 长时程实时可控运动生成对交互动画与人形机器人至关重要，但现有自回归扩散方法受限于有限历史访问和重复去噪开销。

核心工作： 作者提出基于Mamba的根-身体扩散架构Motion Mamba 2.0，引入持久内容记忆和高效执行方案，实现长时程可控运动生成与最高6.138倍推理加速。

中文摘要

长时程、实时可控的运动生成对于交互式动画和人形机器人至关重要，其中智能体必须在移动过程中响应不断变化的指令和空间目标。现有自回归扩散方法以增量方式生成运动，但有界注意力缓存限制了对久远历史的访问，而重复去噪则带来显著的推理开销。我们提出 Motion Mamba 2.0，一种基于 Mamba 的根-身体扩散架构，集成了局部注意力、可恢复循环状态和持久内容记忆（PCM），用于长时程可控运动生成。PCM 将来自 Mamba 循环状态的压缩运动历史，连同状态变化和文本条件特征，转换为可供局部注意力访问的动态更新内容槽。为实现高效推理，我们进一步开发了面向该架构的执行方案，结合 CUDA Graph 重放、融合内核和执行流简化，同时保留规范的历史更新。在重定向后的 HiPHI 上的评估表明，对最长 39.52 s 的 rollout 实现了准确的终端控制；而在 BONES Seed 和重定向后的 HumanML3D 上的短时程比较表明，该模型还保持了较强的空间控制和文本-运动匹配能力。在 RTX 4090 上，优化后的执行将完整窗口的中位延迟从 1685.35 ms 降至 276.14 ms，实现了 6.138× 的中位配对加速比，同时在测试的 rollout 中保持相同的输出和已提交状态。此外，我们在 Unitree G1 上进行了广泛的真实世界评估，展示了顺序式文本引导动作组合、富有表现力的运动，以及通过键盘和鼠标控制实现的交互式移动。

详细分析

1. 任务输入、输出、功能和边界（约100字）

输入是文本动作指令、空间目标（根轨迹/路点、选定关节位置及其生效时间）、有效性掩码，以及初始或已接受运动历史；输出是按窗口自回归生成的 Unitree G1 全身运动参考，含显式根轨迹与身体姿态，可连续拼接后交下游跟踪器。功能是长时程、实时可交互的人形运动生成；边界是只产生运动学参考，不直接保证物理平衡与接触，且固定大小记忆不保证逐字保留任意遥远历史。

2. 研究动机：要解决的问题与核心 insight（约300字）

交互式动画和人形机器人需要在运动过程中响应不断变化的文本指令和空间目标；一次性生成完整片段不适用，因为未来指令在生成开始时未必已知。自回归扩散逐窗口生成提供了在线接口，但有两个相互关联的问题：若只用有界注意力缓存，较早运动特征会被丢弃；若缓存无界，存储和计算会随序列增长。Mamba 的递归状态可以用固定大小压缩历史，但压缩状态本身不是 attention 可直接检索的 token；简单把 attention 分支和递归分支并排，并不能让递归历史被 attention 使用。另一个问题是重复去噪开销大，且去噪中间候选只是同一输出窗口的不同噪声版本，不是物理时间上已发生的运动；若把它们写入历史，会混淆采样迭代与运动时间。

论文的核心 insight 是：用局部 attention 保留近期显式特征，用可恢复的 Mamba-3 递归状态携带压缩历史，并学习持久内容记忆（PCM）把已接受递归状态摘要、状态变化和文本条件映射为动态内容槽，使 attention 可读；同时只在干净窗口被接受后统一提交缓存、递归状态和 PCM，去噪期间读取不可变历史快照，从流式语义上分离扩散迭代和物理时间。推理优化则在不改变输出和已提交状态的前提下降低重复执行开销。

图 2：使用 Motion Mamba 2.0 的交互式运动生成。文本指令指定所请求的动作，而空间控制约束根运动与选定关节位置。从左到右，各面板展示根轨迹、根路点、全身姿态序列和选定关节位置。蓝到灰色姿态表示时间推进，红色叠加层可视化轨迹、路点和关节位置。各面板展示 Viser 运动参考以及使用 SONIC 跟踪的 rollout。

3. 核心贡献（约300字）

论文提出 Motion Mamba 2.0：一种基于 Mamba 的自回归根–身体扩散架构，把局部 attention、可恢复递归状态和持久内容记忆（PCM）结合，用于长时程、实时可控的人形运动生成；PCM 将已接受压缩运动历史、状态变化和文本条件变成动态内容槽，供局部 attention 访问，而近期显式特征仍由有界缓存保留。论文构建并验证了“只提交已接受历史”的流式机制：去噪中间候选读取固定历史快照，干净窗口被接受后才更新缓存、递归状态和 PCM。论文还开发并验证了保持状态的推理优化，包括执行流简化、融合核和 CUDA Graph 重放；在 RTX 4090 上把完整窗口的中位延迟从 1685.35 ms 降到 276.14 ms，达到 6.138× 中位配对加速，并在测试 rollout 中保持输出和已提交状态相同。

实验验证包括：重定向 HiPHI 上最长 39.52 s 的终端空间控制；BONES Seed 和重定向 HumanML3D 上短时程空间控制与文本–运动匹配；Unitree G1 真实机器人上 100 次试验 94% 全任务成功、未观察到跌倒，展示顺序文本动作组合、表现性运动以及键盘/鼠标交互移动。

4. 推理阶段整体流程与基模（约400字）

实际使用时，系统以参数固定的 Motion Mamba 2.0 作为运动参考生成基模：根–身体两阶段扩散去噪器把用户条件与已接受历史变成 G1 运动参考；下游跟踪器（如 SONIC）负责把参考执行到仿真或实体机器人，不改变生成器的角色。

  1. 输入：用户文本指令、空间目标、有效性掩码、初始或已接受历史 → 条件准备黑箱把文本与空间控制整理为当前窗口条件，并冻结历史快照 → 输出条件包和只读历史快照给下一步。
  2. 输入：条件包与历史快照 → 根轨迹预测黑箱输出当前窗口的全局根轨迹候选 → 根候选及其局部运动上下文交给身体预测。
  3. 输入：根候选、噪声身体特征、空间观测与条件包 → 身体运动预测黑箱输出身体动作候选 → 与根候选组成当前去噪步的干净窗口估计。
  4. 输入：当前窗口估计与采样状态 → 扩散采样器重复根—身体预测直至完成当前窗口 → 输出一个完整干净运动窗口。
  5. 输入：完整窗口与有效性掩码 → 接受/提交模块把该窗口作为已接受历史，更新长时程记忆，并把窗口拼到连续参考流 → 输出更新后历史与连续参考。
  6. 输入：连续参考 → 下游跟踪器/动画系统执行；用户根据执行进程用键盘、鼠标或新文本指令修改空间目标/动作 → 新条件与更新后历史回到步骤1，生成下一窗口。

图 4：Motion Mamba 2.0 概览。以文本、空间控制和已接受的运动历史为条件，该框架通过两阶段扩散去噪器自回归生成运动。在每个去噪步骤，根网络预测全局轨迹，其局部特征用于条件化身体预测。两个网络都通过混合序列混合器结合 attention 和 Mamba-3。每个干净运动窗口被接受后，历史状态会更新以用于后续生成。

5. 核心方法：按论文 Method 小节总结（约600字）

IV-A Streaming Formulation and Motion Representation（流式生成建模与运动表示）

目的是把长时程生成写成窗口级条件生成，并采用显式根轨迹与压缩身体 latent 的混合表示。输出被划分为 \(C\) 个 token 的窗口，每个 token 对应 \(P\) 帧；第 \(t\) 个窗口的条件包括文本指令 \(s_t\)、空间目标 \(\mathbf{g}_t\)、有效性掩码 \(\mathbf{v}_t\)，以及由已接受前缀构造的记忆 \(\mathcal{M}_{t-1}\)。条件分布按窗口分解： \[ p_\theta(\mathbf{x}_{0:T}\mid\mathbf{s},\mathbf{g},\mathbf{v}) =\prod_{t=0}^{T}p_\theta(\mathbf{x}_t\mid s_t,\mathbf{g}_t,\mathbf{v}_t;\mathcal{M}_{t-1}). \] 根表示每帧位置与朝向，身体表示由关节旋转、位置、速度、接触等经冻结运动 codec 编码为 latent；token 拼接根 patch 与身体 latent。坐标在当前规范帧中表达，累计平移单独保留以恢复世界轨迹。该小节定义了后续去噪器的输入输出、历史边界和空间控制接口。

IV-B Recurrent Root–Body Denoising（递归式根–身体去噪）

目的是在每个扩散步骤先预测全局根，再在根条件下预测身体，使轨迹直接受空间控制，同时让身体适应根运动。根网络和身体网络分别有参数与层间记忆；根输入包含噪声混合特征与对齐控制，有效根观测替换对应噪声坐标，未来目标嵌入在目标位置并用掩码屏蔽空项；身体输入拼接预测根的局部特征、噪声身体 latent 和对齐观测： \[ \widehat{\mathbf{r}}_{t,0}=\mathcal{F}^r_\theta(\mathbf{u}^r_{t,\tau},\mathbf{c}_{t,\tau};\mathcal{M}^r_{t-1}),\quad \widehat{\mathbf{b}}_{t,0}=\mathcal{F}^b_\theta(\mathbf{u}^b_{t,\tau},\mathbf{c}_{t,\tau};\mathcal{M}^b_{t-1}). \] 每个去噪步根预测刷新后再算身体预测。序列混合层中，attention 检索近期特征，Mamba 从已接受前缀恢复状态，二者输出由逐层学习门控相加；PCM 只增强 attention 路径，不替代递归分支。采用的 Mamba-3 单输入单输出扫描可恢复，其状态包含递归矩阵、累计相位、前一步状态输入和值向量；核心递推形式为 \[ \mathbf{H}_i=\alpha_i\mathbf{H}_{i-1}+\beta_i\mathbf{u}_{i-1}\widetilde{\mathbf{B}}_{i-1}^{\top} +\gamma_i\mathbf{u}_i\widetilde{\mathbf{B}}_i^{\top},\quad \mathbf{y}_i=\mathbf{H}_i\widetilde{\mathbf{C}}_i+D\mathbf{u}_i, \] 其中相位旋转和梯形更新用于保留演化动态。该小节产生可供 IV-C 提交和读取的递归状态。

IV-C Persistent Content Memory（持久内容记忆）

目的是在有界 attention 缓存之外，把 Mamba 压缩历史转成 attention 可访问的内容槽。基础 attention 使用学习 sink、近期缓存和当前窗口 token；PCM 在每层维护 \(S\) 个槽。投影器把已接受递归矩阵池化为摘要 \(\bar{\mathbf{s}}_t^\ell=\Pi^\ell(\mathbf{H}_t^\ell)\)，并计算与上一已接受窗口的差 \(\mathbf{d}_t^\ell=\bar{\mathbf{s}}_t^\ell-\bar{\mathbf{s}}_{t-1}^\ell\)。文本嵌入经层特定投影产生调制参数，对状态差做条件化；候选内容由状态摘要、文本调制差和文本嵌入拼接后投影归一化得到 \(\mathbf{Z}_t^\ell\)。写入门控由候选与旧槽共同决定，槽更新为 \[ \mathbf{P}_t^\ell=(1-\mathbf{w}_t^\ell)\odot\mathbf{P}_{t-1}^\ell +\mathbf{w}_t^\ell\odot\mathbf{Z}_t^\ell, \] 写入门控有上限，限制单次写入影响。读取时，把槽投影成额外 key/value 插在 sink 后，与基础 attention 共用 query；最终输出为 \[ \mathbf{Y}^\ell=\mathbf{A}^\ell_0+\tanh(\rho_\ell)(\mathbf{A}^\ell_P-\mathbf{A}^\ell_0) +\sigma(\zeta_\ell)\mathbf{M}^\ell. \] 将 \(\rho_\ell\) 初始化为零可精确回到无 PCM 的混合器输出。关键之处是 accepted-only 更新：每个去噪评估只读不可变快照，中间候选不提交；采样结束后，在扩散时间为零的规范 pass 中把被接受窗口物化为干净历史，并同时提交缓存追加、递归状态替换和 PCM 写入；若 pass 失败则两栈保留旧状态。因此每窗口计算不随已生成时长增长，但论文也强调这不等于任意长时程无误差。

图 5：流式生成与混合 attention–Mamba 混合。(a) 运动通过根–身体扩散逐窗口生成，去噪期间历史保持固定，仅在采样窗口被接受后更新。(b) 基础 attention 检索近期运动特征，而 PCM attention 额外访问持久内容槽。其门控残差差值与从已提交递归状态恢复的 Mamba-3 输出相结合。

IV-D State-Preserving Efficient Inference（保持状态的高效推理）

目的是降低重复去噪中的 kernel 启动、中间内存流量和不必要的状态物化，同时保持根到身体的顺序和 accepted-only 历史更新语义。只读执行在去噪时避免构造不被预测或后续提交消费的状态提案和诊断量；规范干净历史 pass 仍构造并提交完整已接受状态。融合核把 Mamba 转移预处理中的衰减激活、衰减下限、步长变换和 \(\Delta_i A_i\) 乘积合并为一次遍历，中间值留在 FP32 寄存器，再按扫描所需布局写出；满足数值检查时也融合兼容的 scale–shift 与门控残差操作，attention 与递归扫描本身保留。CUDA Graph 重放对根和身体扩散 Transformer 栈分别建图；每个栈内文本条件、空间条件和无条件三条引导分支串行并一起捕获。输入投影、条件准备、根输出处理、根到局部转换和身体输入构造留在图外；重放前刷新稳定输入和状态缓冲，采样更新、随机数处理、重居中与已接受状态提交也在捕获外；布局或参数版本不兼容时重建图，不支持调用回退参考路径。该小节优化了 IV-B/IV-C 的重复执行，但不改变采样计算和历史提交语义。

图 6：CUDA Graph 与 Kernel Fusion。对三个 CFG 分支进行栈级 CUDA Graph 重放，根和身体 DiT 栈使用独立图，并进行融合的 Mamba 转移预处理。

IV-E Learning Objective（学习目标）

目的是用四项目标优化干净窗口预测。混合项 \(\mathcal{L}_{\mathrm{hyb}}\) 对显式根 patch 和身体 latent 用 Smooth L1；解码身体项 \(\mathcal{L}_{\mathrm{body}}\) 对重建关节运动用 L1；目标项 \(\mathcal{L}_{\mathrm{goal}}\) 只对生成窗口内被观测到的坐标用 L1，尚未进入输出窗口的未来目标仅作为条件输入；一致性项 \(\mathcal{L}_{\mathrm{FK}}\) 约束由解码旋转经前向运动学得到的关节位置与直接解码的位置特征之间的欧氏差异。总目标为 \[ \mathcal{L}=\lambda_{\mathrm{hyb}}\mathcal{L}_{\mathrm{hyb}} +\lambda_{\mathrm{body}}\mathcal{L}_{\mathrm{body}} +\lambda_{\mathrm{goal}}\mathcal{L}_{\mathrm{goal}} +\lambda_{\mathrm{FK}}\mathcal{L}_{\mathrm{FK}}. \] 各项在适用元素上归一化；历史、生成区域和未来观测均用显式有效性掩码，生成区域外输出不进入监督归约。codec 在去噪器训练期间冻结。该小节是 IV-B/IV-C 去噪器参数的训练目标，不改变第 4 节所述推理数据流。

6. 局限性和展望（约300字）

论文明确说明的限制包括：固定大小的递归状态、attention 缓存和 PCM 槽只限定存储与计算上下文，并不保证保留任意遥远运动的每个细节；PCM 目标不是逐字复现任意早期指令，而是提供可用的运动上下文。训练时采样的最大历史为 196 帧（7.84 s），而评估展示到 39.52 s，更长时程仍不能由现有实验直接保证。完整的 52 帧窗口生成延迟也不等于用户指令到可见执行的端到端延迟。生成的是运动学参考，精确参考姿态不自动保证执行后的平衡或合适足底接触；物理可行性由下游跟踪系统承担。真实 G1 的 100 次试验 94% 成功且未观察到跌倒，但任务、地形和扰动范围仍有限。

可谨慎推断的限制是：压缩记忆可能丢失罕见的长尾细节；文本与空间目标冲突时的行为尚未系统评估；更复杂接触、强扰动和多用户交互仍需验证。展望包括学习更好的记忆保留/检索与淘汰策略、扩展到更长时程、把生成与物理跟踪做成更紧的闭环、在更多地形和接触条件下评估，并优化从指令到可见执行的端到端延迟与更广泛的用户研究。
