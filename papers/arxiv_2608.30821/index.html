Lucida: Parse, Generate, and Place for Composable Real-to-Sim Scene Modeling

一句话主题： 可组合真实到仿真场景建模的解析、生成与放置方法

领域标签： 真实到仿真 / 场景建模 / 三维感知

快速理解

背景与任务： 现有场景建模管线依赖准确实例几何、无遮挡视图和匹配资产，而实际捕获难以满足。

核心工作： 提出Lucida，重新分配各步骤需求，并用VLM策略GizmoAct闭环放置物体，显著提升场景重建精度。

中文摘要

可组合场景建模旨在将真实室内场景恢复为按观测排列的完整、可编辑对象资产，为机器人仿真和具身AI提供真实环境的仿真就绪副本，其中对象可被单独操作。现有流水线将该任务分解为三步——将观测解析为实例，为每个实例生成资产，并将每个资产放回原位——但每一步都预设了杂乱采集很少能提供的输入：精确的实例几何、无遮挡视图，以及与观测精确匹配的资产。我们提出Lucida，它保持这一顺序但重新分配要求，使每一步只消费真实采集可靠提供的信息，精度在流水线末端达到，而非从一开始就被要求。Lucida将视频解析为场景图，其节点携带每个实例的多视图证据；从每个实例的证据为其生成完整资产；并使用GizmoAct放置资产——一种VLM策略，将放置建模为多轮GUI交互，在闭环中操作对象的gizmo，并由其自行判断何时达到对齐。在场景级3D物体检测、物体姿态估计和场景重建上，Lucida在R2S-Scene上比Boxer的mAP提高了69%，在CA-1M上将ADD-SB@0.05从57.8%提高到83.4%，并将场景F-Score从SAM3D的0.794提高到0.924。

详细分析

1. 任务输入、输出、功能和边界（约100字）

Lucida 的输入是带相机位姿的多视角 RGB-D 观测，即真实室内场景的视频或图像序列。输出是以物体为中心的场景图：每个真实实例都有完整、可独立编辑的 3D 资产、9 自由度位姿（位置、旋转、各向异性缩放）、类别与空间关系，可直接用于机器人仿真和具身智能。边界是面向静态室内场景，不处理动态物体、光照变化或物理交互模拟。

2. 研究动机：要解决的问题与核心 insight（约300字）

现有“解析—生成—放置”管线把任务拆成三步，但每一步都预设了杂乱真实采集难以提供的输入：解析需要准确实例几何和无遮挡掩码；生成需要物体居中的干净视图或干净点云；放置又假设生成资产与观测在几何上一致。由于三步按固定顺序执行，任一步不满足都会向后传播误差。端到端联合预测也没有解决约束：同时预测形状和位姿会互相拖累，而用单一模型生成整场景受限于配对数据。

论文的核心观察是：人类建模者从同一份视频出发时，并不会先要求精确实例几何。他们先浏览素材、确认有哪些物体，再建模或检索资产，然后把资产逐个放入场景，反复旋转视角、修正位置，直到模型与观测吻合。也就是说，精度不是第一阶段的输入，而是最后闭环调整的输出。

Lucida 的 insight 是保留 parse–generate–place 的顺序，但重新分配各步骤的要求：解析只需产出带多视图证据的物体级证据包；生成利用证据包做 amodal 补全；放置则被建模成多轮 3D 编辑器式交互，由 VLM 策略操作物体 gizmo 闭环修正位姿，并自主决定何时停止。每一步只消费真实采集稳定提供的信息，最终精度由闭环放置阶段承担。

3. 核心贡献（约300字）

  • 重新表述可组合场景建模：不要求管线前段提供无遮挡、精确的几何输入，而是用“证据包”连接解析、生成、放置三个阶段，把精度要求推迟到闭环放置步骤。
  • 提出场景级 3D 物体检测/解析方法：包括几何感知关键帧选择、物体中心全序列证据整合、关系感知场景细化；输出带逐实例多视图证据的场景图。在 R2S-Scene 的 all 协议下，mAP 从 Boxer 的 0.351 提升到 0.592，并在 CA-1M 全部协议上取得最高。
  • 提出 GizmoAct：将 3D 放置建模为多轮 GUI 交互，VLM 策略读取渲染出的场景、资产、3D 框和 gizmo，输出增量位姿编辑，并可自主停止。它接受与观测不完全匹配的生成资产和粗糙初始位姿；在 CA-1M 上 ADD-SB@0.05 从 57.8% 提高到 83.4%，3D IoU 从 0.434 提高到 0.607。
  • 集成完整 Lucida 系统，并构建 R2S 真实室内基准；在场景重建中达到 0.924 的 scene F-Score，优于 SAM 3D 的 0.794 和 SceneGen 的 0.351。

4. 推理阶段整体流程与基模（约400字）

推理时使用的基础模型和工具有明确分工：VLM 承担实例发现、指代理解、编辑指令生成和位姿编辑策略；图像编辑模型负责补全被遮挡的物体外观；图像到 3D 模型把补全图提升为完整资产；3D 检测器、视频分割/跟踪模型负责候选框与跨帧证据传播。

图2：方法概览。给定带位姿的场景观测，解析阶段构建以物体为中心的场景图，包含逐物体多视角证据和粗略3D估计。对每个物体，利用多视角证据合成一个完整的以物体为中心的图像，再将其提升为3D资产。GizmoAct 通过闭环的 9-DoF gizmo 操作放置该资产，迭代细化旋转、平移和各向异性缩放，直到判定对齐达成。放置后的资产构成所捕获场景的可编辑重建。

整体推理流程如下：

  1. 输入：带位姿的 RGB-D 多视角观测。关键帧选择模块先按帧间几何冗余选出稀疏关键帧；VLM 在关键帧上识别物体实例，3D 检测器给出初始 3D 框；随后通过全序列证据整合把同一实例的多帧观测合并、验证。输出：场景图和逐实例证据包（多视图图像/掩码、部分点云、代表 3D 框、指代描述）。
  2. 输入：证据包。资产生成模块为每个物体选择互补视角，用 VLM 生成编辑指令，图像编辑模型合成无遮挡的物体图像，再由图像到 3D 模型生成完整资产，并依据代表 3D 框给出粗初始位姿。输出：待放置的完整资产及其初始状态。
  3. 输入：资产、初始位姿、证据包。GizmoAct 闭环开始：环境渲染场景点云、资产叠置、3D 框和 gizmo；VLM 策略观察后输出 update_pose、switch_obs、permute_axis 或 stop；环境执行动作并重新渲染，将新状态作为下一轮观测，直到策略输出 stop。输出：该物体的 9 自由度位姿。
  4. 输入：所有物体的资产与位姿。后处理模块检查支撑、碰撞、接触等场景级约束，并合成物体级场景图。输出：可编辑物体资产、9 自由度位姿、类别与空间关系组成的最终场景。

5. 核心方法：按论文 Method 小节总结（约600字）

2.1 Multi-View Object-Centric Scene Parsing（多视图物体中心场景解析）

该模块把原始视频解析为场景图 \(G=(V,E)\)，每个节点 \(o\) 携带证据包 \[ \mathcal{E}_o=\{\mathcal{V}_o,\mathcal{M}_o,\mathcal{P}_o,b_o,c_o\}, \] 其中 \(\mathcal{V}_o\) 是多视图观测，\(\mathcal{M}_o\) 是对应掩码/框，\(\mathcal{P}_o\) 是部分点云，\(b_o\) 是代表 3D 框，\(c_o\) 是类别或指代描述。解析阶段不要求精确实例几何，只为后续生成和放置提供可靠上下文。

关键帧选择使用几何共视与时间邻近性：对帧 \(i,j\) 计算深度一致的重投影比例 \(c_{i\to j}\)，再组合成相似度 \[ s(i,j)=\frac{2c_{i\to j}c_{j\to i}}{\max(c_{i\to j}+c_{j\to i},\epsilon)} \left(\lambda+(1-\lambda)e^{-|i-j|/\tau}\right). \] 按时间顺序保留与已选关键帧相似度低于阈值的帧。之后在关键帧上用 VLM 识别实例、3D 检测器预测框，并跨帧按语义和几何一致性分组。

全序列证据整合解决关键帧对单个物体覆盖不足的问题：先从一致的 3D 框中选代表框，若不够一致，则用视频分割/跟踪把物体传播到邻近帧并重新估计；再把代表框投影到各帧作为提示，估计并验证逐帧 3D 框，保留几何一致的观测。最后，关系感知场景细化修正错误合并/分裂，推断支撑、包含、邻接等关系，并补全缺失支撑物。

2.2 Amodal Object Asset Generation（Amodal 物体资产生成）

该模块把证据包变成完整、独立、可编辑的 3D 资产。直接使用点云完成会被遮挡和深度噪声影响，因此 Lucida 先利用多视图 RGB 证据：选择可靠且互补的视图，用 Set-of-Mark 提示标记目标，再由 VLM 组织 anchor/references 并生成编辑指令；图像编辑模型据此合成完整物体图像，最后由图像到 3D 模型将其提升为资产 \(A_o\)。资产用 \(b_o\) 在场景中粗初始化，交给 GizmoAct 精修。

2.3 Agentic 3D Grounding with GizmoAct（基于 GizmoAct 的智能体式 3D 定位）

2.3.1 Formulation: 3D Grounding as Multi-turn GUI Interaction（公式化：将 3D 定位视为多轮 GUI 交互）

GizmoAct 将物体定位表达为状态 \(x_t=(p_t,R_t,s_t)\)、渲染观测 \(o_t=\mathcal{R}(A_o,x_t,\mathcal{E}_o,v_t)\) 和文本动作 \(a_t\) 之间的闭环： \[ o_t=\mathcal{R}(A_o,x_t,\mathcal{E}_o,v_t),\quad a_t\sim\pi_\theta(\cdot\mid o_{\le t},a_{<t}),\quad (x_{t+1},v_{t+1})=F(x_t,a_t). \] 策略是 VLM，既预测位姿编辑，也预测何时 stop。

2.3.2 Graphical Observation Interface（图形化观测界面）

观测由指令块、主视图、辅助视图和沿局部轴的正交视图组成。模型叠置、黄色 3D 框和 gizmo 定义物体局部坐标；辅助视图补充多视角信息；正交视图缓解单视图的尺度-深度歧义；半透明绿色标记被场景点云遮挡的模型表面，帮助判断深度关系。

图3：GizmoAct 的图形化观测与交互轨迹。(a) 单轮中的观测。指令块指定调整目标和指代线索；主视图将原始输入图像与渲染图配对，渲染图叠加了资产、其黄色3D框，以及显示物体局部坐标系（红/绿/蓝轴）的 gizmo；所有编辑都在该坐标系中表达。半透明绿色标记被场景点云遮挡的模型表面。辅助视图增加多视角证据，沿局部坐标系的正交视图支持精细细化。(b) 一次策略发出有缺陷编辑（红叉）并从结果状态恢复（绿勾）的轨迹。在 SFT 数据构建期间，我们通过误差注入模拟此类情况，并且只监督恢复动作。

2.3.3 GizmoAct Action Space（GizmoAct 动作空间）

核心动作是 update_pose 和 stop，扩展动作是 switch_obs 与 permute_axis。连续位姿更新在物体局部系中表达： \[ R_{t+1}=R_tR_{\mathrm{ZXY}}(\delta_r),\quad s_{t+1}=s_t\odot(\mathbf{1}+\delta_s),\quad p_{t+1}=p_t+R_{t+1}(\delta_p\odot s_t). \] 旋转先应用；平移和缩放都按当前物体尺寸归一，因此策略不回归绝对位姿或绝对尺度。粗旋转误差通过 switch_obs 暴露物体六个侧面，再由 permute_axis 选择 24 种轴对齐重定向之一，一步消除主要旋转残差。

图4：为粗旋转设计的扩展动作。当初始旋转误差较大时（步骤1），策略首先发出 switch_obs，该动作只改变渲染模式：下一观测（步骤2，底部面板放大）显示原始视图对以及资产沿其带符号局部轴的六幅正交渲染图，从而暴露出主视图隐藏的侧面。基于这些视图，策略预测单个 permute_axis 动作，选择24种轴对齐重定向之一，一步消除主要旋转残差。在策略预测 stop（步骤4）之前，剩余误差由 update_pose（步骤3）修复。虚线箭头标出另一种选择：使用单个常规 update_pose 预测全部修正而跳过置换，这种方式精度较低。

2.3.4 Supervised Finetuning on Synthetic Trajectories（合成轨迹上的监督微调）

该阶段把基础 VLM 训练成 GizmoAct 策略。训练数据来自 3D-FRONT/MesaTask 桌面布局、FoundationPose 随机化散落场景和 CA-1M 真实长尾物体。每个样例包含证据包、资产、扰动初始位姿和隐藏真值位姿，在同一可执行环境中滚动成多轮对话。特权专家按“先旋转、再平移/缩放”的顺序生成轨迹，并用误差注入模拟欠修正、过冲、错轴等错误，再让专家演示恢复。SFT 目标只监督动作 token，并用权重 \(w_t\) 掩蔽注入的错误动作。

2.3.5 RL Training（强化学习训练）

SFT 后的策略仍难以处理在线自错，因此继续用 GRPO 在同一推理环境中优化。奖励只在轨迹终态给出，由广义 3D IoU \(g\) 和测地旋转误差 \(e_R\) 量化成四级：坏、粗、成功、优秀。联合成功定义为 \[ S=\mathbf{1}[\ell_g\ge 2]\cdot\mathbf{1}[\ell_R\ge 2], \] 终态奖励为 \[ r(\xi)=\frac{S}{8}\left(4+2\cdot\mathbf{1}[\ell_g=3]+2\cdot\mathbf{1}[\ell_R=3]+\mathbf{1}[a_T=\mathrm{stop}]\right). \] 训练采用 DAPO 式动态采样：每组采样 8 条 rollout，若组内任一条未完成或终态奖励全部相同则丢弃该组。策略优化使用 token 级裁剪、截断重要性采样，并关闭 KL 惩罚。由于奖励中的旋转误差会惩罚对称等价位姿，RL 训练显式排除对称物体。

2.4 Scene Composition and Postprocessing（场景合成与后处理）

单个物体生成并放置后，Lucida 组合成完整场景。基础输出是物体级场景图，包含资产、位姿、尺度、类别和空间关系。可选后处理以规则、物理检查或全局验证修正支撑关系、碰撞、接触一致性和放置合理性；这些场景级约束与 GizmoAct 解耦，让策略专注单物体定位，后处理负责全局一致性。

6. 局限性和展望（约300字）

论文明确说明的限制主要有两点。第一，RL 奖励中的测地旋转误差会惩罚对称等价位姿，因此训练时排除对称物体；若没有对称性标注，这类物体难以被当前策略可靠优化。第二，策略虽然能适配 Boxer、Any6D、SAM 3D 等不同初始化器，但哪个初始化器更好仍取决于输入几何精度：在精确深度（ADT）下，Any6D/SAM 3D 初始化更好；在估计深度（R2S-Object、CA-1M）下，Boxer 初始化更稳。这说明整个系统仍受上游深度和位姿质量制约。

可以谨慎推断的边界包括：Lucida 面向静态室内场景，对动态物体、光照变化、多房间或超长序列未验证；最终物体资产依赖图像编辑和图像到 3D 模型，物体级 Chamfer 距离仍非零，细节几何误差会保留下来；物体发现与跨帧关联依赖 VLM、检测器和跟踪模型，在重复家具、极薄或长尾小物体上可能出现错误合并或分裂；场景后处理是可选的规则式检查，不学习物理合理性。

未来方向可以包括：引入对称性标注或对称感知奖励；把生成与放置更紧密地耦合到更强的多模态模型中，减少交互轮数；将支撑、碰撞等全局约束纳入学习式策略；以及把 Lucida 扩展到动态场景、开放词汇物体和更长序列。
