DeformSmith: Physics Harness-Guided Hierarchical Generation of Deformable Assets for Robot Manipulation

来源： arXiv · HF Paper · AlphaXiv

一句话主题： 面向机器人操作的可变形资产生成，用物理引导分层构建和交互反馈闭环优化。

领域标签： 机器人操作 / 可变形资产生成 / 物理引导优化

快速理解

背景与任务： 机器人操作可变形资产的生成需联合确定几何、外观和物理属性，而文本/图像难以提供形变与接触响应证据。

核心工作： 提出DeformSmith，用分层智能体构建和共享物理引导，从文本或单图逐步生成、测试、优化资产，并通过机器人交互反馈闭环提升视觉质量与物理可信度。

中文摘要

为机器人操作创建可变形资产需要同时指定其几何、外观和物理属性。这对于可变形物体尤其具有挑战性，因为文本和图像提供的关于其如何变形及响应接触的证据有限，而这些响应直接影响其是否适合交互。因此，自动化生成需要解决耦合的物理需求，并利用交互证据来指导构建与细化。我们提出了DeformSmith，一个能够从文本或单张图像自动生成可交互、物理可信的可变形资产的框架。通过分层智能体构建和共享的物理基础测试平台，它逐步构建、测试和细化几何、物理模型、材料行为以及机器人交互，直到生成的资产可用于仿真和操作。机器人交互通过操作反馈和可重放的交互数据使生成过程形成闭环。结果表明，DeformSmith生成的资产在视觉质量和物理合理性上优于最先进的基线方法（包括PhysGen3D、PhysGM和PhysX-Omni），同时支持为可变形物体的机器人操作合成数据。项目页面：https://can-lee.github.io/deformsmith-web/

详细分析

1. 任务输入、输出、功能和边界

DeformSmith 的输入是一段自然语言文本或单张物体图像，输出是一个可交互、物理可信的可变形资产。该资产包含基于粒子的物理表示、Gaussian 外观、物理配置（质量、体积、材质参数、接触条件）、验证记录和可重放的机器人交互数据。其功能是为机器人操作仿真提供可直接抓取、搬运、释放的可变形物体。边界是：只处理体积型可变形固体，不处理流体和颗粒材料；材质假设为均匀各向同性弹性体；物理参数和接触模型是近似估计。

2. 研究动机：要解决的问题与核心 insight

在机器人操作中，可变形资产的价值不仅取决于它“看起来像什么”，还取决于它被抓取、搬运、释放时“如何变形”。文本和单张图像只能提供几何与语义信息，几乎不能提供材料刚度、阻尼、摩擦等决定接触响应的物理信息。更困难的是，几何、质量、材质和接触条件彼此耦合：修改材料可能改变物体在重力下的下沉量，修改接触条件可能改变抓取稳定性，因此不能把这些因素拆开独立猜测。

现有方法主要分为两类：基于视频或交互观察的方法能估计物理参数，但需要事先看到物体真实运动；基于单图或文本的方法虽然能生成可交互表示，但缺少反馈校验，无法判断推断出的材料在接触后是否正确。论文的核心 insight 是：输入中缺失的物理信息不应当一次性猜完，而应通过“先搭几何和物理底盘，再用仿真探针筛选材质，最后用机器人操作验证”的闭环逐步补全。用仿真产生的接触、变形和稳定性证据来指导生成，而不是只依赖视觉相似性，才能得到真正可用于机器人操作的可变形资产。图 3 直观展示了这一点：仅靠单图重建的资产在跌落仿真后可能摊平、碎裂或结构散开，而 DeformSmith 在相同交互测试中能保持更完整的外观和结构。

3. 核心贡献

论文提出、构建并验证了以下三方面贡献：

  1. DeformSmith 框架：一个全自动的分层智能体生成框架，能把文本或单张图像转化为可供机器人操作的可交互可变形资产。它将构建过程拆成四层：L0 几何重建、L1 物理模型建立、L2 材质配置、L3 机器人操作验证，逐层构建并检查。
  1. 共享物理接地控制框架（physics-grounded harness）：把 LLM 智能体与仿真评估连接起来，用仿真证据指导每一步的接受或修订。该框架通过“契约”定义每层允许的动作、必须通过的硬性条件、可编辑字段和修订预算，从而在多次修订中保持物理一致性。
  1. 机器人操作进入生成回路：将抓取-搬运-释放的机器人操作作为最终验证和反馈来源，既用于进一步修正资产，又产生可重放的交互数据。实验表明，DeformSmith 在物理真实性、视觉质量和语义一致性上优于 PhysGen3D、PhysGM、PhysX-Omni；消融实验验证了分层结构、共享控制框架和操作反馈各自的作用。

4. 推理阶段整体流程与基模

实际使用时，DeformSmith 按固定流程执行“生成—评估—修订”循环。推理时承担决策的基模是 GPT-5.6 Sol：它在控制框架中分别扮演 Planner（选择动作或修订路线）、Designer（提出结构化候选）和 Critic（解读仿真证据并给出接受/修订建议）。此外，图像生成与几何重建模型 Qwen-Image、SAM 3、SAM 3D、MoGe-2、CoACD 负责把输入变成可仿真的几何；Warp MPM 后端负责可变形物理仿真；SAPIEN 和 GraspNet 负责机器人交互规划。图 2 给出了整体流程。

图2：DeformSmith概览。DeformSmith从文本或单张图像逐步构建可变形资产，每一层都建立在前一层输出的基础之上。该框架重建3D几何、建立物理模型、配置材质属性，并通过仿真探针评估变形与稳定性。随后，机器人抓取-放置测试抓取、搬运和释放，提供交互反馈以进一步细化。一个基于物理的共享控制框架贯穿生成、评估和修订全过程，产出带有验证证据和模拟交互数据的资产。

推理步骤如下：

  1. 输入：文本或单张图像。 若输入为文本，先生成参考图像；分割与重建模块输出物体网格、Gaussian 外观、相机位姿、凸碰撞代理和采样粒子，并将这些几何量对齐到同一坐标系。输出交给 L1 物理建模。
  2. 输入：对齐后的几何和碰撞代理。 物理建模模块在公制单位下初始化粒子体积和质量，设定重力、地面接触和初始速度，并用刚体代理做放置、跌落、滑动检查。输出共享物理模型，供后续材质和操作使用。
  3. 输入：共享物理模型。 材质配置模块提出材料候选（杨氏模量、泊松比、阻尼），用 MPM 仿真执行跌落、压缩/提升和稳定性探针；Critic 根据仿真证据决定接受或修订。输出通过验证的材质参数和物理模型。
  4. 输入：带材质的资产。 机器人交互模块生成抓取位姿，在 SAPIEN 中执行接近、闭合、抬升、搬运、释放，并记录粒子轨迹、接触观测和任务结果。若反馈显示动作问题，则调整动作重试；若显示材质问题，则返回第 3 步重新验证。
  5. 输入：通过任务与验证的资产。 输出最终资产，包括粒子物理表示、Gaussian 外观、物理配置、验证证据和可重放的交互数据。

5. 核心方法：按论文 Method 小节总结

Method 首先明确目标：从文本或单张图像构建可供仿真机器人操作的体积可变形固体资产。资产包含粒子物理表示、Gaussian 外观和物理配置；粒子质量、静止体积、材质参数和接触条件共同决定资产的动态响应。Method 的总体思路是先固定几何和物理模型，再通过仿真探针选择材质，最后用机器人操作验证。

III-A Hierarchical Asset Generation（分层资产生成）

该小节将资产构建拆成 L0–L3 四层，每一层都建立在前一层输出之上。

L0：3D 几何重建与对齐。 文本先被转换成参考图像；图像则直接进入重建。该层重建分割物体的网格和 Gaussian 外观，估计相机与物体几何，并构造凸分解碰撞代理。网格、碰撞代理、采样粒子和 Gaussian 被对齐到同一规范坐标系；每个 Gaussian 与静止构型中的邻近粒子绑定，粒子运动时更新 Gaussian 的位置和方向，从而让物理变形驱动外观变化。

L1：物理建模与初始化。 该层把几何变成物理对象：初始化粒子位置和体积 \(V_i\)（公制单位），并用均匀密度先验 \(\rho\) 赋予质量 \(m_i=\rho V_i\)。 \(\rho\) 由 L1 Designer 根据输入建议。同时设定重力、地面接触参数和零初始速度。在启用可变形仿真前，该层先用刚体碰撞代理执行放置、跌落、滑动测试，验证物理模型的合理性。L1 得到的物理模型被 L2 和 L3 共享，且后续不允许通过改变材质来补偿质量、尺度或支撑条件的变化。

L2：可变形材质配置。 该层假设物体是均匀、各向同性的 neo-Hookean 材料，提出杨氏模量、泊松比和阻尼候选，并用物质点法（Material Point Method, MPM）仿真其响应。MPM 在粒子上跟踪材料状态，通过与背景网格的相互传递更新运动。仿真探针包括：可变形跌落测试（评估冲击变形、回弹和能量耗散）、压缩或抬升测试（评估受控载荷下的变形和释放后恢复），以及较长时域内的稳定性检查。通过数值和物理有效性检查的候选会根据与目标行为的匹配程度排序，最终被接受的材质与 L1 物理模型一起交给 L3。

L3：机器人操作。 该层继承 L1 物理模型和 L2 材质，规划一次抓取-放置操作，考察抓取、搬运和释放。机器人交互反馈用于指导动作和材质修订：动作修订直接在 L3 内重新评估；材质修订则必须先返回 L2 重新验证。该层同时产生模拟交互数据。

III-B Robot Interaction and Evidence Generation（机器人交互与证据生成）

该小节给出机器人交互的接触建模、力估计和交互数据记录方式。

抓取和搬运要求手指能建立接触、通过摩擦支撑变形的物体，并在目的地释放。机器人阶段依次执行接近、闭合、抬升、搬运、释放和退回。夹爪被建模为运动学网格边界。在 MPM 网格节点上，设 \(u_n\) 和 \(\mathbf{u}_t\) 分别为网格速度相对夹爪表面的法向和切向分量。当法向相对速度指向夹爪内部（\(u_n<0\)）时，修正网格速度以阻止穿透：

\[ \mathbf{v}_g^+ = \mathbf{v}_b + \alpha \mathbf{u}_t, \]

其中 \(\mathbf{v}_g^+\) 是修正后网格速度，\(\mathbf{v}_b\) 是夹爪表面速度，\(\alpha\) 是摩擦保留比例：

\[ \alpha = \max\left(0,\ 1-\frac{\mu(-u_n)}{\max(\|\mathbf{u}_t\|,\varepsilon_v)}\right). \]

这里 \(\mu\) 是夹爪与物体间的摩擦系数，\(\varepsilon_v>0\) 避免除零。该更新阻止物体穿入夹爪、施加摩擦，同时允许物体分离。网格到粒子传递后还会修正残余穿透和向内的相对速度。

为了支持力预算，论文估计每个手指上的平均反作用力：在报告区间 \(\Delta t_k\) 内，将该手指接触更新产生的冲量求和并除以区间时长：

\[ \overline{\mathbf{f}}_i^{(k)}=-\frac{1}{\Delta t_k}\sum_{c\in C_i^{(k)}}\mathbf{J}_c, \]

其中 \(C_i^{(k)}\) 是该区间内手指 \(i\) 的接触更新集合，\(\mathbf{J}_c\) 是单个接触更新传递给物体的冲量，负号表示夹爪受到的相反作用力。

交互数据方面，系统记录机器人指令、粒子状态、接触观测和任务结果。记录的粒子轨迹可直接驱动 Gaussian 渲染，无需重跑仿真；录制与重放的有效性被独立验证，失败尝试也会作为带标签的诊断证据保留。图 4 展示了一个生成资产在模拟机器人操作中的表现。

图4：使用DeformSmith生成资产的模拟机器人操作。从左到右，一个毛绒物体经历接近、抓取、提升和释放。场景视图（上）与特写视图（下）配对，突出显示夹爪接触下的物体变形；蓝色线框表示夹爪碰撞几何体。动态高斯泼溅在整个模拟交互过程中渲染机器人场景和可变形物体，从而能够生成可变形物体的操作数据。

III-C Shared Physics-Grounded Harness（共享物理接地控制框架）

该小节说明各层如何被统一协调，以及机器人反馈如何进一步引导修订。

从提案到证据。 Planner 选择当前允许的动作或修订路线，Designer 提出结构化候选，Prober 执行几何检查或仿真并返回证据，Critic 解释证据并建议接受或修订。其中 Planner、Designer、Critic 是 LLM 智能体，Prober 执行仿真和检查，Orchestrator 按 harness 契约做规则检查。Orchestrator 接受候选，或在修订预算内把反馈返回给 Planner 继续迭代。Prober 从仿真 rollout 中收集状态、接触和变形观测；几何评估使用对齐视图和几何检查。每条证据都记录对应的提案来源和修订历史。

Harness 契约。 契约定义每一层允许的动作、必须提供的观测、硬性门禁（hard gates）、可编辑字段和修订预算。每次修订必须保持在允许字段和参数范围内，并且必须通过所有硬性门禁，之后才按照与目标行为的一致性在固定测试条件下排序。每次尝试都记录观测、提案来源和修订历史；只有被接受的候选才会替换当前版本，当修订预算耗尽时搜索结束。

操作引导的细化。 基本物理探针不能完全捕捉抓取、搬运和释放中的行为，因此机器人交互提供了任务层面的反馈。harness 根据反馈诊断动作问题、材质问题和数值问题：动作修订调整抓取选择、闭合和运动时序；数值修订在保持动作时长不变的前提下调整仿真超参数；材质修订用于解决动作诊断后仍出现的不期望变形，且必须返回 L2 重新验证，再在相同指令、相同物理模型和相同力预算下由机器人确认。整个机器人交互过程还强制每根手指的力预算。

6. 局限性和展望

论文明确说明的限制： 当前方法假设物体是均匀、各向同性的体积弹性材料，机器人接触模型也是近似的，因此难以覆盖绳子、布料、流体、颗粒、多层或各向异性等复杂可变形物体。从文本或单图推断出的物理参数只是初始估计，还没有在真实物体上做实物验证。实验评估主要依赖 GPT 和人的主观物理合理性评分，并没有直接建立材质参数精度。论文将未来工作指向结合视频中的 3D 点轨迹进行真实材质参数识别，以及扩展更广泛的材质和接触模型。

可以谨慎推断的限制： 分层流程一旦通过 L0/L1，几何和物理模型就作为后续决策的固定基础；对于中空、多部件、可断裂或塑性变形明显的物体，这种“先固定底盘再改材质”的方式可能不够灵活。机器人操作验证在 SAPIEN 仿真中完成，从仿真到真实机器人之间还需要实物校准。此外，使用 LLM 作为 Critic 虽然能解释仿真证据，但评估标准会受模型先验影响，不一定完全等价于真实物理测量。
