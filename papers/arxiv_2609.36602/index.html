OTRetarget: Joint Robot and Object Motion Retargeting via Optimal Transport

来源： arXiv · HF Paper · AlphaXiv

一句话主题： 人形机器人运动重定向：联合优化机器人与物体姿态以保持交互接触

领域标签： 机器人运动重定向 / 最优传输 / 人机交互 / 物体操作 / 强化学习

快速理解

背景与任务： 将人类演示迁移到人形机器人时，需适应机器人形态并保持与环境和物体的接触一致性，现有方法固定物体轨迹导致适应受限。

核心工作： 提出OTRetarget，用熵最优传输将表面交互量从人体映射到机器人，并联合优化机器人和物体姿态，在真实G1机器人上实现双手搬箱放置任务。

中文摘要

将人类运动迁移到人形机器人，需要使示范运动适应机器人形态，同时保持与环境的交互。这对于移动操作（loco-manipulation）任务尤其具有挑战性，因为尽管身体比例存在差异，与地面及被操作物体的接触仍须保持一致。然而，仅凭骨骼运动无法完整描述这些交互，而固定物体轨迹会限制对新本体的适应。我们提出 OTR ETARGET，一种从人类示范中联合重定向（retarget）机器人运动与多物体运动的统一方法。我们的方法通过有符号距离（signed distances）、最近表面点（closest surface points）和相对方向来表示表面交互，并使用熵正则最优传输（entropic optimal transport）在人体、机器人与物体的几何之间传递这些量。我们将由此得到的交互目标纳入约束逆运动学（constrained inverse kinematics）公式中，该公式在接触保持与运动风格之间取得平衡，并在每一帧联合优化机器人与物体的位姿。该公式能够处理机器人-物体交互与物体-物体交互，而无需重新缩放场景或示范。我们在 OMOMO 上验证了所提出的方法，其机器人-物体交互 Jaccard 分数达到 87%，深度误差为 8.7 mm；相比之下，OmniRetarget 分别为 28% 和 29.3 mm。最后，我们展示了向实体 G1 人形机器人的迁移，使用在重定向后的参考上通过强化学习训练的全身策略（whole-body policies），覆盖包括双手将箱子拾取并放置到桌上在内的多种运动。

详细分析

1. 任务输入、输出、功能和边界（约100字）

OTRetarget 的输入是人体演示（例如 SMPL-X 人体网格/骨架、物体位姿轨迹、场景网格）以及目标机器人和目标物体的几何模型。输出是逐帧的机器人关节构型 \(q_t\) 与所有被操作物体的 \(\mathrm{SE}(3)\) 位姿。其功能是在保持地面、机器人-物体、物体-物体交互一致的前提下，把动作迁移到不同形态的机器人上。边界是单机器人、平地、逐帧运动学求解，不直接输出力或时间最优轨迹。

2. 研究动机：要解决的问题与核心 insight（约300字）

把人体动作迁移到人形机器人时，仅迁移骨架并不够。骨架只描述关节位置，不描述手掌是否完全贴住箱子、脚底是否踩实地面。自由空间动作可以通过缩放近似；接触丰富的移动操纵则不然。若只追踪骨架，手可能悬空或穿地；若固定物体轨迹，短臂机器人无法按原高度搬箱，放下时可能落到桌下；全局缩放会让物体和场景比例失调。图3给出直观对比：OTRetarget 保持手平放地面，而忽略地形的方法会悬空或穿透，只用缩放的方法手腕弯曲。

图3：手和膝着地（爬行）。OTRetarget 像演示中那样将双手平放在地板上。OmniRetarget 以手腕弯曲的方式触地；不表示地形的 GMR 使双手悬在其上方，而 PHC 则使双手穿过地面。

核心 insight 是：把“交互本身”作为可跨形体传输的量，而不是把关节坐标或物体轨迹当作必须逐点追踪的量。交互用表面上的有符号距离、最近点、相对方向来描述；用熵正则最优传输建立源表面到目标表面的对应；然后让机器人关节和所有物体位姿一起作为优化变量，在保留演示交互与贴近演示风格之间分配权重。这样场景和演示都不必全局缩放，交互能够适应新形体，而不是被固定轨迹钉死。

3. 核心贡献（约300字）

论文提出并验证了三点贡献。

C1：表面级交互残差。 论文从演示几何中提取逐点的表面交互残差，并把它与动作风格目标一起放入逐帧约束逆运动学（IK）问题。残差包含有符号距离差、通道表面上的最近点距离差和相对方向差，能够表达骨架目标无法表达的手掌-物体、脚底-地面接触。

C2：机器人与多物体联合重定向。 求解时机器人配置 \(q_t\) 和全部物体位姿 \(\{T^o_t\}\) 都是自由变量，物体轨迹可随机器人形态与场景约束变化，因此无需缩放演示或场景，能够同时处理缩放不一致和物体轨迹不匹配。

C3：不同物体形状之间的交互迁移。 论文把最优传输对应推广到演示物体和替代物体之间，使同一段演示可用于未见过的物体形状和尺寸。

在验证方面，OTRetarget 在 OMOMO（单物体操纵演示数据集）上的机器人-物体交互 Jaccard（交并比）达到 87%，深度误差为 8.7 mm；OmniRetarget 只有 28% 和 29.3 mm。图4展示了大箱、落地灯和举顶搬运上的差异；图5显示抓取召回率在物体尺寸变化下保持稳定；下游全身策略还在物理 G1 人形机器人上完成了双手搬箱到桌子的任务，图6显示更接近演示的参考轨迹带来更低的跟踪误差。

图4：在 OMOMO 上的移动操纵示例，OTRetarget（上）与 OmniRetarget（下）：左侧为一个大型凸箱、一个落地灯和一个网格没有体积可握持的茎秆；右侧为缩放世界中的同一次举顶搬运，分别为物体固定和自由的原始情况。

图5：一个演示在物体尺寸分布上重放的示例（largebox, OMOMO, sub3_003）：抓取召回率和精确率随箱子尺度的变化。

图6：重定向质量对跟踪性能的影响。使用相同训练流程的十个 AMASS 剪辑的 MPJPE 随 PPO 迭代次数的变化。虚线标记 OmniRetarget 的最终精度。

4. 推理阶段整体流程与基模（约400字）

推理时，OTRetarget 不使用可学习的生成式神经网络作为基础模型，而是使用几何基模：有符号距离场/最近点场，以及熵正则最优传输计划。距离场回答“探针离某表面多近、最近点在哪”，最优传输计划回答“演示表面上的哪一个点应该驱动目标表面上的这个点”。这两个固定映射在几何上预先确定，部署后直接查用。图2展示了整体流程。

图2：流程总览。每个探针 x c , p 从通道的有符号距离场读取一个邻近三元组 ( d , w , n ) c , p 。预先计算一次的最优传输计划 P ⋆ 将该目标传递到机器人。在每一帧，一个约束优化程序在联合求解机器人位姿 q t 和每个物体位姿 T t o 的同时，平衡所得残差与骨架式目标。虚线表示可选的物体替换（第三节-E）。

实际使用流程如下：

  1. 输入接受与坐标统一。 输入为人体演示（网格/骨架、物体位姿轨迹）以及目标机器人、目标物体几何；系统把它们放在同一世界坐标系中。
  2. 生成逐帧交互目标。 对当前帧的机器人/物体表面探针，用最优传输对应找到每个探针在演示中的源点，并从该源点所在通道的距离场/最近点场取出目标三元组：有符号距离、最近点、相对方向。若使用替代物体，物体间最优传输先把演示物体上的接触位置映射到替代物体表面。
  3. 求解约束 IK。 优化目标包括交互目标偏差、机器人/物体相对演示的风格偏差和帧间平滑；约束包括关节限位、速度限位、物体位移限位、碰撞避免和自碰撞。求解器联合更新机器人关节角 \(q_t\) 和所有物体位姿。
  4. 输出参考帧并推进。 写出当前帧的 \(q_t\) 与 \(\{T^o_t\}\)；若还有下一帧，则回到步骤2继续。环境/碰撞反馈以约束形式进入求解器。

5. 核心方法：按论文 Method 小节总结（约600字）

III-A Problem Setting and Formulation（问题设定与公式化）

传统重定向输入是骨架和物体位姿，但骨架只是几何上的粗化表示。为了准确表达接触，OTRetarget 在人体、机器人和物体表面密集采样探针点。设机器人构型为 \(q_t \in \mathbb{R}^{n_q}\)，第 \(o\) 个物体位姿为 \(T^o_t \in \mathrm{SE}(3)\)。每帧求解如下约束问题：

\[ \min_{q_t,\{T^o_t\}} E^{\mathrm{int}} + E^{\mathrm{sty}}_r + E^{\mathrm{sty}}_o + \lVert q_t \ominus q_{t-1} \rVert^2, \quad \text{s.t. } \mathcal{C}(q_t,\{T^o_t\}). \]

其中 \(E^{\mathrm{int}}\) 是交互偏差代价，\(E^{\mathrm{sty}}_r\) 和 \(E^{\mathrm{sty}}_o\) 分别是机器人和物体相对于演示轨迹的风格偏差，最后一项平滑帧间变化。约束 \(\mathcal{C}\) 包含关节限位、关节速度限位、各物体速度限位、碰撞避免与自碰撞。

III-B Surface-level Proximity and Optimal Transport（表面级邻近度与最优传输）

把被测量距离的表面称为“通道” \(c\)，例如地面、桌子或被抓物体。通道位姿为 \(T^c_t=(R_c,\tau_c)\)。源表面上的探针点 \(\bm{x}_p\) 在通道坐标系中的位置为：

\[ \bm{x}_{c,p}=R_c^\top(\bm{x}_p-\tau_c). \]

通道预先提供有符号距离函数 \(\Phi_c\) 和最近点函数 \(W_c\)，于是定义邻近三元组：

\[ (d,\bm{w},\bm{n})_{c,p} = \left( \Phi_c(\bm{x}_{c,p}),\ W_c(\bm{x}_{c,p}),\ \frac{\bm{x}_{c,p}-\bm{w}_{c,p}}{\lVert \bm{x}_{c,p}-\bm{w}_{c,p}\rVert} \right). \]

其中 \(d\) 是探针到通道表面的有符号距离，\(\bm{w}\) 是通道表面上的最近点，\(\bm{n}\) 是从最近点指向探针的单位方向。\(\Phi_c,W_c\) 在通道局部网格上按 1 cm 分辨率、表面外 15 cm 范围预计算并插值。

人体到机器人的表面对应通过熵正则最优传输建立。人体部位被手工指派给机器人连杆；对每个部位-连杆点云，先按均方根半径归一化，再求解：

\[ P^\star = \arg\min_{P \in \Pi(a,b)} \langle P, C \rangle + \varepsilon_{\mathrm{ot}} \sum_{i,p} P_{ip}(\log P_{ip}-1). \]

其中 \(a,b\) 是均匀边际，\(C_{ip}\) 是两点间的平方欧氏距离，\(\varepsilon_{\mathrm{ot}}=0.1\)。传输计划用 Sinkhorn 算法求解。探针 \(p\) 的对应源点为 \(\mathrm{src}(p)=\arg\max_i P^\star_{ip}\)，于是目标机器人上的期望三元组直接取自演示中对应源点的三元组。相比最近邻，最优传输的边际约束使所有人体采样点都被使用，肢体末端覆盖更均匀。

III-C Interaction Residuals（交互残差）

给定演示期望 \((\hat d,\hat{\bm{w}},\hat{\bm{n}})\) 和当前值 \((d,\bm{w},\bm{n})\)，定义三个残差：

\[ r^d_{c,p} = d_{c,p} - (\hat d_{c,p})_+, \]

\[ r^x_{c,p} = \rho_c\!\left(\bm{w}_{c,p};\ \hat{\bm{w}}_{c,p}\right), \]

\[ r^n_{c,p} = \left( \operatorname{sign}(\hat d_{c,p})\, \hat{\bm{n}}_{c,p}\cdot(\bm{x}_{c,p}-\hat{\bm{w}}_{c,p}) \right)_-. \]

这里 \(\rho_c\) 是通道表面上的测地距离，\(( \cdot )_+=\max(\cdot,0)\)，\((\cdot)_-=\min(\cdot,0)\)。距离残差 \(r^d\) 把当前间隙拉向演示间隙；最近点残差 \(r^x\) 控制接触位置在表面上的偏移；方向残差 \(r^n\) 解决薄板两侧方向歧义。

交互代价为：

\[ E^{\mathrm{int}} = \sum_{c,p} \frac{f_{\ell(p)}}{N_{\ell(p)}} \left[ \lambda^d \beta_{c,p}^2\,(r^d_{c,p})^2 + \lambda^x \bar\beta_{c,p}^2\,(r^x_{c,p})^2 + \lambda^n \bar\beta_{c,p}^2\,(r^n_{c,p})^2 \right]. \]

权重取 \((\lambda^d,\lambda^x,\lambda^n)=(256,625,2500)\)，由物体携带的探针权重为四倍。\(\beta,\bar\beta\) 是宽度为 13 cm 的二次核：\(\bar\beta\) 只由演示距离决定，控制切向残差仅在演示有接触时激活；\(\beta\) 同时考虑演示距离和当前距离，使距离残差在任意一侧接近接触时都起作用，并对穿透设置上限 5。

III-D Joint Kinematic Retargeting Solver（联合运动学重定向求解器）

风格代价使用人体骨架作为姿态参考。对每个被跟踪连杆，期望朝向为 \(\hat R_\ell = R_{h(\ell)}O_\ell\)，其中 \(R_{h(\ell)}\) 是对应人体连杆的世界朝向，\(O_\ell\) 是固定对准偏移；然后用机器人自身连杆长度做正运动学得到目标位置，避免跨骨架缩放不一致。

\[ E^{\mathrm{sty}}_r = \sum_\ell \left[ \lambda^{\mathrm{pos}} \lVert x_\ell(q)-\hat x_\ell\rVert^2 + \lambda^{\mathrm{rot}} \lVert R_\ell(q)\ominus \hat R_\ell\rVert^2 \right], \]

\[ E^{\mathrm{sty}}_o = \sum_o \left[ \lambda^{\mathrm{pos}}_o \lVert \tau^o-\hat\tau^o\rVert^2 + \lambda^{\mathrm{rot}}_o \lVert R^o\ominus \hat R^o\rVert^2 \right]. \]

其中 \(R\ominus \hat R=\log(R\hat R^\top)^\vee\) 是世界坐标系下的朝向误差。机器人根部和场景保持原始尺度，位置权重设得较小，以便交互目标主导非交互连杆的姿态先验。

硬约束包括：有符号距离场给出的非穿透约束 \(d_{c,p}\ge -\varepsilon_{\mathrm{col}}\)，其中 \(\varepsilon_{\mathrm{col}}=0.3\) mm；自碰撞用连杆胶囊体近似；还有机器人关节限位、速度限位以及物体位移限位。求解时使用信任域序列二次规划（SQP），决策变量为机器人步长 \(\delta v\) 和每个物体的 \(\delta\xi_o=(\delta\tau_o,\delta\theta_o)\in\mathbb{R}^6\)，物体位姿按 \(\tau^o\leftarrow\tau^o+\delta\tau_o\)、\(R^o\leftarrow\exp(\delta\theta_o)R^o\) 更新。QP 子问题用 Gauss-Newton 二次近似和线性化约束，由 Pinocchio 提供解析雅可比、ProxQP 求解。

III-E Generalization to New Object Shapes（泛化到新物体形状）

为了把同一段演示迁移到新物体，论文在演示物体和替代物体的表面点云之间再解一次最优传输。两个点云分别在自己的局部坐标系中表示，并归一化到单位半径用于建立对应；对应只需传递“最近点位置”等拓扑信息，交互目标本身仍保持公制，不做尺寸缩放。替代物体位姿仍然是决策变量，因此机器人-物体和物体-物体相对运动可以根据新几何调整，同时尽量保留演示中的接触时间与接触关系。

6. 局限性和展望（约300字）

论文明确说明的限制包括：评估主要限于单一机器人（Unitree G1）、平地以及一段双物体 RGB-D 捕获；方法是运动学且逐帧求解，不显式建模力、力矩或时间相关性；物理迁移是单机器人、单段动作的策略部署，且策略不依赖物体感知。此外，当前 Python 实现虽比 OmniRetarget 快，但在行走和搬箱片段上仍需每帧约 21.5 ms 和 63.8 ms，距离高频在线重定向仍有优化空间。

可以谨慎推断的限制是：物体间最优传输迁移依赖表面拓扑相似；对于绳索、软体、液体等非刚性或可变形物体，以及需要长期稳定支撑的接触任务，仅靠有符号距离、最近点和相对方向可能不足以描述完整交互。

展望上，论文作者指出可以考虑把动力学可行性、接触力和时间窗口纳入优化，以支持更复杂地形和更丰富的操作场景。后续也可以在多机器人、多物体、非平坦地面和在线重定向上继续扩展。
