# LLM 入门：从预测下一个词到训练推理模型

学 LLM 时，Transformer、预训练、SFT、GRPO 等词常常一起出现，容易误以为它们是同一层面的技术。可以先把它们放在一张粗略的学习地图里：**模型怎样生成文字 → 怎样获得基础能力 → 怎样学会回答问题 → 怎样评价回答 → 怎样用奖励改进回答 → 怎样检验推理能力。**

下面的六阶段是**入门学习顺序**，不是规定每个模型都必须依次接受六轮训练。有了这张地图，再去看具体论文会更容易知道它解决的是哪一段问题。

## 第一阶段：Transformer 与下一个 token

先弄清 LLM 最基本的动作：读入已有文字，预测下一个 token（可以理解为一个词或词的一部分），再把新 token 接回输入，重复预测。Transformer 的注意力机制让模型利用前文；模型最终给词表中各个 token 一个概率。

这一阶段最值得理解的是**输入怎样变成概率，概率怎样变成连续的回答**。例如给出“北京是中国的”，模型可能给“首都”较高概率，但单次预测还不是完整对话。

## 第二阶段：预训练，获得通用能力

模型在大量文本上反复做“预测下一个 token”的练习，这叫预训练。它从中学习语言、知识和一些推理模式，得到一个能续写、但未必善于遵循提问方式的基础模型。

可以把这一阶段想成“广泛阅读”。关键问题是**训练数据是什么、预测损失是什么、规模如何影响能力与成本**。数据质量和评估尤其重要：答对训练材料里的句子，不等于面对新问题也可靠。

## 第三阶段：SFT，学会按要求回答

SFT（监督微调）用“用户问题 → 理想回答”的示范数据继续训练模型。它让基础模型更熟悉聊天格式、任务指令和回答风格。比如同样知道一道题的知识，SFT 可以教模型把答案写成用户要的步骤，而不是随意续写一段相关文字。

这一阶段可以先记住：**预训练主要教模型会什么，SFT 主要教模型怎样回答**。两者都用已有文本作学习信号，但数据来源和希望塑造的行为不同。

## 第四阶段：奖励与强化学习基础

示范答案不一定能覆盖所有好回答，于是我们还需要比较不同回答的好坏。一个奖励信号可以来自人工偏好、奖励模型，也可以来自可自动检查的结果，例如数学题是否答对。模型面对一个问题生成回答，得到奖励，再据此调整产生回答的倾向。

在学具体算法前，先分清三个角色：**策略**是正在生成回答的模型，**采样**是让它实际写出回答，**奖励**是对回答的评价。奖励只表达某种目标；如果评价方式设计得不好，模型可能学会迎合评分而不是真的解决问题。

## 第五阶段：PPO、GRPO 等后训练算法

到这里再看 GRPO 就有位置感了。GRPO（Group Relative Policy Optimization）通常让模型针对同一个问题生成一组回答，比较组内奖励的相对高低，再提高较好回答出现的倾向。PPO 是另一类常见的策略优化方法。它们都属于**利用奖励更新模型的后训练方法**，具体更新方式不同。

这一阶段先抓住“**好回答相对多学、差回答相对少学**”的直觉即可。KL 约束等机制常用于限制更新幅度，避免模型为了当前奖励偏离原本有用的行为。读 GRPO 的推导之前，理解上一阶段的策略、采样和奖励会省很多力气。

## 第六阶段：推理模型训练与评估实践

最后把前面的方法放进真实任务：怎样收集值得训练的题目、怎样验证答案、怎样判断模型是真会推理，还是只记住了题型？可验证的问题适合用检查器给反馈；开放问题则需要更谨慎地设计评价。

这一阶段关注**训练后的能力是否真的迁移**：既看新题上的正确率，也看不同难度、回答长度、成本和失败方式。一次奖励上涨或训练集成绩变好，都不能单独证明模型的推理能力提升。

## 记住这张地图就够了

可以用一句话回忆六阶段：**先懂模型怎样续写，再看它怎样预训练、怎样按指令回答；然后学习怎样评价回答、怎样用 GRPO 等算法改进回答，最后检查改进在新问题上是否成立。**

如果你已经懂 Transformer，GRPO 大约位于这张入门地图的**第五阶段**。真正的前置知识是 SFT、采样、奖励和基本的策略更新直觉；不必一开始就陷入公式细节。
