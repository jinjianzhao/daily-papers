# Transformer 基础：从注意力到序列建模

## 这篇文章解决什么问题

Transformer 用一组 token 表示输入，并让每个 token 根据上下文重新组合信息。它不依赖循环结构，因此可以并行处理整段序列，也能通过堆叠层逐步形成更抽象的表示。

## 核心数据流

1. 把文本、图像或其他输入切成 token，并映射到向量。
2. 加入位置编码，让模型知道 token 的顺序或空间位置。
3. 在每一层中，用自注意力计算 token 之间的关系，再用前馈网络变换每个 token 的表示。
4. 重复多层后，把最终表示交给预测、分类或生成头。

## 自注意力的直觉

每个 token 会产生 query、key 和 value。query 与其他 token 的 key 计算相似度，得到一组权重；再用这些权重对 value 加权求和。这样，一个 token 可以动态读取上下文中与当前任务相关的信息。

## 需要记住的三个点

- 注意力负责跨 token 的信息交换。
- 前馈网络负责逐 token 的非线性变换。
- 多头注意力让模型可以同时学习不同类型的关系。
